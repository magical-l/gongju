# 关系图 V1.1：排版效率（缩放 + 多选对齐 + 搜索）

日期：2026-10-18
状态：已实现（v1.72.0，2026-10-19）

## 目标

把「把图排好」这条路打通：

1. 实体可以在画布上缩放。
2. 能多选实体，整组移动、对齐、等距分布、批量删除、方向键微调。
3. 左树支持按名字/标签搜索，并支持多选高亮。

## 边界

**做：**

- 实体四角缩放手柄；宽 + 最小高度；内容垂直居中；端口/连线/标签实时跟随。
- 宽/高作为实体 `style` 覆盖项，沿原型链继承，右栏显示来源和 `↺`。
- 多选仅针对**实体**；关系仍单选。
- `Shift+点` 多选、`Shift+空白拖` 框选、点空白清空、`Ctrl+A` 全选已放置实体。
- 组拖、整组删除、方向键 1px / `Shift+方向键` 10px。
- 对齐：左/中/右、上/中/下；分布：水平/垂直等间距（按相邻边距）。
- 左树 `Shift+点` 实体行多选高亮；左树搜索框过滤实体名/关系标签。
- 右栏多选时切换为组面板。

**不做（留给后续）：**

- 复制粘贴/复制子树、颜色预设/实时预览（V1.1.1）
- 自动布局、富卡片/字段、图库/模板
- 关系多选、缩放多选实体、框选关系
- 触屏/pointercancel、正交连线、SVG/分享

## 数据与样式

### 实体尺寸

- `style.width` 有两种值：**有限数**（固定宽度，默认 168）或 **`'auto'`**（按文字定宽的**规则**）。
- `'auto'` 是规则而不是测量值：父节点设 `auto` 后，子节点继承的是规则，各自按自己的 `name` 测量宽度。熊 42px，熊 1 按「熊 1」算出的宽度会比 42 宽。
- 新增 `style.minHeight`，默认 0；0 表示由内容决定高度。
- CSS：固定宽度用数字；`auto` 由 CanvasView 在卡片渲染后按名字字体 + 左右 padding + 边框测量，夹在 [40, 480]；`min-height: style.minHeight`；内部 flex 垂直居中。
- 缩放拖角只写当前实体的 `style.width` / `style.minHeight`，即“覆盖项”；原型尺寸沿原型链传给未覆盖的后代。水平拖动写数字宽度，即取消该节点的 `auto` 规则；纯纵向拖动不动宽度。
- 最小宽度 40；`minHeight >= 0`；导入校验：实体 width 为 `'auto'` 或 >=40 的有限数，关系 width 仍为正数线宽。
- 宽度变化导致换行、高度变化由 CSS 自动处理；`getEntityRect` 继续用实测尺寸。
- 固定宽度与按文字规则**互斥**：右栏宽输入框为空/placeholder「按文字」表示规则生效；输入数字即固定；点「↺」清掉本节点覆盖，回到继承（可能是 auto、祖先数字或默认 168）。

### 缩放交互

- 选中单个实体时显示四角**方形**手柄；四边中点仍是圆形连接点。
- 按住任一角拖动：
  - 东/南：改宽/最小高度。
  - 西/北：同时改位置和宽/最小高度；位置 = 起始位置 + 拖动位移。
  - 宽度夹在 40 以上；最小高度夹在 0 以上；水平拖动写数字宽度，取消 auto 规则。
  - 卡片内容垂直居中；最小高度小于内容时，卡片仍会由内容撑高。
- 拖动过程中实时改卡片 CSS 和所有关联边；松手 `pushHistory()` 一次。
- 右栏宽行：`auto` 时数字框为空、placeholder「按文字」，旁边「✓ 按文字」按钮选中；输入数字即固定并取消规则；高空/0 → 清空覆盖（自动）。

## 多选

- 选择状态：
  - `app.selectedIds: Set<entityId>`：多选实体集合。
  - `app.selectedId`：当前主对象；选实体时等于最后点击的实体，选关系时是关系 id。
  - 关系选中时清空 `selectedIds`；实体多选时 `selectedId` 是其中一个。
- 交互：
  - `Shift+点` 卡片/左树实体行：切换该实体在选择集合中。
  - 普通点卡片/左树实体行：单选。
  - `Shift+空白拖`：框选（与矩形相交的已放置实体），替换当前选择。
  - 普通空白拖：平移（保持现状）。
  - 点空白：清空选择。
  - `Ctrl+A`：选中所有已放置实体。
- 组拖：
  - 普通拖动已选中的卡片 = 整组移动；拖动未选中的卡片 = 先单选再移动。
  - 以整组外接框做对齐吸附，显示参考线；松手一步历史。
  - 没有实际位移的点击：若多选，则收拢为单点实体。
- 删除：
  - 有 `selectedIds` 时逐个删除；能删的删掉，被引用阻塞的汇总 toast；一次历史。
  - 无 `selectedIds` 且选中关系时，删除该关系（沿用现状）。
- 方向键：
  - 有实体选择时移动全部已选实体；1px；`Shift` 10px。
  - 连续微调用 400ms 定时器合并成一条历史。
- 对齐/分布：
  - 选中 ≥2 个实体显示组面板：左/中/右、上/中/下对齐；≥3 个显示「水平等距」「垂直等距」。
  - 对齐目标：选择集外接框；左对齐 = 全部左边对齐到最左，右/上/下同理；中/中对齐到外接框中心。
  - 等距 = **相邻卡片之间的空隙相等**；保持首尾位置，当总尺寸超过首尾跨度时间距归零、从第一张依次排开，末张自动移出原跨度，不产生负间距重叠。
  - 排成一行/一列不另设按钮：先用上/中/下的「中」或左/中/右的「中」对齐，再用对应等距。
  - 一步历史。

## 左树

- 搜索框在树上方，按实体 `name` / 关系有效标签过滤（不区分大小写）。
- 命中行连同祖先显示；祖先强制展开；非命中隐藏。
- 点搜索结果选中并居中。
- 多选高亮：`state.selectedIds` 中的实体行高亮；关系仍用 `selectedId`。
- `Shift+点` 实体行切换多选；关系行保持单选并设置待用关系。

## 右栏

- 选中 2+ 实体：组面板显示 `已选 N 个实体`、六个对齐按钮、两个分布按钮（不足 3 个禁用）、删除、取消选择。
- 选中单个实体：现有面板 + 宽/高行；宽行区分固定数字与「按文字」规则，显示继承来源和 `↺`；原型有子对象时提示尺寸会沿原型链继承。
- 选中关系：保持现状。
- 未选中：保持图名/计数。

## 实现记录与决策日志（v1.72.0，2026-10-19）

### 交付

- 实体缩放：四角方形手柄；宽 + 最小高度；内容垂直居中；端口/连线/标签实时跟随；一步撤销。
- 尺寸继承：实体 `width`/`minHeight` 沿原型链继承；右栏显示来源与 `↺`；原型节点提示尺寸会传给后代。
- 按文字定宽：`width: 'auto'` 是**可继承规则**，子节点按自己的名字测量宽；与固定数字宽度互斥。熊 auto=42，熊 1 继承规则后按「熊 1」=56。
- 最小宽度 40；水平拖缩写固定数字并取消该节点 auto；纯纵向拖动保留宽度规则。
- 多选：Shift 点选/框选、组拖、Ctrl+A、方向键 1px/10px（400ms 合并历史）、批量删除（阻塞汇总）、对齐六种 + 水平/垂直等距。
- 等距溢出：总尺寸超过首尾跨度时间距归零、末张自动撑开，不再负间距重叠；按钮改名「水平等距/垂直等距」并加说明。
- 左树搜索与多选高亮；右栏多选组面板；搜索模式 twisty 不改折叠状态。

### 缓存事故与修正

- 现象：按文字定宽后宽度变 168 且不可调；刷新提示「本地数据已损坏」；新建图也不能调宽。
- 根因：`关系图.html` 资源无缓存版本，浏览器混用旧 `model.js`（无 `MIN_ENTITY_WIDTH`）与新 `关系图.js`；宽度运算得到 `NaN`，自动保存序列化为 `width: null`，刷新校验失败并备份。
- 修复：本页资源统一 `?v=261020`；`MODEL_VERSION=3` 与 app 版本握手；`saveNow` 写前 `validateDocument`；宽度测量/输入/缩放全部 `Number.isFinite` 防御。
- 数据恢复：从 `relation_graph_v1_broken_1792377238799` 删除 null width/minHeight 后写回主键，旧 4 实体图恢复并通过新模型校验；事故期间新建的 2 实体图备份在 `relation_graph_v1_before_recovery_1792378457656`。
- 教训：本页任何脚本/样式改动必须同步递增 `?v=YYMMDD` 与 `MODEL_VERSION`，并保持保存前校验。
