### 导出 PNG（核心）
- **SVG foreignObject 光栅化**：克隆画布 DOM → 去 canvas 平移缩放 transform、去选中态（`.selected`/resize-handle）→ 注入各元素实时 `font-family` → 塞进 `<svg><foreignObject>` 转 data URI → `new Image()` 让浏览器自渲染 → drawImage 进 canvas → toBlob 下载。
- 失败兜底 `toastr.error('导出图片失败')`（img.onerror）。

### 导出 HTML / JSON
- HTML：`captureSnapshot()` 数据生成自包含 HTML（内嵌 JSON + 极简渲染脚本，双击即看）；JSON 内 `<` 转义为 `<` 防 `</script>` 破坏。
- JSON：`captureSnapshot()` 快照，与 localStorage 同格式，可回导。

### 导入 JSON（「打开」）
- 「打开」直接弹文件选择器导入 JSON；移除「恢复上次保存」。

## 设计决策

- **放弃 canvas 逐字符重绘**：`fillText`+`textBaseline:middle` 的字体度量与 DOM 行盒基线不一致（元素垂直偏 6-7px，且 emoji/符号/CJK 偏移不同 → 相对偏）。foreignObject 让浏览器自渲染，像素级还原。
- **foreignObject 必须注入真实 font-family**：内容默认用浏览器默认字体（Times New Roman）；即使 emoji 字形来自 emoji 字体，**行盒度量（strut）由声明的 font-family 决定** → emoji 垂直落点也偏移、随字号放大。注入 `getComputedStyle().fontFamily` 后声明字体与编辑器一致。
- **移除「恢复上次保存」**：应用每次操作自动保存（pushHistory→autoSave），localStorage 恒等于当前状态，该按钮等价 no-op；回退靠撤销（Ctrl+Z，50 步）。
- **不引入 html2canvas 等依赖**：纯静态项目、无 npm；foreignObject 零依赖实现同等效果。
- **「打开」直接导入而非弹窗**：只剩一个动作时弹窗冗余。

## 踩坑记录

1. **CSS 渐变被浏览器规范化**：`#b2e0fa` → `rgb(178,224,250)`，正则 `/linear-gradient\(([^,]+),([^,]+),([^,]+)\)/` 遇 rgb() 内逗号失配 → 走白底分支，背景变白。教训：解析 CSS 渐变要按顶层逗号切分（括号内逗号不算）。
2. **canvas 逐字符重绘文本偏移**：`textBaseline:middle` 用字体 ascent/descent 度量，DOM `inline-block; line-height:1` 行盒基线由字体 strut 决定，两者不一致 → 元素垂直偏移 6-7px，且不同字符类型偏移量不同。教训：导出 DOM 像素优先让浏览器自渲染（foreignObject）。
3. **foreignObject 默认字体 ≠ 编辑器字体**：即使全 emoji 场景也偏移——emoji 字形来自 emoji 字体，但行盒度量由声明 font-family 决定（struts）。实测全 emoji 场景旧版 dy=-2~-3px（随字号放大），注入字体后 -1px（截图取整）。教训：foreignObject 须显式带字体，见 [[image-export-foreignobject]]。
4. **导入 JSON 缺字段会搞坏画布**：只校验 elements 数组时，缺 transform/width 导致 `canvasWidth=undefined`、transform=NaN → 画布静默损坏。修复：整体校验 + 字段默认值 + 逐元素规范化（left/top 补 px、fontSize/repeat 兜底、缺 char 报错），失败原子性（不调用 applySnapshot，避免导一半）。
5. **CSS 写保护 hook**：CSS 增删走 `css-ast` 官方工具（`ensure-rule` 添加、`remove-rule` 删除），不可直接 Edit/Write。

## 验证

- **混合字符场景**（emoji/CJK/符号/拉丁/旋转+重复 9 元素）：导出与 DOM 对齐 ≤1px、像素数逐字一致（n 全同）、元素间相对距离最大差 0.0px。
- **全 emoji 场景**：旧版（不注入字体）dy=-2~-3px，新版（注入）dy=-1px（截图 601/600 取整）。
- **导入健壮性**：5 种畸形 JSON（非 JSON / 无 elements / 元素缺 char / 缺 transform+width / 缺 left+top）全部优雅处理，画布不坏；字段级缺失走默认值。
- **回归**：导出弹窗 3 按钮、打开直导、PNG 背景渐变、清空/撤销、导出 HTML 独立渲染 7 元素、0 console error。全绿。
