## 2. 命名法

- **条目级主名** = `kEH_Desc` 的**中文短名**，只取主体
  （照 `✓035` 定的口径：首个名词短语、切到第一个逗号、去掉 `with/holding/…` 引出的附带成分），4–12 字
- **条目级简介** = 「画的是〈Desc 中译〉。〈类型〉符（〈具体〉），读作 〈`kEH_FVal`〉。」
  - 类型按 `kEH_Func` 首词映射：`Phonemogram`→音符、`Logogram (X)`→表意符（X）、
    `Classifier X`→限定符（X）、`Phono-repeater`→重复符
- **不带 Gardiner 码**（直译名里已有）；`desc` 里的部件括注如 `(S42)` 在主名里去掉、简介里照留

样本（官方码表字形与拟名并排的对照图见 `tmp/egypt-sheet-1..10.png`）：

|---|---|---|

## 3. 做法

照 `设计/数据说明.md` §七那套「按域批量译名」：**按码位切 10 批（每批 ~95），一批一个子代理**，
各产出「码位 → 主名 + 简介」的成品映射到 `tmp/egypt-N.json`（**不碰权威数据**），主代理验货后统一落盘。

**验货四项**（`§七` 定的）＋复跑体检，实抓出：

| 抓到的 | 数 | 处置 |
|---|---|---|
| 主名里混进 Gardiner 部件码 | 16 | 去掉（规范自相矛盾，子代理提过） |
| 全局撞名「赛特头权杖」 | 1 | `78534` 与 `78592` 描述几乎同，前者多羽饰带子 → 「带羽饰的赛特头权杖」 |
| 简介开头不统一（「画的」vs「画的是」） | 28 | 统一成「画的是」 |
| 键集合不符 / 键不存在 / 残留英文 | 0 | — |

## 4. 落盘后的三轮措辞修正

1. **`纸草` → `纸莎草`**（18 处，主名与简介都有）——项目惯例（`✓035` 文档同）
2. **`78723`/`78724` 主名补「卷起」**——`desc` 原词是 `shelter`（庇护所），但「棚」易被读成草棚，
   故写「卷起的纸莎草牧人棚」。这两个是 **`sꜣ`（保护）符**，简介里补了「这也是古埃及常见的一种护身符」
3. **9 条真指国王的条目加「法老」别名**（如「持鞭的坐姿国王」→ 别名「持鞭的坐姿法老」）——
   主名保留「国王」（埃及学里 `nswt` 就是"王"），别名只当搜索键。
   ⚠️ 含「王」的 15 条里，**「王座」「王后」「王冠」「王名圈」6 条不能动**
4. **`78420` 主名补「平面图」**——`desc` 是 `A plan of a courtyard or reed shelter.`，是**图**不是实物
