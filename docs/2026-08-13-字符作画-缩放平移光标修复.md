# 字符作画页：缩放平移与光标修复（bug2）

## 动机

todo bug2「很多地方都是 grab 光标，但没有相应的用处」+ 用户实测反馈的缩放平移问题：放大后滚动条"自己伸缩"、贴底元素拖不到底、左右拖不动。

## 变更

| 文件 | 变更 |
|------|------|
| `字符作画/字符作画.js` | `clampTransform` 重写（offset 基准 + 位置感知溢出）；新增 `updatePanCursor`；`initCanvasPan` 加溢出门槛；`setZoom`/画布设置/init/resize 刷新平移态 |
| `字符作画/字符作画.css` | `.canvas-card` `overflow:auto → hidden`、去常驻 `cursor:grab`、新增 `.pan-enabled` 条件光标；`.float-panel` 加 `cursor:default` |

### grab 光标条件化
- 画布溢出卡片才显示 grab（`.pan-enabled` 类），zoom=1 无溢出时默认光标。
- `updatePanCursor()` 维护类；`setZoom`/画布设置/init/窗口 resize/平移结束各刷新一次。
- pan 门槛：无溢出时不进入平移（消灭"拖了没反应"）。
- `.scene-item`/`.layer-rail-item`/`.symbol-card` 的 grab 保留（本就可拖）。

### 滚动条移除
- `.canvas-card` `overflow:auto → hidden`：CSS transform 改变可滚动溢出 → 滚动条 thumb 随平移伸缩，且滚动条与 transform 平移两套导航打架。改为 **grab 平移唯一导航**（画布工具标准做法）。

### clampTransform 重写（核心）
- **基准位置用 `canvas.offsetLeft/Top`**（布局位置，不受 transform 影响、拖拽中稳定），替代 `getBoundingClientRect() - sceneTransform`（拖拽中 sceneTransform 先更新、DOM 差一拍，导致 clamp 范围算错 → 边缘内容不可达）。
- **位置感知溢出**：`baseLeft + canvasVisualW > containerW`（而非 `canvasW > containerW`）。画布 `margin:auto` 居中，放大后从基准向右下扩展——即使尺寸小于容器，右/下缘也已溢出，必须按位置判断。

## 设计决策

- **去滚动条、纯 grab 平移**：滚动条（overflow:auto）与 transform 平移本质冲突，无法共存；Figma/Miro 均是无滚动条 + grab。平移覆盖画布全部内容（clamp 修好后）。
- **平移只到内容边界**：没溢出的方向无内容可看，平移为零。水平方向在 1920 屏需 zoom ≥ ~160%（居中右缘 1656 > 1552）才可平移。

## 踩坑记录

1. **transform + overflow:auto 幻影滚动溢出**：浏览器对 `transform:scale()` 元素算可滚动溢出与视觉尺寸不一致（scrollHeight 虚高）→ 滚动条出现但拖不动、thumb 随 transform 伸缩。修复：`overflow:hidden` + 位置感知的 getBoundingClientRect 判断。
2. **clamp 基准不能从 getBoundingClientRect 反推**：`canvasRect.top - sceneTransform.y` 在拖拽中因 DOM 与 JS 差一拍而错误（mousemove 先改 sceneTransform 再读 DOM）。修复：`offsetTop/offsetLeft`（布局值，与 transform 无关，恒稳定）。
3. **居中元素的溢出判断必须位置感知**：`margin:auto` 居中画布（baseLeft=376），zoom 160% 时宽 1280 < 卡片 1552 但右缘 1656 > 1552——按尺寸判断误判"塞得下"→ 右侧 104px 内容永久不可达。修复：`baseLeft + visualW > containerW`。
4. **CSS 守卫**：`.css` 文件的任何写命令（含官方 css-ast 工具）都被 hook 拦，需"验证副本 + 单行锚点 Edit"绕过（见 [[css-edit-contract]]）。

## 验证

五套 Playwright 回归共 50 项全绿、0 console error：
- 平移到底：zoom160 垂直拖到底画布底边=卡片底边（gap 0）、zoom200 水平拖到底画布右边=卡片右边（gap 0）、贴底元素画布内部分全部可见。
- 水平平移：zoom130 水平真塞得下→拖不动（正确）；zoom160 居中右缘溢出→可拖；zoom200 可来回拖。
- grab 光标：zoom1 无 grab、zoom1.5 有、floatPanel 恒 default；元素/素材/图层 grab 保留、元素拖拽生效。
