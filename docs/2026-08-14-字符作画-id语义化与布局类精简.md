# 字符作画页：id 语义化 + 布局类精简

## 动机

在优化7（往 common.css/layout.css 靠）基础上深化两件事：
1. **id 只留给语义唯一实体**——id 用于 JS 锚点还不够，语义上"一类"（可以有多个）的东西即使 JS 只操作一个也应改 class。例：工具栏没有"规定只有一个"，就该用 `.toolbar` 而非 `#toolbar`。
2. **CSS 零 id 选择器**——id 只做 JS 锚点，样式一律 class。

## 类名判定原则

- **id**：语义上"页面确定唯一实体"（画布、图层轨道、主弹窗）→ 保留 id 作 JS 锚点。CSS 不用 id。
- **class**：语义上"一类"（按钮、滑块、素材容器、面板区）→ 一律 class，即使 JS 恰好只操作一个。
- 类名避撞 common.css 的 icon 状态类（`.help/.close/.copy/.delete/.settings`），用组合词（`help-btn`/`close-props`/`copy-char`/`delete-item`/`canvas-settings`）。

## 踩坑记录

1. **layout.css `.flex` 默认 `flex-wrap: wrap`**——把自配 `flex-direction:column`（原生默认 nowrap）换成 `.flex items-go-y` 后，flex column 在子元素总高超过容器高时**横向换列**（tab 与 symbols 并排、symbols 超右缘）。必须显式加 `items-single-line`（nowrap）。波及 `.right-side`（row，行高被 library-bar 内容 1206px 撑到 1269px）、`.library-bar`、`.layer-rail` 三处。
2. **layout.css `.flex` 默认 `align-items: flex-start`**——flex column 子元素宽度收缩到内容宽，tab 不占满、字换行。需 `items-x-stretch`（column 下 = align-items:stretch）显式拉伸。
3. **`items-x-*`/`items-y-*` 是方向感知的**——在 `items-go-y`（column）作用域内会重映射（layout.css 91-99 行）：`items-x-stretch`=align-items:stretch（水平拉伸）、`items-x-near-center`=align-items:center+justify-content:flex-start（水平居中+垂直从顶）。曾误用 y 方向类（垂直拉伸+触发 `> *{flex:1}` 把 tab 拉高到 379px），实测后修正。
4. **`scrollable.on-y` 是强制滚动**（overflow-y:scroll 恒显滚动条），内容短也显示；需 `scrollable on-y when-content-long`（auto 按需）。
5. **`.no-shrink` 是后代选择器**（`.flex .no-shrink`），自身是 `.flex` 但祖先无 `.flex` 时不生效——`.right-side` 的 no-shrink 无效，改回 CSS `flex-shrink:0`；`tab-bar` 的 no-shrink 因祖先 `.library-bar` 有 `.flex` 而有效。
6. 这五处全部是"自配 flex 语义（nowrap + stretch）被 `.flex` 类默认值改变"的连锁反应，浏览器实测定位，不能靠静态推理。
7. **`.scrollable.on-y.when-content-long` 带 `scrollbar-gutter: stable`**（common.css）——无条件预留滚动条空间（~15px）。36px 窄轨道被挤得内容区只剩 19px（珠子 22px 放不下），珠子相对轨道中心偏左 7px、右侧留大边距。layer-rail 珠子少不需要预留，去 scrollable 类 + CSS `overflow-y:auto`（按需滚动、无占位）后珠子 offset 0 居中、左右 gap 对称。用公共滚动类时注意 gutter 占位。
