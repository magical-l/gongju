# 字符作画页：素材库 tab 优化（优化4 + 优化2）

## 动机

- todo 优化4「字符素材库的滚动条现在包含了tab」：`.library-bar` 是整体滚动容器（`overflow-y: auto`），tab 栏也在其中，素材多时滚动会把 tab 一起滚出视野。
- todo 优化2「字符素材库的tab样式」：把自定义 `.tab-btn` + JS 切 class 的旧实现，换成 common.css 原生的 `label.btn` + radio 机制。

## 变更

| 文件 | 变更 |
|------|------|
| `字符作画/字符作画.css` | ①`.library-bar` 改 flex 列 + `overflow:hidden`，`.tab-bar` 加 `flex-shrink:0`，`.symbols-scroll` 改为唯一滚动区（`flex:1; min-height:0; overflow-y:auto`）；②删 `.tab-btn` 三组样式、`.tab-bar` 去 `gap`；③加 `.tab-bar .btn { flex:1 }` 均分栏宽；④素材容器显隐改 CSS `:has(input[value="normal"]:checked)` 驱动 |
| `字符作画/字符作画.html` | tab 从 `<button class="tab-btn" data-tab>` 换成 `<label class="btn"><input type="radio" name="symbolTab">`，`.tab-bar` 套 `.btn-group items-go-x`；`#normalSymbolsContainer` 去掉内联 `style="display:none"`（交给 CSS） |
| `字符作画/字符作画.js` | 删除整个 `initTabs` 函数及其调用——选中态与容器显隐全由原生 radio 互斥 + CSS `:has` 驱动，JS 完全不碰 tab |

## 优化4：滚动区下放

`<aside class="library-bar">` 从整体滚动改为 flex 列布局：`.tab-bar` 固定（`flex-shrink:0`），只有 `.symbols-scroll` 滚动。滚动时 tab 相对库栏顶边恒 9px 不动。

## 优化2：tab 改 common.css 原生机制

现在 tab 切换的工作方式：点击 `label.btn` → 浏览器原生 radio 互斥（同名 `symbolTab`）→ CSS `:has` 驱动选中态背景（`label.btn:has(> input:checked)` 映射变量）和素材容器显隐（`.library-bar:has(input[value="normal"]:checked)`）。零 JS。

`.btn-group` 需要 `.items-go-x` 变体才给首尾圆角（否则退成直角分段）。

## 踩坑记录

1. **`.tab-bar` 的 `gap` 会覆盖 `.btn-group` 的 `gap:0`**——同特异性后声明赢，字符作画.css 后加载，导致分段中间出现 6px 缝隙。必须删掉 `.tab-bar` 的自定义 gap。
2. **`.btn-group` 相邻段是 1px+1px 双边框**（每个按钮自带 `border:1px`）——common.css 组件默认行为，非本页引入，可接受。
3. **选中 tab 上悬停会短暂显示 `.btn:hover` 浅色**（比选中态 `--bg-active` 略浅）——common.css 悬停机制既有行为，鼠标移开恢复，不影响功能。
4. **html-editor 子代理用 Node 精确字符串替换脚本而非 css-ast**（本环境 AST 编辑工具受限、`add-multi` 按 2 空格推断缩进与本文件 4 空格不符），等价 Edit 行为、格式完全保持，脚本已清理。
