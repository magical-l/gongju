## 少打标签补正

- 分数：¼½¾ + ⅐-⅟ + ↉ → `数学/数字/分数`
- 上标、下标：²³¹ + ⁰-ₜ → `数学/数字/上标、下标`
- 罗马数字补齐：Ⅼ-ↈ → `数学/数字/罗马数字`
- 带圈数字补齐：⓪-⓿ + ❶-➓ → `带圈数字、带框数字`
- 阿拉伯数字 0-9 → `数学/数字/阿拉伯数字`
- 🚀🛸 → `天文、太空、宇宙/航天`；🛰 → `通讯、网络`
- ⚖ → `法律、秩序`；🏭 → `工业`；🚜 → `农业`

## 设计决策

### 特殊语言标记拆两节点

原节点混装两个无关概念：方块片假名（3300-33FF，CJK 兼容字，256 字符）与手语文字 SignWriting（1D800-1DA86，540 字符）。拆为：
- `语言、文字/方块假名`：别名（片假名方块字、日语兼容字符、特殊语言标记）——保留旧名便于搜索。
- `语言、文字/手语文字`：别名（手语符号、SignWriting）。

为支撑此拆分，build_tags.py 新增 `SPLIT_RANGES`（旧路径 → {新路径: [[lo,hi]...]}，区间正好覆盖旧节点 ranges），比 SPLITS 逐码位清单更清晰；下次遇到整块拆分直接用。

### build_tags.py 幂等与防护

- 本次审计的所有放置修正都固化进 `EXTRA_REMOVES`/`EXTRA_ADDS`（可重跑）。
- 上标、下标区间初次误加未分配码位 2072/2073/208F（UCD 17 判定），已修并在 EXTRA_REMOVES 加防护条目。

### 未分配的判断

判断未分配必须用 `ucd-17.0.0.json` 的 categories.Cn（Python unicodedata 版本旧，会把新分配字符误判为 Cn）。
