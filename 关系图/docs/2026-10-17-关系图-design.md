# 工具兽 · 关系图 设计文档

日期：2026-10-17
状态：已实现（v1.72.0，2026-10-19；V1.1 见 `2026-10-18-关系图-V1.1-design.md`）

## 背景

站点需要一个**可编辑的关系图**，用来表达依赖、进化、科技树、食物链、地理迁移、时间线、发展路径等结构。现有页面里没有同类工具。

这个工具的核心不是「画框和线」，而是：

1. **对象完全平等** —— 没有「类型对象」和「实例对象」的区别，只有对象和一条可选的 `prototypeId` 指针。
2. **原型是角色，不是种类** —— 任何对象都可以被同类的其他对象指向而成为原型；任何对象都可以覆盖自己的样式。
3. **左树与画布是同一批对象的两个视图** —— 左树按原型链组织全部对象，画布显示其中被放置的那部分。
4. **线是自由的** —— 一条线可以两端都接实体，也可以一端接实体、一端自由，或两端都自由；自由端点随时可以接上或拉开。

## 最小完成条件

能在一个页面里：

- 在左树建立实体/关系对象及其原型层级；
- 把对象拖到画布生成实例，或把对象本身放到画布；
- 用连接点画关系，也能放一条自由线再接头；
- 改原型样式能传递给后代，后代能单独覆盖；
- 撤销/重做、自动保存、JSON 导入导出、PNG 导出、缩放平移；
- 刷新后数据还在。

## 本次范围

**做：**

- 单图编辑器，一张图画一份数据
- 实体/关系统一对象模型与多级原型链
- 左栏两片原型森林（实体 / 关系）
- 画布 DOM 卡片 + SVG 连线
- 关系端点：实体端口或自由坐标
- 样式按属性继承/覆盖，关系标签继承/覆盖
- 拖拽创建、连接点拉线、端点改接、对齐吸附
- 撤销/重做、自动保存、JSON 导入导出、PNG 导出
- 缩放/平移/适应内容
- 帮助说明弹窗
- 接入全站导航与首页

**不做（进路线图）：**

- 触屏优化
- 多选、框选、批量操作、复制粘贴、复制子树
- 自动布局、对齐分布、分组/容器
- 富卡片（图标、描述、字段、图片）
- 正交连线与自动避障
- 自连（两端接同一实体）
- 把原型链本身渲染成画布上的关系视图
- 多图库、分享链接、协作
- 模板库

## 一、核心模型

### 1.1 两类对象

统一文档只有 `entities` 和 `relations` 两个数组，没有独立的「类型列表」。

```js
{
  schemaVersion: 1,
  name: "未命名关系图",

  entities: [
    {
      id: "n_species",
      name: "物种",
      prototypeId: null,
      position: null,          // null = 未放置，只存在于左树
      style: {}                // 只存覆盖项
    },
    {
      id: "n_tiger",
      name: "虎",
      prototypeId: "n_species",
      position: { x: 320, y: 180 },
      style: {}
    },
    {
      id: "n_white_tiger",
      name: "白化虎",
      prototypeId: "n_tiger",
      position: { x: 560, y: 180 },
      style: { fill: "#ffffff" }
    },
    {
      id: "n_deer",
      name: "鹿",
      prototypeId: "n_species",
      position: { x: 320, y: 380 },
      style: {}
    }
  ],

  relations: [
    {
      id: "r_predator",
      name: "捕食",
      prototypeId: null,
      ends: null,              // null = 未放置的关系定义
      style: {}
    },
    {
      id: "r_1",
      name: "",                // 空 = 继承原型的标签
      prototypeId: "r_predator",
      ends: {
        a: { entityId: "n_tiger", port: "right" },
        b: { entityId: "n_deer",  port: "left"  }
      },
      style: {}
    },
    {
      id: "r_free",
      name: "",
      prototypeId: "r_predator",
      ends: {
        a: { x: 700, y: 300 },
        b: { x: 860, y: 300 }
      },
      style: {}
    }
  ],

  viewport: { x: 0, y: 0, zoom: 1 }
}
```

### 1.2 实体

| 字段 | 说明 |
|---|---|
| `id` | `n_` 前缀，文档内唯一 |
| `name` | 必填，始终是自身的名字，不继承 |
| `prototypeId` | 可空；必须指向另一个实体 |
| `position` | `{x, y}` 为卡片左上角；`null` 表示未放置 |
| `style` | 只存覆盖项，键见 1.5 |

### 1.3 关系

| 字段 | 说明 |
|---|---|
| `id` | `r_` 前缀，文档内唯一 |
| `name` | 可选；空字符串表示沿原型链继承标签 |
| `prototypeId` | 可空；必须指向另一条关系 |
| `ends` | `null` 表示未放置的关系定义；否则为 `{ a, b }` |
| `style` | 只存覆盖项，键见 1.5 |

端点：

```js
{ entityId: "n_1", port: "right" }   // 接实体端口
{ x: 700, y: 300 }                   // 自由坐标
```

- `port` ∈ `top | right | bottom | left`。
- `a` 是方向起点，`b` 是终点（箭头默认在 `b`）。
- 两端可以独立是「接实体」或「自由」。

### 1.4 放置与可见性

- 实体：`position !== null` 才在画布上。
- 关系：`ends === null` 不在画布上；`ends !== null` 时，**只要有一个接实体的端点所指向的实体未放置，整条关系就不显示**，但对象仍保留在左树。
- 实体从画布移除时，`position = null`；挂在上面的关系随之隐藏，重新放置后自动出现。
- 关系从画布移除时，`ends = null`（几何信息丢失，可用撤销恢复）。

### 1.5 原型与样式继承

`style` 只写覆盖项。解析顺序：

```
内置默认样式 → 根原型.style → … → 当前对象.style
```

- 每次取值都沿 `prototypeId` 链合并，后出现的键覆盖前面的。
- 改祖先的某个键，所有未覆盖该键的后代立即跟着变。
- 当前对象自己存了某个键，就只影响自己和未覆盖的后代。
- 右栏「↺ 继承」= 从当前对象的 `style` 中删除该键。

实体样式键：

| 键 | 值 |
|---|---|
| `shape` | `rounded` / `rect` / `pill` |
| `fill` | CSS 颜色 |
| `border` | CSS 颜色 |
| `text` | CSS 颜色 |
| `width` | 数字，V1 固定 168，不暴露编辑（预留） |

关系样式键：

| 键 | 值 |
|---|---|
| `color` | CSS 颜色 |
| `dash` | 布尔 |
| `arrow` | `end` / `both` / `none` |
| `lineStyle` | `curve` / `straight` |
| `showLabel` | 布尔 |
| `width` | 数字，V1 固定 2，不暴露编辑（预留） |

内置默认：

```js
ENTITY_STYLE_DEFAULTS = {
  shape: "rounded",
  fill: "#ffffff",
  border: "#9aa3b2",
  text: "#1f2430",
  width: 168
};

RELATION_STYLE_DEFAULTS = {
  color: "#5b6472",
  dash: false,
  arrow: "end",
  lineStyle: "curve",
  showLabel: true,
  width: 2
};
```

### 1.6 关系标签

- 有效标签 = 自身 `name` 非空 → 用它；否则沿 `prototypeId` 找最近的非空 `name`；都没有则显示「关系」。
- 关系实例通常 `name: ""`，因此随原型标签变化而变化。
- 单独改一条线的 `name` 即覆盖标签，不影响原型。
- 标签是否画在线上由 `style.showLabel` 控制；左树永远显示有效标签。

### 1.7 文档与 ID

- `schemaVersion: 1`；导入时版本不符直接拒绝，并给出提示。
- ID 使用 `n_` / `r_` 前缀 + 随机/计数；同数组内唯一，跨数组也不重复（便于跨引用排查）。
- `viewport` 参与自动保存和 JSON 导出，但**不进撤销历史**。

## 二、左栏：两片原型森林

### 2.1 结构

```
实体                                   ＋
▾ 物种 (2)
    ▾ 虎 (1)
        白化虎
    ▾ 环境
关系                                   ＋
▾ 捕食 (2)
    捕食 · 虎 → 狼
    捕食 · 狼 → 兔
▾ 栖息
    栖息 · 自由线
```

- 两片森林分别按实体的 `prototypeId`、关系的 `prototypeId` 嵌套。
- 根 = `prototypeId === null` 的对象。
- 有子对象的行显示折叠三角；折叠状态保存在内存中，刷新后全部展开。
- 行尾显示子对象数；关系行显示有效标签和端点状态。

### 2.2 行状态

实体的行尾状态：

- `在画布`：`position !== null`
- `未放置`：`position === null`

关系的行尾状态：

- `未放置`：`ends === null`
- `自由线`：两端都是自由坐标
- `虎 → …` / `… → 狼`：一端接实体、一端自由
- `虎 → 狼`：两端都接实体
- 若接实体的一端所在的实体未放置，行尾额外标注 `端点未放置`，画布上不显示

### 2.3 操作

| 操作 | 行为 |
|---|---|
| 点击行 | 选中对象；已放置则画布居中；未放置只更新左树和右栏 |
| 点击关系行 | 选中并进入「待连线」状态（见 4.3） |
| 行上 `＋` | 新建一个**未放置**的子对象 |
| 拖实体行到画布 | 在落点生成一个**已放置**的子实体 |
| 拖关系行到实体 | 生成一条从该实体出发的**半连接线**：起点接最近端口，终点自由，沿该端口法线向外 120px |
| 拖关系行到空白画布 | 生成一条以落点为中心的**自由线**（默认 140px 水平线） |
| `Ctrl+拖` / `Alt+拖` 实体行 | 把该实体本身放到画布；已放置则移动到落点 |
| `Ctrl+拖` / `Alt+拖` 未放置的关系行 | 把该关系本身放到画布，成为自由线 |
| 行菜单「放到画布」 | 仅未放置对象：实体放到视口中央；关系定义变成自由线放到视口中央 |
| 行菜单「从画布移除」 | 仅已放置对象：实体 `position = null`；关系 `ends = null` |
| 行菜单「删除」 | 走统一删除规则（见 6.1） |

- 默认拖 = 建子对象；`Ctrl` = 操作对象本身。Mac 上 `Ctrl+拖` 与右键冲突，所以 `Alt+拖` 作为别名，界面提示写「Ctrl+拖（Mac：Alt+拖）」。
- 默认拖关系行时同时把它设为下一条线使用的关系；`Ctrl+拖` 只放置对象本身，不进入待连线状态。

### 2.4 新建默认值

- 根实体：「新实体」
- 子实体：`父名 N`，N 取同级未被占用的最小正整数
- 根关系：「新关系」
- 子关系（`＋` 创建的定义）：`父标签 变体`，重名时追加数字
- 由拖拽生成的关系实例：`name: ""`，继承原型标签
- 新对象 `style: {}`，全部继承

### 2.5 父原型修改

- 右栏「原型」下拉可改父级，选项包含「无（根）」。
- 候选排除自己和自己的后代，防止环。
- 实体的父候选只能是实体；关系的父候选只能是关系。
- 改父级不改变位置/端点，只改变原型链和解析后的样式/标签。

## 三、画布

### 3.1 渲染

- 世界层用 `transform: translate(...) scale(...)` 承载缩放与平移。
- 实体 = 绝对定位的 DOM 卡片：
  - 宽 168px，高度随文字自动；
  - 内边距、圆角/直角/胶囊由 `shape` 决定；
  - `fill / border / text` 通过 CSS 变量落到卡片上；
  - V1 卡片只显示名字，原型关系由左树表达。
- 关系 = SVG 层：
  - 路径可曲线或直线；
  - 颜色、虚线、箭头由解析后的关系样式决定；
  - 标签画在路径中点，带浅色底，`showLabel: false` 时不画；
  - 每条可见路径下叠一条透明的加宽命中路径。
- 层级：关系路径 → 关系标签 → 实体卡片 → 选中态/连接点/端点手柄/参考线。
- SVG 层尺寸按可见内容外接框动态计算，避免无限画布裁剪路径。

### 3.2 端点解析

每个端点解析为「点 + 出线方向」：

- 接实体端口：端口在卡片对应边中点，方向沿边法线向外。
- 自由坐标：直接用坐标；方向取指向另一端的方向。
- 混合端点（一实一空）同样按上述规则取控制点。

曲线控制距离取 `max(40, 两端直线距离 × 0.4)`；直线模式直接用两点连线。

### 3.3 选择与手柄

- 点击卡片选中实体；点击关系路径或标签选中关系。
- 选中实体：卡片描边高亮，四边中点显示连接点（10px 圆点）。
- 选中关系：路径加粗/高亮，两端显示端点手柄（10px 圆点）。
- 端点手柄无论当前端点是接实体还是自由，都可以拖：
  - 拖到实体上 → 接上最近端口；
  - 拖到某个连接点上 → 接该端口；
  - 拖到空白 → 变成自由坐标。
- 自连（两端接同一实体）拒绝，提示「暂不支持自连」，并取消本次操作。

### 3.4 移动

- 拖实体卡片本体 = 移动实体。
- 拖自由线的线身 = 整条平移。
- 拖半连接线的线身 = 只移动自由端。
- 拖已连接线的线身 = 不移动（选择即可）。
- 拖空白画布 = 平移视口。

### 3.5 对齐吸附

- 移动实体时，与其他已放置实体的左/中/右、上/中/下比较。
- 阈值 6 屏幕像素（按当前 zoom 换算成世界坐标）。
- 吸附时显示贯穿视口的参考线；松手隐藏。
- 参考线不进导出。

### 3.6 缩放与平移

- 滚轮以指针为中心**平滑**缩放（每格 ×1.1），范围 25%–300%。
- 工具栏 `− / +` 每次固定 **±10 个百分点**（Word/Excel 手感）；到 25%/300% 对应按钮禁用。
- 百分比显示可点击，弹出档位 25/50/75/100/125/150/200/300；另有 100% 回正和「适应内容」。
- 适应内容：以所有可见对象的外接框加 60px 留白计算。
- 视口随自动保存持久化。

### 3.7 空状态

- 完全没有任何对象：画布中央提示「在左栏新建根对象，或把左栏节点拖到这里」。
- 有对象但没有任何可见内容（无已放置实体、无可见关系）：提示「把左栏节点拖到这里生成实例」。
- 空状态不参与 PNG 导出。

## 四、创建与编辑手势

### 4.1 实体

- **建实例**：拖实体行到画布 → 子实体，落点为卡片中心，自动选中并进入改名。
- **放本体**：`Ctrl+拖` / 行菜单「放到画布」→ 该实体本身放到落点/视口中央。
- **移动**：拖卡片本体，带对齐吸附。
- **改名**：双击卡片或右栏名字输入框。
- **删除**：选中后 `Delete` / `Backspace`，或右栏删除按钮。

### 4.2 关系

三条路径，底层共用同一套端点与待连线状态：

1. **连接点拉线**：从实体四边连接点按下，拖到目标实体/目标端口 → 两端接实体。
2. **拖关系行**：
   - 拖到实体/端口 → 生成半连接线，自由端沿最近端口法线向外 120px，然后拖自由端手柄去接头。
   - 拖到空白 → 生成自由线，两端都能拖。
3. **先选关系再拉线**：点击关系行（或开始拖它）进入待连线状态，然后从任意连接点拖出，直接使用该关系；松在实体上两端接，松在空白则半连接。

### 4.3 待连线状态

- 点击任意关系行 → 选中并设为「下一条线使用的关系」（待用）。
- **左树该关系行高亮就是待用状态**，工具栏不再显示单独的「当前关系」chip。
- 点画布上的关系线也会设为待用，左树对应行随之高亮；点实体/空白不改变待用状态。
- 在待用状态下，从连接点拖出的新线直接使用该关系作为原型，不再弹选择菜单。
- 新建一条线后，**待用关系仍留在原来那条关系上**，避免连续画线时越挂越深；新线只是被选中。
- 再点一次左树中当前待用的关系行 → 取消待用（保留选中）并 toast「下次拖线会先选择关系类型」；`Esc` 也可取消；删除当前待用关系时清除。
- 取消后从连接点拖线，先弹关系选择菜单。

### 4.4 未指定关系时

- 从连接点拖出、松手时若没有待用关系，在松手位置弹一个小菜单：
  - 关系定义（无端点）排前面，然后其他已放置关系；
  - 末尾「默认样式」。
- 选一个 → 以它为原型创建；选「默认样式」→ 创建 `prototypeId: null` 的根关系，使用内置默认样式。
- 菜单取消 → 不创建。
- 菜单里的选择只作用于本次创建，不改变待用关系状态。

### 4.5 端点改接

- 选中关系后拖任一端点手柄：
  - 靠近实体/端口时高亮目标，松手接上；
  - 松在空白 → 该端变自由坐标。
- 改接后原型、样式、标签不变。

### 4.6 快捷键

| 键 | 行为 |
|---|---|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| `Delete` / `Backspace` | 删除选中对象 |
| `Esc` | 取消当前连线/端点拖动；清除待连线状态；取消改名 |
| `Enter` | 提交改名 |
| 双击卡片 | 改名 |

焦点在 `input / textarea / select / contenteditable` 内时不触发画布快捷键。

## 五、右栏：统一属性面板

任何对象选中后共用一套面板。

### 5.1 公共部分

- 名字：
  - 实体：必填输入框。
  - 关系：标签输入框；为空时占位提示「继承自 捕食」。
- 原型下拉：
  - 「无（根）」+ 同类别候选；
  - 排除自己和后代；
  - 显示类似缩进/层级提示。
- 实时预览：实体小卡片 / 关系小线段 + 标签。
- 子对象计数：`N 个子对象`，并注明其中多少个已放置。
- 「＋ 子对象」按钮。
- 删除按钮；被引用时禁用并提示。

### 5.2 样式编辑

每个属性一行：

```
填充    [色块] #ffffff    继承自 物种
形状    [圆角|直角|胶囊]    覆盖         ↺
```

- 当前值显示解析后的结果。
- 来源显示「默认」/「继承自 X」/「覆盖」。
- 修改控件 → 写入当前对象的 `style`。
- `↺` → 删除该键，恢复继承。
- 只对修改过的属性显示 `↺`。
- 颜色采用 8 个站点相容预设 + 原生取色器：`#ffffff`、`#f3f4f6`、`#6b7280`、`#111827`、`#5b8def`、`#059669`、`#d97706`、`#dc2626`。

实体属性：形状、填充、边框、文字色。

关系属性：颜色、实线/虚线、箭头（终点/两端/无）、曲线/直线、显示标签。

### 5.3 放置与端点

- 实体未放置：显示「放到画布」。
- 实体已放置：显示「从画布移除」。
- 关系无几何：显示「未放置」+「放到画布」。
- 关系有几何：显示两端状态（`虎 · right` / `自由`），提供「反向」、「从画布移除」。
- 反向：交换 `a` / `b` 及其端口/坐标。

## 六、数据操作与约束

### 6.1 删除

**实体：**

1. 若任意实体或关系的 `prototypeId` 指向它 → 禁止，提示引用数。
2. 找出所有端点为该实体的关系（含半连接线）。
3. 若其中任一条关系又被别的对象当作原型引用 → 整个删除禁止，提示先处理该关系。
4. 否则删除该实体，并连带删除第 2 步找到的关系。

**关系：**

1. 若任意关系的 `prototypeId` 指向它 → 禁止，提示引用数。
2. 否则删除。

- 删除可用撤销恢复。
- 连带删除时用 toast 说明 `删除了实体及 N 条关系`。

### 6.2 原型链校验

- `prototypeId` 必须同类别。
- 不允许自指或成环。
- 右栏下拉和导入校验都执行同一套检查。

### 6.3 撤销 / 重做

- 快照保存 `name / entities / relations`，不含 `viewport`、选中态、待连线状态。
- 一次拖拽 = 一步；一次放置/移除 = 一步；一次样式控件改动 = 一步。
- 名字输入 500ms 防抖合并，失焦立即提交。
- 上限 100 步。
- 导入、新建、删除、放置、改父级都可撤销。
- 撤销后若选中的对象已不存在，清空选中；若存在则保留。

### 6.4 自动保存

- `localStorage` 键：`relation_graph_v1`。
- 任何模型变化 300ms 防抖保存；`pagehide` 强制落盘。
- 读取时校验；失败时把原始内容备份到 `relation_graph_v1_broken_<时间戳>`，以空图启动并 toast 提示。
- 保存失败（如配额）toast，但不阻断继续编辑。

### 6.5 JSON 导入导出

导出：完整文档（含 `viewport`），格式化 JSON，文件名 `关系图-<图名>-YYYYMMDD.json`。

导入校验：

- `schemaVersion === 1`
- `entities` / `relations` 是数组；ID 唯一
- `prototypeId` 同类别、存在、无环
- 端点要么两端都有，要么都没有；接实体的端点必须指向存在的实体；`port` 合法；自由坐标是有限数字
- `style` 键在允许集合内、值类型/枚举合法
- `viewport` 数值合法

任何一条失败 → 整份拒绝，不覆盖当前图，提示第一个错误。

导入成功 → 替换模型，已有历史保留（导入本身是一步，可撤销）；视口优先用导入的 `viewport`。

### 6.6 PNG 导出

- 范围：所有已放置实体 + 所有可见关系 + 标签，外接框留白 40。
- 2 倍像素，浅色实底背景；不含点阵、选中态、连接点、端点手柄、参考线、空状态提示。
- 沿用字符作画的 `foreignObject` 方案：克隆世界层、内联样式、光栅化。
- 文件名 `关系图-<图名>-YYYYMMDD.png`。
- 没有可见内容时提示，不生成空图。

## 八、技术实现

### 8.1 文件

```
关系图/
  关系图.html
  关系图.css
  model.js          # 纯数据层，不碰 DOM
  关系图.js         # 渲染、交互、历史、持久化

```

- 原生 JS，无构建、无 npm、无 package.json。

### 8.2 分层

**model.js：**

- 样式解析（默认 → 链 → 自身）
- 关系标签解析
- 原型链查找与环检测
- 增加/删除/改父级/放置/移除
- 关系端点操作
- 导入校验
- 删除规则检查

**关系图.js：**

- 左树渲染与展开状态

### 8.3 渲染细节

- 关系箭头用 `<marker>`，按解析后的颜色生成/复用；箭头两端按 `arrow` 模式设置。

## 附录：关键决策

| 决策 | 理由 |
|---|---|
| 目录/页面叫「关系图」 | 直白、好搜；进化、科技树、食物链都能装下 |
| 单图 + 自动保存 + JSON | 先把编辑器做好，多图管理后置 |
| DOM 卡片 + SVG 连线 | 卡片富样式自由；连线/箭头用 SVG；PNG 走 foreignObject |
| 实体/关系统一指针模型 | 没有类型/实例的二分；任何对象都能作原型、都能覆盖 |
| 位置/端点可选 | 未放置对象只存在于左树，天然成为「定义」 |
| 关系端点可为自由坐标 | 支持自由线与半连接线，消掉「线必须接头」的例外 |
| 默认拖=建子对象，Ctrl+拖=操作本体 | 保留「拖类型生成实例」的主手感，同时允许把原型本身放到画布 |
| 左树/画布选关系=下一条线待用；左树高亮即状态 | 连续画同类关系快；去掉工具栏 chip 后由左树高亮表达，二次点击可取消；新建后待用状态不跟着新线走，避免原型链越挂越深 |
| 缩放按钮 ±10 个百分点，滚轮平滑 | 用户要求 doc/excel 式手感；按钮步长可预期，滚轮保留连续缩放 |
| 名称提交只就地更新，不整体重绘 | blur 中整体重绘会替换 DOM，吞掉紧接着的 click；就地更新树/卡片/边/右栏 |
| ID 正则校验 + 转义 + 不拼选择器 | 导入文档的 ID 可能含引号/尖括号；防 HTML 注入和非法选择器 |
| 删除被引用对象时禁止 | 避免静默破坏原型链；级联/提升留到后续 |
| 撤销用整份快照 | 图规模小，快照简单可靠；拖拽合并成一步 |
| `width:'auto'` 是可继承的规则 | 子节点继承规则后按自己的名字算宽，而不是复制父节点的测量值；固定数字与 auto 互斥 |
| 等距溢出自动撑开 | 总尺寸超过首尾跨度时归零间距、末张外移，避免负间距重叠 |
| 本页资源带 `?v=YYMMDD` + `MODEL_VERSION` 握手 | 防止浏览器缓存混用旧 model.js 与新 app，导致 NaN/本地数据损坏；保存前再校验 |

- 关系图页无 console error / pageerror / 404

### 踩过的坑与修正

1. **名称 blur 中整体重绘会吞掉下一次 click**：`mousedown` 的 blur 里 `renderAll()` 替换了树/inspector DOM，mouseup 后的 click 落空。改为提交时只更新模型 + 就地刷新树标签/卡片名/SVG 标签/右栏输入，不替换 DOM；行内改名同样处理。
2. **`hasEdited` 门控会丢正在输入的文字**：实时输入只改模型、未置位，关页时被门控跳过。改为两个 input 处理器先置位再 `scheduleSave()`；坏档备份成功后移除主键，避免空图立刻写回。
3. **导入 ID 注入/非法选择器**：ID 只校验前缀时，带引号/尖括号的 id 会进入 HTML 或 `querySelector`。改为 ID 正则（`^n_…$` / `^r_…$`）+ 树属性转义 + 按 `dataset.id` 遍历匹配，不拼选择器。
4. **行内改名后右栏名字陈旧**：不整体重绘后，右栏仍显示旧值，后续编辑可能把改名覆盖回去。新增就地同步 `[data-field="name"][data-obj-id]`。
5. **连接点/端点手柄被卡片盖住**：单层 SVG 在卡片下方。改为边/标签一层、卡片中间、手柄/参考线/橡皮筋独立上层 SVG。
6. **SVG 外接框漏自由端点**：只按卡片框计算会裁掉自由线。bbox 合并自由端点；命中路径用 `pointer-events: stroke`。
7. **用户反馈缩放步长随缩放变化**：由 ×1.1 等比按钮改为固定 ±10 个百分点；百分比可点选档位；滚轮保留平滑缩放。
8. **用户反馈工具栏「当前关系」chip 不清楚**：移除 chip，改用左树关系行高亮表达待用状态；二次点击取消并 toast；点画布上的线同步高亮左树行。
