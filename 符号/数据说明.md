# 符号页 · 数据说明

面向要改 `符号/` 下数据文件的人。**改数据前先读第三节（组键）与第六节（坑）。**

---

## 一、文件一览（谁权威）

| 文件 | 角色 | 权威性 |
|---|---|---|
| `标签.json` | 语义树（`roots → children`）：成员 `ranges`/`seqs`、`alias`、`intro`、`code`/`src` | **唯一权威**（成员归属只认它） |
| `中文名.json` | `{_v, names:[[cp,name]…], patterns}`，**按码点升序**；全局通用名 | 名字兜底层 |
| `符号数据.js` | `const SYMBOLS = [...]`，富化条目（语境名/英文名/别名/简介） | 名字/简介的富化层 |
| `序列别名.json`、`noto-cmap.json`、`ucd-*.json`、`zh-*.json` | 辅助数据（序列别名、字形覆盖、UCD 派生表等） | 只读参考 |
| `参考资料/` | Unicode 官方数据（UnicodeData.txt、Blocks.txt…） | 只读参考 |
| `dev_server.py` | 编辑保存服务（页面 → `POST /symbol-api/save` → 落盘） | 写入通道 |

## 二、SYMBOLS 条目结构

```js
{"char":"♂","groups":{"性别、婚姻":{"name":"男性、雄性","alias":["Mars"]},
                      "天文、太空、宇宙":{"name":"火星","alias":["男性符号"]}},
 "intro":"…","mode":"dual"}
```

- `char`：字符（可为多码位 ZWJ 序列）。
- `groups`：**键 = 标签名**（外连 id），值 = `{name 语境名, alias 别名[]}`；一个字符可以有多个组（=多标签语境下各叫各名）。
  注意上面例子里的 `alias` 是**文件里存着的**，只属于那一个组。**界面上显示的别名比这多**——还会并上其他组的主名（虚拟合并，不落盘），见第四节。
- `intro` / `mode`：简介 / 双码位序列标记。
- **条目里没有英文名字段**。英文名的来源分工：
  - **单码位** → 一律 `nameOf(cp)` 读 `ucd-names.json`（Unicode 官方名）。SYMBOLS 里不存英文名。
  - **ZWJ 序列（多码位）** → `标签.json` 对应 `seqs` 里的末项（`SEQ_INDEX` 的 `en`）。
  - 与官方名**真正不同**的英文俗称（CLDR 短名如 `Grinning Face With Big Eyes`、按键名 `Escape`、卢恩名 `Raidho`）写进该组的 `alias`，只当搜索词。只是官方名截短的（`Dollar` vs `DOLLAR SIGN`）不写——搜索通道会匹配官方名，`dollar` 照样命中。
  - 历史：`ename` 曾挂在每个组上，删组会连英文名一起丢，v1.26.0 起废弃。
- 文件格式：第一行 `const SYMBOLS = [`，每组条目**一行** `\t{...},`，最后一行 `];`（**末条不带逗号**）。手工追加条目时不要漏逗号。

## 三、组键（groups 的键）——最容易踩的地方

**是什么**：组键是这组名字的「容器名 + 外连 id」，指明**这组名字属于哪个标签**。

**谁在用它**（渲染不读键，但下面三处读）：
1. **语境名渲染**：`符号.js` 的 `zhNameIn(cp, tagName)` 用「当前选中标签名」去匹配组键，匹配到才显示该组名。
2. **序列联动**：改一个肤色/旗帜序列的名字或别名时，兄弟条目按「当前组键」写入同一容器。
3. **工具脚本**：`dedupe_symbols.py` 等按**组名**取数/合并。

**硬约束**：
- **组键必须是现存标签名**。键指向的标签若不含该符号（或标签已被改名/删除），该语境名**永远显示不出来**，且**静默回退**到全局名，不报错。
- 机械轴（`文字系统` / `官方分类` / `区块` / `emoji（绘文字）`）**不作组键**；新建条目取"首个非机械轴标签"名，一个都没有才落兜底键 **`编辑`**（纯容器名，界面上不可见）。
- **标签改名会自动同步组键**（`dev_server.py` 的 `tag_meta()` → `sync_symbol_group_keys()`，含撞键合并）。但**手工直接编辑数据文件时，程序不会兜**——改标签名要自己把 `符号数据.js` 里的同名组键一起改。

**体检**：改完数据跑一次
```bash
python 符号/check_group_keys.py     # 列出"不可达组键"（键不是标签名，或该标签不含对应符号）
```
输出为空即健康（`编辑` 属兜底键，会单独归为"提示"）。

## 四、名字的权威层次与显示规则

| 场景 | 显示名链 |
|---|---|
| **标签视图**（选中某标签） | 该标签的组名 → **全局名** → `中文名.json` → 分类兜底（未分配码点/私用区/控制字符） |
| **全局视图**（搜索、无标签浏览） | **全局名** → `中文名.json` → 同上兜底 |

- **全局名**（`符号.js` 的 `joinGroupNames` 算出，不落盘）= 该符号**各组语境名按组序去重后以「、」拼接**。
  例：♂ 的组是 `性别、婚姻="男性、雄性"` + `天文、太空、宇宙="火星"` → 全局名 `男性、雄性、火星`。
  所以拆语境名不影响全局名；要改全局名就改对应的语境名。
- **首组名** = `groups` 里第一个组的 `name`（对象键顺序）。**它的内容仍会被搜到**（搜索匹配全部组名），只是不再决定全局显示名。
- **祖先标签视图会回退到全局名**：只有"该符号真挂了组"的那个标签才显示语境名。例如 ♂ 有 `性别、婚姻` / `天文、太空、宇宙` 两组，点上级的「人」就显示全局名。
- **组名之间不要互相嵌套**（如 `厕所` 与 `厕所/洗手间`）——那样全局名会拼出两个近乎重复的名字；发现就统一成一个。
- **别名**：语境下 = 本组 `alias` ∪ **其他组的 name**（**虚拟合并**，用于展示与搜索，**不写回文件**）；全局下 = 该字符各组合并的 `aliases`。
- **编辑规则**：在某标签下改名/改别名，**只写该标签对应的组**；其他组不动。挂标签**不建空组**——只有在某标签下起过名，才会有那个组。

## 五、编辑保存链路（页面 → 文件）

页面把改动 POST 到 `/symbol-api/save`，由 `dev_server.py` 落盘（`action` 见其文件头注释）：

- `add` / `move` / `remove` → `标签.json`（成员增/移/取消打标）
- `tag`（改名/别名/简介） → `标签.json`；**改名时另同步 `符号数据.js` 同名组键**
- `tag-new` / `tag-del` / `tag-sort` / `tag-reparent` → `标签.json`
- `sym`（符号名/别名/简介） → 字符已在 `SYMBOLS` → 写 `符号数据.js`；否则写 `中文名.json`
- 三大机械轴（`文字系统`/`官方分类`/`区块`）**禁止修改**

## 六、常见坑

1. **改标签名不同步组键** → 组键变成"历史快照"，语境名失效（页面改走服务端已兜；手工改文件不兜）。
2. **把语境名当全局名**：全局权威仍是 `SYMBOLS` 首组名，`中文名.json` 只是兜底。
3. **组键写成不存在的标签名** → 语境名静默失效（跑 `check_group_keys.py` 可查）。
4. **`中文名.json` 必须保持码点升序**（页面用二分查找），插入用 `dev_server.py` 的 `zhname_set()` 或自行二分。
5. **`符号数据.js` 行格式**：每条一行、除末条外结尾带逗号；批量脚本改完务必跑 `node --check 符号/符号数据.js`。
