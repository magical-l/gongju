规律归纳

writing-mode inline轴 block轴 grid-auto-flow: row grid-auto-flow: column
horizontal-tb 横向 纵向 横向填充 纵向填充
vertical-rl/lr 纵向 横向 纵向填充 横向填充

核心规律：
grid-auto-flow: row = 先沿 inline 轴填充
grid-auto-flow: column = 先沿 block 轴填充
writing-mode 决定 inline/block 轴的物理方向
justify-content 控制主轴（inline轴方向）
align-items 控制交叉轴（block轴方向）
