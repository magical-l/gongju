# 字符作画 · 阶段 1 风格统一 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `字符作画/字符作画.html` 从全屏 App 式页面改造为项目文档式页面：标准 header/footer 骨架 + 共享 CSS 栈 + 蓝主调小圆角视觉，同时拆分内联 JS/CSS 为独立文件，功能零丢失。

**Architecture:** 单一 HTML 文件重构为三文件（`.html` + `字符作画.css` + `字符作画.js`）。HTML 采用 `body.目字形` 布局 + 共享 CSS 栈；页面私有样式引入 common.css 的 CSS 变量与 `.btn`/`.modal` 组件；弹窗用 `.modal > .body`（biz.css 已定义卡片体）；反馈提示用 toastr 替换 `alert`。**阶段 1 不改任何交互逻辑**（旋转/图层/多选等留到阶段 2）。

**Tech Stack:** Vanilla JS（保留原生 DOM 架构）+ 共享 CSS（common.css / layout.css / biz.css）+ toastr。不引入 Vue/Element Plus。

## Global Constraints

- **不动画布交互逻辑**：阶段 1 只改外壳与视觉，`字符作画.js` 中所有函数、变量名、元素 ID 原样保留。
- **保留全部元素 ID**：`newSceneBtn / saveSceneBtn / loadSceneBtn / canvasSettingsBtn / undoBtn / redoBtn / clearCanvasBtn / helpBtn / sceneCanvas / canvasContainer / rightPanel / libraryPanel / propsPanel / emojiSymbolsContainer / normalSymbolsContainer / previewChar / copyCharBtn / sizeSlider / sizeValueDisplay / repeatSlider / repeatValueDisplay / colorControlArea / charColorPicker / raiseBtn / lowerBtn / deleteItemBtn / closePropsBtn`。
- **画布内容视觉不动**：场景默认渐变（`linear-gradient(145deg, #b2e0fa, #c5e0a4)`）、字符渲染方式、resize 手柄交互全部保留。
- **不修改 `lib/` 任何文件**；不新建 package.json/node_modules；不引 CDN 运行时依赖（共享 CSS 的 CDN 链接按项目惯例保留，本地 `../lib/css/*` 作注释 fallback）。
- **阶段 1 不含**：旋转、透明度、图层、方向键微调、多选、画布缩放（均为阶段 2）。
- 路径约定：`字符作画.html` 同目录下新建 `字符作画.css`、`字符作画.js`；资源引用用相对路径 `../lib/...`、`../resources/...`。
