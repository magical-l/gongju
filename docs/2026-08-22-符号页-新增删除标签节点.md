## 设计决策

- **新增**：`tag-new` 创建 `{children:{}}` 空节点（可选 alias）；页面校验空名/斜杠/兄弟撞名后服务器直写，成功才改内存。`标签.txt` 子节点插在父子树末尾（tab 缩进对齐）、新根追加文件末尾。
- **删除**：`tag-del` 删节点+子树。页面先 `ElMessageBox.confirm` 提示影响（成员数=collectNodeMembers 聚合 + 子标签数=countSubtreeNodes，空标签显示「空标签」），确认后才发服务器。删除选中标签后清空 selectedTag/selectedChar。
- **机械轴双保险**：页面 ✎ 对机械轴隐藏；服务器 `tag-new`/`tag-del` 二次拦截。
- **树不刷新 bug 的根因**：给父节点加子键后，父 TagTreeNode 的 props（node 对象引用）未变，Vue `shouldUpdateComponent` 浅比较判定无变化而跳过重渲染 → 新子节点不出现（改名能刷新是碰巧改了 key 触发重建）。修复：TagTreeNode 增加 `version` prop，根 v-for 传 `treeVersion`，递归透传；bump 时 props 变化级联重渲染，且保留组件 `open` 展开状态。
- **端口变更提示**：本次重启服务器从 18765 → 18766（18765 被旧实例占用）。用户浏览器连旧端口时旧服务器无 tag-new 动作 → 报「未知动作」。教训：改 dev_server.py 后重启服务器会换端口，页面需指向新 URL。
