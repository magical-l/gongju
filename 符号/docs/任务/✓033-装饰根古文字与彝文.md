于是改成**把渲染结果截成图，我自己看**：

1. 用 Playwright 在符号页里注入网格，字体栈取 `--sym-font-stack`
   （**必须与实际环境一致**，否则会像 `✓032` §3② 那样测出假的豆腐块）

## 3. 楔形/线形/彝文：官方名同样看不出形状

`CUNEIFORM SIGN A TIMES BAD`、`LINEAR B SYLLABLE B008 A`、`YI SYLLABLE IT`——
全是**音节值或部件组合**，不含外观描述。这三类只能人眼判，摆审阅页。

## 4. 审阅页的四个坑（这轮全踩了）

### ① 一次别给太多
楔形 922 摆成 3 页 × 360，用户审得动；彝文 1165 一次摆出来，用户
**"只审到了 U+A09F"** 就说「**你一次性不要搞那么多啊**」。
→ 改成**每批 120 个**。

### ② 页面必须报告「用户点开过哪几批」
默认口径是「**没勾 = 删除**」（2026-09-27 用户定）。但用户可能只审了前几批就提交，
**后面的一个都不能动**——否则会把没看过的东西判死。
做法：页面记 `seen`（点开过的批次），提交时把每批的码位范围一并发上来，
主代理**只落盘 seen 覆盖的范围**。

⚠️ 落盘要读**最后一条 `submit`**，不是最后一条事件——页面 `load` 时会发一条
`report('ready')`（勾选为空），用户刷新页面后它就成了最后一条。
（实测踩过：585 个差点被读成 0 个。）

⚠️ 刷新页面会清空**未提交**的勾选（只在内存里）；**已提交的**已经发到服务器，刷新不丢。

### ③ 服务器只给 `/` 路由注入 helper
`/files/<name>` 返回裸文件，里面没有 `window.brainstorm`。所以审阅页**不能拆成多个
HTML 靠 iframe 或链接切换**——必须做成**单页多标签**（切标签时重建 DOM，
一次只渲染一组，否则 1474 个卡片会把浏览器卡死）。

### ④ 服务器默认空闲 4 小时自停
启动时必须传 `--idle-timeout-minutes 4320`；Windows/Git Bash 下还要 `--background`
（脚本检测到 Git Bash 会回收 nohup 进程，转而前台运行，被后台任务生命周期带走）。
详见全局记忆 `brainstorm-server-pitfalls`。
