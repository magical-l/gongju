## 0. 一句话

`=` 是「**同一个字符的另一个叫法**」（不是官方名的改写）。2528 个码位 / 2729 条，**全是英文**——
所以只能当**搜索键**，当不了中文主名。先落英文，再给能译的配中文说法。

## 1. 料

| | 数 |
|---|---|
| NamesList 里带 `=` 的码位 | 2579 |
| 本库显示得出来的（有直译名） | **2528** |
| 别名条数 | 2729 |
| 其中**纯 ASCII** | 2612（含汉字 **0**） |

`=` 分两类，别混：
- **就是官方名本身**（控制符那批：`BACKSPACE`/`NULL`/`LINE FEED (LF)`）→ 零贡献，剔
- **另一个叫法**（`#` 的 `hashtag`/`octothorpe`、`!` 的 `factorial`/`bang`）→ **这才是主体**

## 2. 清洗规则（英文本）

1. 一条串塞多个说法的**按逗号拆开**（`hyphen, dash` → 两条）
2. **剥掉末尾括注**——那是解释不是名字（`pound sign (weight)` → `pound sign`；`registered trade mark sign (1.0)` → 去掉 `(1.0)`）
3. 剔**以 `the` 开头 / 含 `is`·`are` 谓语**的句子（`the use as decimal or thousands separator is locale dependent`）
4. 剔**与官方英文名同名**的（59 条）
5. 剔**已是别名**的（21 条）
6. 落盘后 `datatool` ④d 再抓**被直译名整段包含**的（61 条，如朝鲜语字母的罗马字 `N`/`R`/`M` 本就在「谚文终声NIEUN」里）→ 删

**结果：2387 个码位补了 2867 条英文别名。**

## 3. 中文说法（第二轮）

按 `数据说明.md` §七 那套打法：6 批子代理，每批产出「英文别名 → 中文说法」（判不译的写空串）。
**翻 1029 / 不译 1569**，落盘 **984 条中文别名 / 834 个码位**。

判「不译」的：外来专名（`milréis`/`Feuerwache`）、纯转写（`anusvara`/`tha`/`syllabic ta6`）、
**译文会等于或包含于直译名**的（`vertical bar`→竖线 对 直译名「竖线」）、碎片（带引号/落单括号）。

## 4. 顺带修的 3 条直译名

子代理翻译时撞出来的——它们按「中文读者真会搜的说法」给词，与直译名严重不符，一查是直译名的错：

| 码位 | 原直译名 | 现直译名 | 官方名 |
|---|---|---|---|
| 🥉 U+1F949 | 第三场所奖牌 | **第三名奖牌** | `THIRD PLACE MEDAL`（PLACE = 名次） |
| 🖋 U+1F58B | 左下喷泉笔 | **左下钢笔** | `LOWER LEFT FOUNTAIN PEN` |
| 🥂 U+1F942 | 碰杯眼镜 | **碰杯玻璃杯** | `CLINKING GLASSES`（跟 🍸`COCKTAIL GLASS`→鸡尾酒玻璃杯 同例） |

⚠️ 我一开始提的是把 🥉 改成「铜牌」——**那是错的**：直译名是官方名的**忠实直译**，
「铜牌」是俗称，本来就该留在别名里（它一直在）。

## 5. 试过一条"找直译名错译"的新判据——作废

这轮 `=` 的中文给了个交叉核对的角度：同一码位现在有**两条中文**（直译名 + `=` 中文），对不上就至少一条错。
拿「两者**零共同字**」筛，得 200 多条——**抽样看全是「同一个东西的不同叫法」，没有一条是错译**
（`!` 感叹号/阶乘、`` ` `` 抑音符/反引号、`¥` 元符号/人民币符号）。
更致命的是**反向也漏**：真错（🥉「第三场所奖牌」vs「铜牌」）**共享一个「牌」字，进不了这个筛子**。

**结论与 `·015` 一致：直译名的错没有自动化判据**，只能按官方名的构造族人工过（那条老路 `·015` 已扫过）。
**不开专轮。**

## 6. 教训

1. **清洗正则容易误伤真名字。** 我第一版把 `long i with left hook and tail`、`a-chung`、
   `PRIVATE USE ONE` 全误剔了（`^a\b` 撞了 `a-chung`、关键词 `use` 撞了 `PRIVATE USE ONE`）。
   收窄成「只剔 `^the` / 含 `is`·`are`」才对。
2. **提修改方案前先核"那一层是干什么的"。** 我把「铜牌」提成直译名的改法，忘了直译名必须忠实官方名。
3. **新判据要先小范围验证再铺开**——「零共同字」这条我按你说的先抽样 19 条，一眼就看出不成立，
   省下了一整轮。
