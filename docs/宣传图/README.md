# 宣传图（首页卡片缩略图）

首页每张卡片顶部那张图。**不是页面截图，是按「这个工具主要干嘛」画出来的示意图**——页面会改版，示意图不用跟着改。

## 画面约定

- **构图**：左「输入什么」→ 中箭头 → 右「出什么」
- **画布宽高比**：统一取 **1.566**（即 260 × 166）。两种常用尺寸：`780 × 498`（260×166 的 3×）或 `1000 × 637`。
  为什么约定的是"统一比例"而不是"某个体积正确的尺寸"：首页卡片图区 `.shot.box` 的**高度固定 190px（内容高度），宽度随视口和栅格列数变**
  （4 列；≤1180px 3 列；≤860px 2 列；≤560px 1 列），所以图区宽高比本身是浮动的（实测 900px 视口 1.19、1920px 视口 2.17）——没有哪个比例"对得上"。
  图是 `object-fit: contain` 等比缩进框内、不裁切，**因此唯一有意义的约定是：所有缩略图用同一个比例**，这样它们在任何视口下都渲染成同一大小。
  比例不一致的会先撞到宽度上限、显得更矮。2026-10-10 修的就是这个：`svg转图标.jpg` 原来是 1.786（当时按"图区=1000×560"的错判做的），在中等窗口下比 `数字转化`/`符号` 矮 20px。
  分类工具页的 7 张现已统一到 1.567。（`游戏/thumbnails/数字华容道.jpg` 是 0.998 的竖图，游戏区不走这套约定。）
- **配色**：画布底 `#eef0f7`（分类色紫苑 `#757cbb` 的极浅版）、主体 `#3d3f57`、强调 `#757cbb`。分类色与 `resources/home.css` 里的 `[data-cat]` 保持一致
- **铺满**：每个元素尽量撑开画面，不留大块空白
- **按卡片里显示多大定字号**：图在卡片里的显示宽度 = 图区宽度（约 260 ~ 414px，随视口）。换算就是
  **画布字号 × (显示宽度 ÷ 画布宽度) = 屏幕上多大**：画布 1000 宽、卡片里显示 300 宽时缩放 0.3，
  想让代码在卡片上约 9px，画布里就得写到约 30px（`svg转图标.html` 的 28px 就落在这个量级）。
  反过来，画布里 20px 的字落到卡片上只有 6px，等于看不清。
  这条约束会倒逼内容重排：`svg转图标.html` 的示例代码就是为了配合 ~28px 字号（每行只装约 30 字符）按短行重新断行过的。

### 变体：符号（2026-10-09）——不走「输入→箭头→输出」

`符号.html` 是另一路画法：**页面的缩小复刻**，因为符号这工具没有「输入输出」，它的卖点就是「字符多、按标签找得到」。

- **画布 260 × 166**（卡片图区净尺寸）**按 3× 渲染** = 780 × 498。字号不按上面那条倒推，直接把真实页面的尺寸照搬，再整体放大 3 倍——这样字距行距跟线上一致。
- **左栏**：标签树，80px 宽。选中「自然 / 生物 / 植物 / 花朵」，带父级、兄弟姐妹、叔伯。
  四个硬要求：窄、行铺满列高、**选中态不能把文字挤右**（用 `box-shadow: inset` 不用 `border-left`）、三角收展符保留。
  行尾**不列成员数**（用户要求）。
- **右栏**：5 × 5 网格。成员**从「花朵」标签里手挑、顺序手排**，照搬页面顺序没有意义——**网格是按码点顺序分页的**，一页往往只有一种文字，看不出「什么都有」。
- **取名字要走真实页面的顺序**：该标签子树里最深的已命名组 → 条目级主名 → 直译名。只查后两层会显示直译名。
- ⚠️ **不要给整块加 `font-variant-emoji: text`**。真实页面只把它加在「文本变体」那个小标签上（`.vs-text` / `.variant.text`），网格卡片是 `normal`——emoji 在网格里是**彩色**的。加错会做出一屏黑白 emoji。
- ⚠️ **墨迹比字号框大的字符**（如 `꧁ ꧂`，13px 字号画出 20px 墨迹）会顶出格子压到邻居。约定：**这种字符不进图**，别靠裁剪或缩小字号救——用户认为「字形溢出」本身会让访客以为是 bug。

### 变体：数字转化 / 文本转化（2026-10-10）——第三路：格式矩阵 + 右缘裁切

`数字转化.html`、`文本转化.html` 既不是「输入→箭头→输出」，也不是整页复刻。这两页的卖点都是
"一段输入，一次给出所有形式"，所以主体画成一版**格式卡阵**：

- **画布 260 × 166**（同 符号），按 3× 渲染 = 780 × 498。
- **顶部一个输入框**，里面是这次演示的输入 + 一根光标。没那根光标就认不出是输入框（曾因此被要求改）。
- **下面 3 列 × 3 行**格式卡。同类不并排、不同类混排，是为了"一眼看到信息多"：
  - 数字转化：汉语数字 / 大写汉语数字 / 汉语数码 → 十六进制（带「大写·小写」开关）/ 二进制 / 八进制 → 通讯读法 / 年份·编号 / 筛出数字
  - 文本转化：MD5 / Base64 编码 / SHA1 → URI 编码 / unicode 编码 / utf16 编码 → 十六进制编码 / 二进制编码 / gzip 压缩
  - **结果值必须是页面真实输出**。文本转化那张是把 `你好` 打进真页面、把 20 条结果读出来再挑的，不要凭印象编。
- **每张结果卡的标题栏右侧带一个小「复制」图标**（`.cp`，8.5px）。用一份 `<symbol id="cp">` + 若干 `<use>` 复用，不开 JS。
  真实页面是"点文本即复制"，缩略图里没有可点的地方，配个图标把"可复制"这个卖点说出来。
- **右侧不留内边距**，网格比画布宽，第 3 列被画布右缘裁掉一大半——暗示"格式还有更多，只截到这一部分"。
  这是**刻意**的，与"内容溢出被切"要区分开。
- **数字转化保留原文里的非数字字符**（`元`），否则看不出"文中数字"这个特性。
- **值放不下就用省略号**（`text-overflow: ellipsis`）。文本编码天生很长（MD5 固定 32 位），装不下的用 `…` 收尾，比右端淡出更明确。

⚠️ **两个"看起来像 bug 的裁切"，别踩：**

1. 卡片内容高度必须 ≤ 可用高度。`.grid` 用 `flex: 1` + `grid-template-rows: repeat(3, 1fr)` 撑满；
   若 9 张卡的自然高度超出可用高度，**最后一行会被底边切掉**。
2. `.v` 一旦开了 `overflow: hidden`，省略号的裁切基准就从"卡片边框"变成"内容框"——原本靠溢进内边距才显示完整的短值会被误截。
   （2026-10-10 数字转化的「一千二百三十四 元」就被截成了「一千二百三十四 …」。）**值装得下的那张别开省略号。**

### 变体：元素周期表（2026-10-10）——第四路：搬真实 DOM + 搬真实 CSS

`化学/元素周期表.html` 跟前三路都不同：**不重画、也不整页截图，而是把真实页面的 DOM 和 CSS 搬进一个临时页**，让浏览器自己渲。所有特效——金属炫光、气态虚线框＋蒸汽粒子、液态/固态状态边框、放射性图标、铁磁性磁力线、筛选半透明——**一个都不用抄，也不会抄漏**。

生成页放在 `tmp/` 下（`tmp/元素周期表-组装.html`），**不进版本库**：CSS 是从页面里复制来的，存档等于在仓库里放一份副本。

**做法：**

1. **CSS 原样搬** —— 脚本读 `化学/元素周期表.html`，把它 `<head>` 里那段含 `--period1-row-offset` 的内联 `<style>`（约 17.8 KB）整段复制过来，**一字不改**。
2. **DOM 原样搬** —— 先在真实页面上把温度设成 **1904 ℃**、勾上 **碱金属 + 过渡金属**，再抠这些节点的 `outerHTML`（去注释）：
   - 第 1~7 周期、前列的元素格（连同 `vapor` 里 8 个粒子、`辐射-icon`、`人造-icon`、磁力线 SVG、内联底色与 opacity）
   - 详情卡 `.element.detail.area` —— 它**不是浮层，是 article 里的一个 grid item**（CSS 定位成 `grid-column: 4/14`、`grid-row: 1/4`）
   - 「镧系标签」「锕系标签」两个占位格（保持收起状态）
3. **外层画布**（唯一新写的部分）—— 260×166、`zoom: 3`、左侧竖温度计＋筛选栏、右侧一个 **208×158 裁切窗口**。
4. **裁切** —— `article { zoom: 0.308 }`（每格约 24px）；`main` 要撑到 `width: 1200px`，否则 article 的 bisque 底色会被窗口宽度限死、右边和下边露白；`left: 0`（左沿靠「周期序号」那一列当边距，把里面的数字 `display: none` 藏掉）；`top: -2px`。

⚠️ **两个变量必须显式补**：`--period1-row-offset: 0` 和 `--element-gap: 8px`。真实页面把它们定义在 `body > main` 上，而这里的 `main` 在裁切窗口里、继承不到，会走回退值——行距一压，跨 3 行的详情卡就矮 8px、「活泼非金属」标签从卡片下沿冒出来。**别为了多塞一列去改小 `--element-gap`**，报应就在详情卡上。

⚠️ **两处有意偏离页面**：① 碱金属 5 格（锂/钠/钾/铷/铯）去掉内联 `opacity: 0.5`——抠图那次碱金属没勾选，但它们在当前筛选里是选中的；② `.element.detail.card .tag.list { transform: translateY(-8px) }` 把标签条上提几像素（原位置几乎贴卡片下沿；用 `margin-bottom` 没用，卡片是 flex column + `justify-content: normal`，标签排在正文之后，加下边距只会让内容更高、位置不动）。

### 变体：拼音（2026-10-10）——还是第四路，但宿主页没有内联 `<style>`

`拼音/拼音.html` 走的是同一条路（搬真实 DOM + 搬真实 CSS），两处与元素周期表不同：**页面没有内联 `<style>`**，样式全在 8 个外链表里；**页面内容不在 HTML 里**，是 Vue 读同目录几个 JSON 渲染出来的，所以只能从「渲染后的真页面」抠 `outerHTML`。

生成页 `tmp/拼音-组装.html`（脚本 `tmp/build.py` 可重跑），**不进版本库**。

**做法：**

1. **CSS 照抄 `<link>`** —— 8 张表原样列上（`element-plus/index.css`、`el-plus.css`、`toastr.min.css`、`common.css`、`layout.css`、`biz.css`、`花活.css`、页面自己的 `拼音.css`），一张不改，也不用复制成段。
2. **DOM 从真页面抠** —— 在真页面上先点出要演示的音节，再抠 `main` 的 `outerHTML`，去注释。**抠之前必须先去掉 `[v-cloak]` 属性**（见下）。
3. **外层只新写三样**：`260 × 166` 画布（`zoom: 3`）+ 一个普通块容器 `.page` + 一段 `<style>`。`.page` 给 `width: 1200px`，里面直接是搬来的 `<main>`。
4. **裁切**：`.page { zoom: 0.395; left: -293.2px; top: -80px }`。左沿正好落在声母按钮 `d` 的左边界（第 1~3 行的按钮同一起点，一条竖线切下来是齐的），右沿把韵母的 `e` 切掉约 4 成，下沿让第四行**声调**露出约 9 成、只削掉一点点。

**演示的状态**：先在真页面点 **ch + ang + ˊ → cháng**，出来 ✔️ + 「卷舌」「后鼻音」两枚标签——一次把「拼读」「正误判定」「声母/韵母特征」三件事都摆上。抠 DOM 时那个 ❓/✔️ 是渲染结果的一部分，不用自己写。

⚠️ **`[v-cloak]` 必须摘掉**。`common.css` 第 63 行有一条 `[v-cloak] { display: none !important }`（原意是防未编译的模板闪现），真页面上 Vue 挂载后自己摘了；静态副本里没人摘，整个 `<article>` 会一片空白。

⚠️ **别用 `.反叵字形` 网格去复刻宿主布局**。真实页面是 `body.反叵字形` 的两栏网格（`main` + 右 `aside`），但把 `aside` 换成空列后轨道尺寸会变（`aside` 的 max-content 在副本里是 300px 而不是真页面的 150px），`main` 落到 980px 而不是 1200px —— 键盘每行两个 group 之间那 200px 的空隙就没了，整张图一眼能看出是假的。**直接给 `main` 一个 1200px 宽的普通块容器**（= 真页面 1280 视口下 `main` 的宽度）就复现了。

⚠️ **`.page` 自己的 `zoom` 会把它的 `left` / `top` 再乘一次**。`left: -293.2px` 在 `zoom: 0.395` 下实际只位移 115.8 画布 px（Chrome 的行为：元素的自身 zoom 也缩放它相对包含块的偏移）。调位置时要把这个因子算进去，否则会「改 200px 只动了 80px」。

⚠️ **窗口的高度是三条边里最紧的一条，`top` 怎么取决定了「露出多少键盘最后一行的行」。** `article` 高 450，窗口只有 166 个画布 px，`zoom: 0.395` 折算下来一次只能装下约 420 页 px —— 从「显示区」的顶到第四行按钮的底一共 445 页 px，**竖着必然要切掉约 25px**，这 25px 全从上面省（切进白卡一点）还是全从下面省（少露一截声调行），是个取舍。这里选择切上面：**声调行露出约 9 成**，下沿只削掉一点点。

⚠️ **`zoom` 再调小会顺手废掉右沿的裁切**。键盘右侧每组按钮的节距是 70px（按钮 60 + 间隙 10），而窗口宽 = `260 / zoom`。`zoom: 0.395` 时窗口宽 658px，右沿正好落在韵母 `e`（917~977）的中段；`zoom: 0.38` 时窗口宽 684px，右沿跑到 977 —— 刚好压在 `e` 的右边界上，切不到了，整列变成「完整按钮贴边」。**想再缩小内容，得连着把 `left` 一起往右推**（但 `left` 最多推到约 313，再往右就切到算式左边那个「声母」字了）。

### 游戏（2026-10-10）——另一套约定：把游戏玩到中盘，截棋盘本身

游戏卡片跟上面几路都不一样：**不画示意图、也不裁界面，而是把游戏跑出一局面，直接截棋盘元素**（`2048蛇` / `2048方块` / `数字华容道` / `中国象棋` 四张就是这个路子，后来补的 `2048` / `贪吃蛇` / `俄罗斯方块` 照它做）。

**尺寸规则和工具页不同，不用统一比例。** 游戏卡片图区 `.shot.box` 同样是 190px 高（内容 166），但游戏棋盘都比 1.567 窄，所以**一张都撞不到宽度上限，全是高度受限**——都渲染成 166 高，宽度随各自棋盘比例变（实测 1280 视口下：中国象棋 186、贪吃蛇/2048/数字华容道 191、2048方块 130、俄罗斯方块 99）。既然高度天然一致，**游戏这边只要保证渲染出来是 166 高就行，不必把比例对齐**。

**出图三步：**

1. **先把游戏弄出一局像样的局面。** 三个游戏的做法各不相同：
   - `2048` —— 有存档，键是 `2048-game-state`（格式见 `游戏/2048/logic.js` 的 `serializeGameState`：`board` 是 `width×height` 的一维数组，空位是 `0`，格子值是数字）。写一份进去即可。
   - `贪吃蛇` —— 也有存档，键 `snake-game-state`（`snake` 是 `{x,y}` 数组、**头在 `[0]`**，`food` 是 `{x,y}`）。
   - `俄罗斯方块` —— **没有存档**，只能操作 Vue 组件实例：`document.querySelector('main > article').__vue_app__._instance.proxy`，先 `p.startGame()`，再把 `p.grid`（20 行 × 10 列，格值是 `'I' 'O' 'T' 'J' 'L' 'S' 'Z'` 或 `0`）和 `p.player = {tetromino:{shape,color}, pos:{x,y}}` 直接赋值。
2. **截棋盘元素。** 给棋盘元素加一句 `style.zoom = '2.27'`（按「目标 760 宽 ÷ 棋盘实际宽度」算）再 `locator.screenshot()`，最后缩到 760 宽。棋盘是 CSS 网格，`zoom` 是矢量重排、不糊。
3. 存到该游戏目录的 `thumbnails/`：`游戏/2048/`、`游戏/贪吃蛇/` 各自一份；**页面直接在 `游戏/` 根目录的（俄罗斯方块、点灯）共用 `游戏/thumbnails/`**。

⚠️ **开局都有暂停覆盖层，得关掉。** `贪吃蛇` 和 `俄罗斯方块` 一进来 `isPaused = true`，棋盘上盖着「准备就绪 / 按空格或点击以开始」。**直接改状态位 `proxy.isPaused = false`，别去调 `togglePause()`** —— 后者会顺手 `startGameLoop()` / `requestAnimationFrame`，棋盘当场就跑起来了。`俄罗斯方块` 的 `startGame()` 自己也会把 `isPaused` 设回 `true`，要在它之后再改。

⚠️ **`2048` 的方向键按不动，不是 bug 是守卫。** `resources/game-keys-area.js` 的 `shouldHandle(e)` 要求 keydown 的 `target` 落在 `.gaming.area` 里；`page.keyboard.press` 打到 `body` 上会被直接忽略（`page.click('body')` 也没用）。两条路：调 `window.Game2048.move('left'|'right'|'up'|'down')`，或往 `.gaming.area` 里某个元素派发合成 `keydown`。

⚠️ **想写存档，不能直接 `localStorage.setItem` 再 `goto`。** 页面 `beforeunload` 会 `saveState()` 把当前局面覆盖回去。用 `page.addInitScript()` —— 它在**新文档的脚本之前**跑，正好压过旧页面的最后一次保存。

⚠️ **别指望自动玩出好看的棋盘。** 贪吃蛇/俄罗斯方块都不是「随便下下就行」：贪吃蛇得手工给一条像样的蛇形路径（我试过一个 45 节的折线，见下）；俄罗斯方块用启发式自动摆出来的盘面要么堆得太矮、要么一边高一边空。**俄罗斯方块最后是手工写了一版盘面**（底部 11 行铺满 10 列、顶面呈台阶状、颜色呈斜向色带），因为自动玩的形态一直不够稳。

## 怎么出图

1. 起本地静态服务（`python -m http.server`），浏览器打开本目录下的 `<工具名>.html`
2. 用 Playwright 截图。**视口要开得比画布大**（如 `1240 × 820`），再按画布区域 `clip` 裁：

   ```js
   await page.setViewportSize({ width: 1240, height: 820 });
   const b = await page.evaluate(() => {
     const r = document.body.getBoundingClientRect();
     return [Math.round(r.x), Math.round(r.y), Math.round(r.width), Math.round(r.height)];
   });
   await page.screenshot({ path: 'shot.png', clip: { x: b[0], y: b[1], width: b[2], height: b[3] } });
   ```

   **不能直接用视口尺寸截图**：Playwright MCP 会在视口右下角画一个实例角标，它会被截进图片、又不在 DOM 里删不掉。放大视口后裁剪就能把它落在框外。

   整页就是画布的文件（`符号.html`、`数字转化.html` 对 `.thumb`，`svg转图标.html` 对 `body`）可以直接对元素截图，
   省掉裁剪，也避开了 `page.screenshot({ clip })` 在这套 MCP 上偶发的超时 / 尺寸错乱：

   ```js
   await page.locator('.thumb').screenshot({ path: 'shot.png' });
   ```

3. 用 Pillow 缩到宽 760、存 JPEG 到该工具所在目录的 `thumbnails/`：

   ```python
   from PIL import Image
   im = Image.open('shot.png').convert('RGB')
   im = im.resize((760, round(im.height * 760 / im.width)), Image.LANCZOS)
   im.save('编解码/thumbnails/svg转图标.jpg', 'JPEG', quality=86, optimize=True, progressive=True)
   ```

4. 在 `resources/tools.js` 填 `thumb` 字段、在 `index.html` 把图标占位换成 `<img class="tool thumb">`
