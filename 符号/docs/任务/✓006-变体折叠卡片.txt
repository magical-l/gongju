验收标准：同款不同肤色的 ZWJ 序列在网格 / 概览 / 搜索里折叠成一张卡；分页与计数按卡算。

实施（2026-08-28）
	网格 / 概览 / 搜索把「同款不同肤色」的 ZWJ 序列折叠成一张卡（主符号 + 肤色变体下拉），消除笛卡尔积平铺冗余（人 / 职业 348 → 60 卡）。
	分组键 = 去肤色码位；性别不折叠（男 / 女 / 中性各自成卡）；单成员组无按钮；旗帜 / 单码位不折叠
	卡片 main = 无肤色成员优先（无则取第一个）
	卡片下方「肤色变体 ▾ N」按钮 → dropdown 列全部变体（略小卡），点选进详情、点外部关闭
	分页 / 计数按卡；搜索 main 优先取命中变体；数据文件零改动

后续修正（v1.37.0）
	原实现是 members.find(命中 preferKeys 的)，取的是列表里第一个命中项，而 members 顺序来自各标签 seqs 的并集顺序——搜「划船」时浅肤色那条排在前面就被选中了，尽管无肤色那条也命中。
	改成：命中项先聚成数组，再从里面优先挑无肤色的。卡片 main 的无肤色优先现在在「多个命中」时也生效。
