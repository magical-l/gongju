## 0. 一句话

用户先点名 `𓃒–𓄊`（加德纳 E001–F012）进「哺乳动物」，随后要求「检查整个埃及象形，看还有哪些要补到动物植物里」。
按加德纳分类把**整块 5105 个**过了一遍，**新增 1393 条归属**。

## 1. 分类方法

- **定族**：Unikemet 的 `kEH_UniK`（加德纳码，覆盖 5067 = 全部，含扩展区）
- **细分**（靠 `kEH_Desc` 关键词）：
  | 加德纳族 | 标签 |
  |---|---|
  | E（走兽）、F（走兽部位） | 哺乳动物 |
  | G（鸟）、H（鸟部位） | 鸟类 |
  | I（两栖与爬行） | 蛇/蜥蜴/鳄/龟 → 爬行动物；蛙/蟾蜍/蝌蚪 → 两栖动物 |
  | K（鱼） | 水生生物 |
  | L（无脊椎） | 虫 |
  | M（树与植物） | 果实、种子 / 叶子 / 花朵 / 树木（兜底） |
- **神话生物**：动物族 ∩ 描述点明赛特兽/狮鹫/斯芬克斯 → **额外**挂「传说生物」（两边都挂，用户 2026-10-09 裁定）

## 3. 三处判错又改回来的（都是我自己的）

1. **字段取错**：先用 `kEH_HG` 定族，它只有 3752 个码位有（`U+130D2` 就没有），
   1186 个被误判「无分类」；`kEH_Cat` 与 `kEH_UniK` 还有 211 处不一致。
   → 改用 `kEH_UniK`。规则已写进 `设计/数据说明.md`。
2. **爬行关键词漏词**：`viper`/`cobra` 不在表里，把整族毒蛇判成了「两栖动物」（90 个）。
   → 补词后 爬行 110 / 两栖 25。
3. **`seth` 扫宽了**：全块搜 `seth` 命中 171 个，其中 167 个是「带赛特兽头的权杖/神像/旗杆」这类
   **复合符号**，不是神秘生物本身。→ 收紧成「动物族 ∩ 点明神秘生物」得 18 个，
   再人工复核剔掉 2 个假阳性（`𓲲` 猎隼、`𓴃` 兀鹫——它们是鸟，只是爪里握着带赛特兽头的权杖）→ **16 个**。

## 4. 两条要记住的

- **扩展区 1149 个现在在标签里，但页面看不见**：`Noto Sans Egyptian Hieroglyphs` 只覆盖基础区
  1072/1072，扩展区 0/3995，页面上全是空框。归属是对的（用户裁定「全补」），
  要看见得等覆盖扩展区的字体，或给页面加一个（目前没有）。实测：基础区 8 个样本全渲染，扩展区 8 个样本全空框。
- **植物桶里有 6 个复合符号**（如「蛇压在纸莎草上」），按「主形状是植物」归了植物类；
  松判据的边界，已列在此处备案。

## 5. 教训

1. **同一份参考数据里多个「看起来都像答案」的字段，先数覆盖率再选。** `kEH_UniK`(5067) /
   `kEH_Cat`(5067) / `kEH_HG`(3752) / `kEH_JSesh`(3860) 四个都像编号，取错一个就丢 1186 个。
2. **关键词判据必须先把假阳性样本打出来看。** 三处错里两处（爬行漏词、seth 扫宽）都是
   样本一眼能看出来的——`I9 角蝰` 出现在「两栖动物」里、猎隼出现在「传说生物」里。
   跑完统计先 dump 每个桶的前 8 条，比事后复查便宜得多。
3. **用户给的范围可能不是天然边界。** 用户最初给的 `𓃒–𓄊` 停在 F012，而 F 族（兽类部位）
   一直排到 F050；提出来后用户直接改成「整块都查」，一次做完比两轮补省事。
