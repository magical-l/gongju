# 字符作画页：floatPanel 拆解设计

日期：2026-08-12
状态：已确认（2026-08-12，多轮设计问答后用户确认）

## 背景与动机

`字符作画/字符作画.html` 的右侧悬浮面板 `#floatPanel` 用 details 管风琴容纳三个职责不同的面板（已选元素/素材库/图层），受 `max-height` 约束时 flex 按自然高度比例收缩，导致自然高度小的"已选元素"面板被压到几乎不可用（内容区仅 ~30px），操作控件点不到、层级条被压扁——todo bug3 与 testing 发现的"点不到控件"是同根因（高度分配不合理）。

修 flex 分配属"样式层面缝缝补补"。经头脑风暴确定：三个面板**本质职责不同**，应各归其位，而非挤在同一容器抢空间。

## 目标

把 floatPanel 拆解为三个独立呈现，消除空间竞争，同时保留全部现有功能（撤销/重做、自动保存、拖拽移动、缩放固定中心、多选、画布平移缩放、新建/打开/清空）。

## 布局架构

```
editor（flex）
├── canvas-card（画布，flex:1，min-width:0）
│   ├── sceneCanvas（场景，zoom/pan transform）
│   │   └── floatPanel = 已选元素浮层（贴选中元素，随画布变换）
└── 右侧固定组合（页面布局一部分，不悬浮，同高）
    ├── 图层瘦长条（~36px 窄条，贴左沿）
    └── 素材库固定栏（~300px）
```

### 1️⃣ 素材库 → 右侧固定栏
- 从 floatPanel 移出：`.tab-bar`（emoji/普通）+ 两个 `symbols-scroll` 容器
- 放 editor 右侧固定列，宽度 ~300px，高度与画布区撑齐；固定不悬浮
- 画布区相应变窄（canvas-card flex:1）

### 2️⃣ 图层 → 瘦长条（素材库左沿）
- 窄条 ~36px，紧贴素材库左沿、同高，视觉像素材库"边框"，互不覆盖
- 自上而下 = 顶层→底层，每项一个小字符（按 z-index 降序，同现有 refreshLayers 排序）
- 交互：
  - 点击项 → 选中该元素（与画布 `selectElement` 联动）
  - 拖拽项上下换位 → 调整层级（触发 `swapLayerZ` 语义，改由拖拽排序驱动）
  - 键盘 Delete/Backspace → 删除（现有 handleBackspaceDelete 已有）
- hover 显示字符全名（title 或 tooltip）
- 现有 `.layer-list` 列表 + 上移/下移/删除按钮移除

### 3️⃣ 已选元素 → floatPanel 浮层（画布内）
- floatPanel 容器移入 sceneCanvas 内（随 zoom/pan 变换），继续 absolute 定位
- 无选中：隐藏
- 单选：贴住选中元素右上角浮现；可拖动脱离（拖开后停留位置，脱离跟随）
- 内容保留：操作栏（✕ 取消选中 / 🗑 删除）+ 预览卡片 + 字号/旋转/透明度/重复滑块 + 颜色
- 多选（Ctrl 点选）：切批量模式（已选 N 个 + 批量删除 + 取消选择），贴住最近点选元素
- 画布变换（拖动元素/平移/缩放）不实时跟随浮层——浮层仅在选中时定位一次

## 迁移与保留

- `refreshLayers()` → 改为渲染瘦长条（字符列），保留与 `selectElement` 的选中高亮联动
- `swapLayerZ(el, dir)` → 由瘦长条拖拽排序驱动（计算目标位置后调用层级交换）
- 撤销/重做、自动保存（pushHistory/undo/redo 已覆盖所有状态变化，结构变化不破坏）
- 多选移动/删除、拖拽移动、缩放固定中心、画布平移缩放、新建/打开/清空 全部保留
- `initPanelFloating`（拖面板头移动）→ 浮层拖离逻辑复用

## 交互细节

- 浮层贴住位置：元素右上角（画布相对坐标）；多选贴最近点选元素
- 拖离：拖浮层标题栏离开后，浮层停留在拖放位置（脱离跟随），重新选中其他元素时重新贴住
- 图层条拖拽排序：pointer events 实现，与画布元素拖拽（makeDraggable）区域不冲突

## 实现注意

- 素材库固定栏与画布区在小屏的适配（editor 可横向滚动或响应式收缩）
- floatPanel 移入 sceneCanvas 后，其 absolute 定位随 transform；多选/单选切换的显示逻辑沿用现有 selectElement
- 移除 floatPanel 中素材库/图层 details 的 HTML/CSS，避免死代码
