# 符号页：中间列表区显示标签别名 v1.1.4

## 动机

用户要求：中间列表区标签卡片上，标签名字（gridhead）下、标签简介（grid-intro）上，显示标签别名。此前别名只在搜索视图（tag-alias 行）和左侧树悬浮 title 显示，主视图选中标签后看不到别名。

## 变更

| 文件 | 变更 |
|------|------|
| `符号/符号.html` | gridhead 与 grid-intro 之间新增 `.grid-alias` 行（有别名才显示，v-if 守卫与文本格式同搜索视图 tag-alias）；`符号.css` 缓存版本 `?v=260821`→`260822` |
| `符号/符号.css` | 新增 `.grid-alias` 样式（font-size 12px、color `--el-text-color-secondary`、margin-bottom 8px，与 gridhead/grid-intro 垂直节奏一致） |
| `docs/2026-08-21-符号页-网格区显示标签别名.md` | 本次决策文档 |

## 设计决策

- **位置**：gridhead 与 grid-intro 之间独立一行，不塞进 gridhead 的 flex 行内（避免破坏 name+count 并排布局）。视觉顺序：名字（含数量）→ 别名 → 简介。
- **复用模式**：v-if 守卫 `selectedTag.node.alias && length`、文本格式「别名：xxx、yyy」、次要文字色，均与搜索视图 `.tag-match .tag-alias` 一致。
- **数据**：读 `selectedTag.node.alias` 数组，无别名不渲染该行（生肖、emoji 根等节点实测不显示）。
- **缓存版本**：CSS 同日二次修改，`?v=260821`（v1.1.3 已部署过）无法强制刷新，换 `260822` 与 符号.js 对齐（经验：浏览器缓存旧 CSS/JS）。

## 验证

testing 实测（HTTP 52330 + Playwright）：

- 带别名标签：情绪表达→「别名：表情、情绪、感情、情感」；水生生物→「别名：海洋生物、海洋动物」；苏州码子→「别名：杭州数字」
- 无别名标签：生肖、emoji 根 → grid-alias 不渲染，无报错
- computedStyle：font-size 12px、color rgb(144,147,153)（= `--el-text-color-secondary` #909399）、margin-bottom 8px
- 回归：字符网格渲染、右侧详情、搜索视图 tag-alias 均正常；控制台无应用层错误

## 已知项

- 当前语义树数据中无节点同时含 alias 与 intro，别名与简介两行同屏暂无真实数据可观测（模板顺序 gridhead→grid-alias→grid-intro 已确认）。
- 实测「生肖」节点无别名（带别名的是水生生物：海洋生物/海洋动物）。
