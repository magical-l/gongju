## 1. 加挂

| 标签 | 加挂后 | 内容 |
|---|---|---|
| 信仰/风水堪舆 | 80 → **88** | 易经 79 ＋ 外围 8 ＋ 原有 🧭 |

**落盘方式**：不走 HTTP 的 `add` 动作——它的 `is_member_list` 只认**对象数组**
`[{cps:[...]},...]`，直接发整数列表会被判成**一条 N 码位的序列**（那就成 ZWJ 序列了）。
正确做法是直接调 `dev_server._add_member` + `save_tags`，写盘路径与页面点「添加标签」一致。

**没加语境名**：这两个标签下符号显示的还是别处的名字。用户在 ☯ 上先做了示范
（`groups.{"风水堪舆":{"alias":["天池"]}}`——罗盘中心那层叫天池，正是从本轮调查里取的）。

| 卦 | 先天（伏羲） | 后天（文王） |
|---|---|---|
| 乾 | 南 | 西北 |
| 兑 | 东南 | 西 |

写法 `南（先天）`／`西北（后天）`。**后天那套拿洛书九宫数互校过**：坎1北、坤2西南、震3东、

若以后要它只在水语境露出，可改挂 `风水堪舆` 组。

## 4. 调查：风水到底用哪几层？

起因是用户问「风水堪舆会用太极两仪四象这些吗？是不是只用八卦和六十四卦」。

**结论：全套都用，而且用的是「罗盘圈层 ＋ 穴法」这一路**：

| 层 | 风水里的实际用法 |
|---|---|
| 太极 | 罗盘中心放指南针那层叫「**天池**」，又名「**太极**」；阴宅穴法里穴场那道隐微圆晕叫「**太极晕**」，有晕才生气内聚、才是真穴 |
| 两仪 | 「**子午中分为两仪**」；穴法里肥起为阳穴、瘦陷为阴穴，阴龙配阳穴、阳龙配阴穴 |
| 四象 | 「**两仪合卯酉为四象，四象合四维为八卦**」；穴法里具体成「**脉息窟突**」＝少阴／少阳／老阴／老阳 |
| 八卦 | 罗盘有先天、后天**两层**，实操用**后天**——纳甲、二十四向、九星、龙上八煞都建在它上面（「先天为体，后天为用」） |
| 六十四卦 | 「后天八卦顺行…变八八六十四卦」，附在**缝针（外天盘）**里用于**立向收水**；内盘正针格龙，「内外两盘各用不同，不可错乱」 |

**道教的结论**：术语**同名**——这套本来就是道教吸收《易传》的（「易有太极，是生两仪…」→
陈抟《无极图》一路）。道教多的东西是：在太极**之前**加一环「**无极**」（「无极而太极」）；
☯ 本身有别称（阴阳鱼、阴阳太极仪图），用户已补进别名。

### 一处自我修正

我先前对用户说「风水的『四象』指青龙白虎朱雀玄武」——**说得太绝对**。实际有**两路**：

- **峦头形势**那一路：四象 ＝ 青龙白虎朱雀玄武
- **理气／穴法**那一路：四象 ＝ 少阴少阳老阴老阳（脉息窟突）——**跟 ⚌⚍⚎⚏ 的名字是同一套**

所以之前那句「别把 ⚌⚍⚎⚏ 在风水语境改叫青龙」只说对了一半：别改叫青龙没错，但它们在风水里
**不是没关系**，是在穴法里当太少阴阳用。

## 5. 经验教训

1. **查「库里有没有」别拿 `ENRICHED_SYMBOLS` 当全集。** 我第一轮扫出「🐉 龙 / 📿 念珠 / 🔮 水晶球
   库里都没有」，实际它们都在——只是没有语义标签，挂在机械轴上，有直译名。
   **判据应该是「能不能显示」（有直译名或落在标签区间里），不是「在不在富化数据里」。**
   我差点据此把一大批候选毙掉。
2. **表情符当象形符号用，要挑「整只」不挑「脸」。** 我第一轮给风水加的是 🐯（虎头，库里
   名字就叫「老虎脸」），而白虎要的是整只 🐅。项目里「承载词当背景」那条讲的是同一件事的
   反面（`😛 伸出舌头的脸` 主名取「吐舌」——脸的成分该丢）；反过来，当要的就是那个**物**时，
   「脸」反而是缺了主体。
3. **引文式断言要留余地。** 「风水的四象指青龙白虎」是一句听起来很确定的断言，而它只覆盖了
   一路用法。**说「X 指 Y」之前先问：有没有第二路？**
4. **批量加挂前先看同类标签挂着什么。** 键盘上敲关键词扫出 793 个噪音命中；改成「先列同类
   标签的成员、再逐个点名核查」才拿到真候选。
