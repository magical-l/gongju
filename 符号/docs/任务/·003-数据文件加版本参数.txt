验收标准：5 个数据文件的请求都带上 ?v=YYMMDD；改数据后刷新页面拿到新版本，不依赖服务器缓存头。

背景
	不能依赖服务器缓存头——本地服务器可能换、别人可能用别的服务器。
	搁置原因：数据改动频繁，等稳定后再统一加。

方案
	与 符号.js 现有惯例一致用 ?v=YYMMDD。fetch 和 <script src> 两处都要加。

涉及文件
	标签.js / 官方名直译名.js / unicode官方名.js / noto-cmap.js / 符号富化数据.js

风险 / 次生问题
	加了之后，每改一次数据就要改一次 ?v=，否则用户拿到旧缓存——比现在更容易忘。需要一个提醒机制，或把它写进改数据脚本的收尾步骤里。
