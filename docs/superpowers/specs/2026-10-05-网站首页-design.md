# 工具兽 · 网站首页 设计文档

日期：2026-10-05

## 背景

站点是纯静态 MPA，各页面独立文件，靠浏览器整页跳转。随页面增多出现三个问题：

1. **域名根路径是 404** —— 仓库没有 `index.html`，访问 `gongju.document.cool/` 直接 404。
2. **导航靠复制** —— 每个页面在自己的 `<header>` 里手写一份**双行扁平导航**，列出全部已放出页面。加一个页面要改十几处，且各页导航已经不一致（`数学/math-quiz.html` 干脆没有导航）。
3. **没有全站入口** —— 用户只能通过站内导航或直接 URL 进入某个工具。

## 目标

给站点做一个**导航索引型首页**（不做介绍性门面），并同时把"导航要改十几处"这个根因消掉。

## 本次范围

**做：**

- 新增根目录 `index.html` 作为站点首页
- 抽出一份全站共用的工具清单数据
- 首页与所有子页的顶部导航都由这份数据渲染
- 各子页 header 里的双行全量导航替换为分类下拉

**不做：**

- 搜索框（17 个工具 + 分类标签足够；等工具数超过约 40 个再加）
- 工具页自身的任何功能改动
- `css/` 子项目（它有自己的文档体系与部署域名 css.document.cool）

## 二、首页结构

```
<body>
  <header>           站名「工具兽」+ 一句定位        ← 首页不放分类下拉（首页本身就是索引）
  <main>
	<div 分类标签行>  全部 17 / 文本与编码 3 / 字符与图形 2 / 学科学习 2 / 游戏 10
	<div 卡片网格>    17 张卡片，每行 4 张
```

**筛选行为**：点分类标签 → 只显示该分类的卡片。默认"全部"。

- 实现为纯前端显隐（切换卡片的 class），**所有 17 条链接始终存在于 HTML 中**，因此对搜索引擎与"禁用 JS"场景都可用。
- 当前选中的标签有选中态。

## 三、卡片规格

每张卡片从上到下：

1. **图区** —— 固定高度 `190px`，图片 `object-fit: contain` 居中，不裁切；底色用该分类色的极浅版（约 12% 透明度）
2. **名称**
3. **一句话简介** —— 说明"这是个啥、能干嘛"，兼顾不认识该工具的人

图片统一带细描边与轻投影，看起来像卡面上贴的一张实物图。

**有图 / 无图的处理**：本次只有 6 个工具有缩略图。**没有缩略图的卡片，图区换成"该分类色极浅底 + 一个居中大号符号"占位**，图区高度与有图卡片完全一致，视觉上是一张完整卡片而非缺了一块。补图时直接替换即可。

## 四、缩略图规格

**内容标准**（由用户在 2026-10-05 以 6 张示例图确立）：取该工具的**完整核心界面或完整核心单元，不切边**。

- 棋盘类：取整盘（如 2048蛇、数字华容道、2048方块）
- 棋盘过大以致看不清：放大到局部（如中国象棋取九宫区域，棋子大而字清）
- 页面型：取整块代表性界面（如元素周期表取整表连两侧面板、拼音取等式卡 + 全键盘）
- **不追求字号可读**：元素周期表这类密集页面，看清形式即可

**尺寸**：不做统一裁切。入库时只统一**宽度上限**，高度按原图比例保留（保证不裁切内容）。

**存放**：**跟着页面走**，放该页面所在目录下的 `thumbnails/` 子目录（实现时定的规则）：

```
化学/元素周期表.html   →  化学/thumbnails/元素周期表.jpg
游戏/点灯.html         →  游戏/thumbnails/点灯.jpg      （游戏根目录下的几个页面共用这一个）
游戏/2048/2048.html    →  游戏/2048/thumbnails/2048.jpg
```

放在页面目录下是因为 `游戏/` 根目录里除了三个页面还有 `game.css`、`kit.esm.js`、`turn-based-game.esm.js` 等共享文件，图直接同级会分不清归属；多一层 `thumbnails/` 也让将来放 2x 图或多尺寸有地方。`tools.js` 的 `thumb` 与 `index.html` 的 `img src` 都写相对站点根的路径。

## 五、全站导航改造

### 5.1 数据

新增 `resources/tools.js`，用 IIFE 模式暴露全局（与项目既有 JS 风格一致，普通 `<script src>` 即可引入，不依赖 ES module）：

```js
window.TOOLS = [
	{ cat: '文本与编码', name: '文本转化', desc: '编码解码、去重、大小写、查找替换', href: '文本转化.html', thumb: '' },
	// ...17 条
]
```

路径字段存**相对站点根**的路径（如 `游戏/2048/2048.html`），各页面自行加前缀。

### 5.2 子页导航

新增 `resources/site-nav.js`，读取 `window.TOOLS` 渲染分类下拉。

页面侧改动只有两行 —— 把原 `<header>` 里的 `<nav>` 整块替换为：

```html
<nav class="site nav" data-root="../"></nav>
<script src="../resources/site-nav.js"></script>
```

- `data-root` 是该页到站点根的相对前缀（根目录页面为 `""`，一级子目录为 `"../"`，二级为 `"../../"`），nav.js 用它拼出每个链接与图片的完整相对路径。
- 下拉用原生 `<details>` / `<summary>`：点击展开、触屏可用、键盘可达、展开收起不依赖 JS。
- 最左是站名「工具兽」，链接回首页。
- 当前页所在分类的 summary 加选中态。

### 5.3 首页

首页不引入 `site-nav.js`（不放分类下拉，避免与筛选标签重复）。

**首页的 17 张卡片写成静态 HTML** —— 名称、简介、链接、图区全部直接写在 `index.html` 里，不靠 JS 渲染。理由：首页是全站唯一入口，一旦靠 JS 渲染，禁用 JS 或脚本出错时首页会整页空白；静态写出则无论 JS 如何都能用，且 17 条链接天然进入源码，利于收录。

代价：新增工具时首页要改两处（`tools.js` 加一条 + `index.html` 加一张卡片），而不是一处。这个代价可接受 —— 相比原来的"改十几处"仍是数量级的改善，且两处都是直白的追加。

## 八、取舍与遗留

1. **子页导航改为 JS 渲染** —— 子页顶部导航不再出现在 HTML 源码里。代价是这些内部链接对爬虫弱一些；换来的是子页导航"加页面只改一处"。首页作为全站入口，17 条链接全部写在 HTML 源码中，弥补了这一点。
2. **首页完全静态、无 JS 也能用** —— 卡片是静态 HTML，筛选只是显隐切换（切换 class），不依赖 JS 取数。代价见 5.3：新增工具要同时改 `tools.js` 与 `index.html`。
3. **11 张缩略图待补** —— 补图时把图放进该页面目录的 `thumbnails/`，再在 `tools.js` 填 `thumb`、`index.html` 把图标占位换成 `<img>`，无需改其它结构。
4. **6 个工具未收录** —— 补进各自导航、确认完工后再加入 `tools.js`，届时"生活计算"分类会随之出现。
