# 符号页 · 数据说明

面向要改 `符号/` 下数据文件的人。**改数据前先读第三节（组键）与第六节（怎么写脚本）。**

写脚本一律 `from datatool import *`，别手写读写（第六节）。改完 `python 符号/datatool.py` 体检。

## 一、文件一览（谁权威）

**跟"名字"有关的只有三份**，其余是只读参考。**下文一律用"统一叫法"这一列的词**，别再造别名。

| 文件 | 存什么 | 量 | **统一叫法** |
|---|---|---|---|
| `标签.json` | 语义树 `roots → children`：每个节点只有 `ranges`/`seqs`/`alias`/`intro`，**不存字符名** | 899 节点 | **标签树**（成员归属的唯一权威） |
| `中文名.json` | `{_v, names:{码点:名字}, patterns:[[起,止,前缀]…]}`，一张全库平名表 | 35526 键 + 22 条 patterns | **名字表** |
| `符号数据.js` | `const SYMBOLS = [...]`，每字符一条"符号条目"，条目里挂若干"组" | 3137 条 / 3294 组 | **符号条目**（一条）、**组**（条目里的一个键值对） |

| 文件 | 角色 | 统一叫法 |
|---|---|---|
| `名字.json` | `{_v, names:[[cp,英文名]…], patterns}`，**Unicode 官方英文名**（页面 `nameOf()` 读它） | 只读参考 |

| `待译清单.json` | 名字表里还没译干净的条目（临时工作文件，做完删） | 工作清单 |

| 曾用过的叫法 | 实指 | 现在怎么说 |

## 二、SYMBOLS 条目结构

```js
{"char":"♂","groups":{"性别、婚姻":{"name":"男性、雄性","alias":["Mars"]},
                      "天文、太空、宇宙":{"name":"火星","alias":["男性符号"]}},
 "intro":"…","mode":"dual"}
```

- `char`：字符（可为多码位 ZWJ 序列）。
- `groups`：**键 = 标签名**（外连 id），值 = `{name 语境名, alias 别名[]}`；一个字符可以有多个组（=多标签语境下各叫各名）。
  注意上面例子里的 `alias` 是**文件里存着的**，只属于那一个组。**界面上显示的别名比这多**——还会并上其他组的主名（虚拟合并，不落盘），见第四节。
- `intro` / `mode`：简介 / 双码位序列标记。
- **条目里没有英文名字段**。英文名的来源分工：
  - **单码位** → 一律 `nameOf(cp)` 读 `名字.json`（Unicode 官方英文名，机器直译的来源就是它）。符号条目里不存英文名。
  - **ZWJ 序列（多码位）** → `标签.json` 对应 `seqs` 里的末项（`SEQ_INDEX` 的 `en`）。
  - 与官方名**真正不同**的英文俗称（CLDR 短名如 `Grinning Face With Big Eyes`、按键名 `Escape`、卢恩名 `Raidho`）写进该组的 `alias`，只当搜索词。只是官方名截短的（`Dollar` vs `DOLLAR SIGN`）不写——搜索通道会匹配官方名，`dollar` 照样命中。
  - 历史：`ename` 曾挂在每个组上，删组会连英文名一起丢，v1.26.0 起废弃。
- 文件格式：第一行 `const SYMBOLS = [`，每组条目**一行** `\t{...},`，最后一行 `];`（**末条不带逗号**）。手工追加条目时不要漏逗号。

## 三、组键（groups 的键）——最容易踩的地方

**是什么**：组键是这组名字的「容器名 + 外连 id」，指明**这组名字属于哪个标签**。

**谁在用它**（渲染不读键，但下面三处读）：
1. **语境名渲染**：`符号.js` 的 `zhNameIn(cp, tagName)` 用「当前选中标签名」去匹配组键，匹配到才显示该组名。
2. **序列联动**：改一个肤色/旗帜序列的名字或别名时，兄弟条目按「当前组键」写入同一容器。
3. **工具脚本**：`dedupe_symbols.py` 等按**组名**取数/合并。

**硬约束**：
- **组键必须是现存标签名**。键指向的标签若不含该符号（或标签已被改名/删除），该语境名**永远显示不出来**，且**静默回退**到全局名，不报错。
- 机械轴（`文字系统` / `官方分类` / `区块` / `emoji（绘文字）`）**不作组键**；新建条目取"首个非机械轴标签"名，一个都没有才落兜底键 **`编辑`**（纯容器名，界面上不可见）。
- **标签改名会自动同步组键**（`dev_server.py` 的 `tag_meta()` → `sync_symbol_group_keys()`，含撞键合并）。但**手工直接编辑数据文件时，程序不会兜**——改标签名要自己把 `符号数据.js` 里的同名组键一起改。

**体检**：改完数据跑一次
```bash
python 符号/check_group_keys.py     # 列出"不可达组键"（键不是标签名，或该标签不含对应符号）
```
输出为空即健康（`编辑` 属兜底键，会单独归为"提示"）。

## 四、名字的权威层次与显示规则

**名字只有两层**（"这个字符叫什么"）；往下再没有第三层，只剩一个"它没有名字"的标记。

| 场景 | ① 语境名 | ② 名字表 | ③ 无名字时的标记 |
|---|---|---|---|
| **全局视图**（搜索、无标签浏览） | **全局名** | `中文名.json` | 「未分配码点 / 私用区码点 / 控制字符」 |
| **标签视图**（选中某标签） | 该标签**子树里最深的已建组**里那个 `name`（**语境名**） | 同上（全局名 → 名字表） | 同上 |

- **③ 不是第三层名字，是"没有名字"的占位提示** —— 它只在①②都没有时出现，本身不给出任何名字，只说明这个码位的情况。
  ⚠️ 它靠**码位区段**判断（`unnamedKind`），不查 Unicode 到底分配没分配，所以**已分配但①②都没登记的字符会被误标成「未分配码点」**（已发现至少 5029 个，待修）。
- **组键** = `groups` 的键 = **标签名**（外连 id）。
- **语境名** = 组键对应那组里 `name` 字段的值 = 该字符在**那个标签语境**下的名字。
  （⚠️ 别叫"组名"——那会让人以为指组键。就叫**语境名**。）
  例：🩠 只在「中国象棋」建了组 → 点「中国象棋」「棋类」都显示「红方帅」。
- **全局名**（`joinGroupNames` 算出，**不落盘**）= 该字符**各组语境名按组序去重后以「、」拼接**。
  例：♂ = `性别、婚姻="男性、雄性"` + `天文、太空、宇宙="火星"` → 全局名「男性、雄性、火星」。
- **组可以没有名字**：名字表里已有的名字，不必在组里再写一遍（写了就是两份，改一处另一处成假数据）。目前 1537 个组是这样——它们只用来挂别名/简介，名字由名字表供。
- **首组名** = `groups` 第一个组的 `name`。它的内容仍会被搜到（搜索匹配全部组名），只是不再决定全局显示名。
- **语境名之间不要互相嵌套**（如 `厕所` 与 `厕所/洗手间`）——全局名会拼出两个近乎重复的名字；发现就统一成一个。
- **别名**：语境下 = 本组 `alias` ∪ **其他组的组名**，并**一律排除"当前正在显示的那个名"**。**虚拟合并，不写回文件**；全局下 = 各组合并的 `aliases`（构建时已滤掉等于任何组名的项）。
  数据侧要求：`alias` 不得与本组名或其他别名重复（大小写不敏感）。
- **旧粗名不留别名**：`a变音` 这类宽泛名一个名字盖着 à/á/â/ã/ä 五个码位，留成别名只会变成搜谁都出一堆的废词，直接换掉不留。
- **编辑规则**：在某标签下改名/改别名，**只写该标签对应的组**；其他组不动。

## 五、编辑保存链路（页面 → 文件）

页面把改动 POST 到 `/symbol-api/save`，由 `dev_server.py` 落盘（`action` 见其文件头注释）：

- `add` / `move` / `remove` → `标签.json`（成员增/移/取消打标）
- `tag`（改名/别名/简介） → `标签.json`；**改名时另同步 `符号数据.js` 同名组键**
- `tag-new` / `tag-del` / `tag-sort` / `tag-reparent` → `标签.json`
- `sym`（符号名/别名/简介） → 字符已在 `SYMBOLS` → 写 `符号数据.js`；否则写 `中文名.json`
- 三大机械轴（`文字系统`/`官方分类`/`区块`）**禁止修改**

## 六、改数据怎么写脚本

**不要各自手写 JSON 解析和写回。** 用 `符号/datatool.py`，坑都封在里面了：

```python
import sys; sys.path.insert(0, r'd:\工具兽\静态页面工具\符号')
from datatool import *

n = update_symbols(lambda o: ...)   # 改 符号数据.js：只重写被改的行，其余字节不动
append_symbols([{...}])             # 在 '];' 前追加
set_zh(0x262D, '镰刀锤子')           # 改 中文名.json（names 是 {码点:名字} 映射）
check_all()                         # 一次跑完所有不变量，返回 (ok, 问题列表)
```

`check_all()` 覆盖：`node --check` / 逐条解析 / **char 是不是字符串**（防 `},,` 造成稀疏空槽，
那种语法合法但数组里是 `undefined`、页面整挂）/ char 重复 / 组名空串与顿号异常 /
两个 JSON 可解析 / 组键可达性。

命令行直接跑：`python 符号/datatool.py`（通过退出码 0/1）。

## 七、常见坑

1. **改标签名不同步组键** → 组键变成"历史快照"，语境名失效（页面改走服务端已兜；手工改文件不兜）。
2. **把语境名当全局名**：全局权威仍是符号条目的名字，名字表只是第二层。
3. **组键写成不存在的标签名** → 语境名静默失效（`check_all()` 可查）。
4. **`符号数据.js` 每行一条、末条不带逗号** —— 用 `update_symbols`/`append_symbols` 就不用操心；
   手写的话改完务必 `node --check`，还要逐条验 `char`（见上）。
5. **写回时选错缩进风格**：`中文名.json` 是 `indent=2`；用紧凑格式写回会把 3.5 万行压成 1 行
   （曾经把 14 万行的老格式压成 1 行，diff 全红）。`save_zh()` 已固定 indent=2。
6. **改名前两层都要扫**：符号条目（组里的 `name`）和名字表（`中文名.json`）都存名字，只扫一层必漏。
