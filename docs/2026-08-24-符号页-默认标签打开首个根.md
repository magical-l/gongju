# 符号页：默认标签打开标签树首个根 v1.3.3

## 动机

用户发现加载符号页时默认打开的是"文字系统"，希望改为打开**整个标签树的第一个元素**（当前应为"人与身体"）。

## 根因

默认标签由 `符号.js` 的 `mounted()` 决定。旧逻辑硬编码优先找 FLAT 里名字为"表情、脸"/"表情、情绪"的标签——语义树 v1.3.0 重组后这两个标签已不存在，随后回落到 `FLAT[0]`。

而 `FLAT` 按 标签.json 的 roots **插入序**展平（第一个是"文字系统"），与页面树的**展示序**（`treeRoots` 计算属性：语义轴在前、文字系统/官方分类/区块末尾）不一致。所以默认落在了"文字系统"。

## 方案

`mounted()` 默认标签改为取 `this.treeRoots[0]`（展示序第一个根，当前为"人与身体"）。`selectTag` 只依赖 `name/node/path` 三个字段，直接构造标签对象。

```js
// 默认标签：整个标签树展示序的第一个元素（语义轴在前，当前为「人与身体」）
const firstRoot = this.treeRoots[0];
if (firstRoot) this.selectTag({ name: firstRoot[0], node: firstRoot[1], path: firstRoot[0] });
```

| `符号/符号.html` | `符号.js?v=260823→260824` |

## 验证

Playwright（52330 端口静态服务，CDP 连接）：
- 默认选中标签 = **"人与身体"**（gridhead 显示，非"文字系统"）
- 网格 415 个字符与"人与身体"聚合成员（合并 ranges 去重）逐一吻合，首字符自动 `sel`
- 左侧树首根"人与身体"默认展开；控制台无页面逻辑错误（仅既有的 /symbol-api 404 优雅忽略 + 无关广告 403）

## 踩坑

- **FLAT 展平序 ≠ 页面展示序**：FLAT 按 标签.json roots 插入序，`treeRoots` 会把语义轴重排到前、机械轴末尾。"取标签树第一个元素"必须用展示序 `treeRoots[0]`，不能沿用 `FLAT[0]`。
- **聚合成员数勿简单求和**：初估"人与身体"754 为误算（子节点 ranges 直接相加未合并去重），页面 `collectNode` 合并后真实 415。
