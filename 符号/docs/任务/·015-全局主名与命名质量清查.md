# ·015 全局主名与命名质量清查

日期：2026-09-18　（承接 ·013）

## 一、定的规矩

### 1. 语境名该不该提为全局主名

**全局主名这个功能上得晚**，所以历史上很多好名字只能挂在某一个标签下。判据：

- 一个字符**总共只有一个语境名** → 提为条目级主名（名字本来就该处处生效）
- 有 **2 个以上不同**的语境名 → 名字真的随语境变（`♂` 性别下叫「男性、雄性」、天文下叫「火星」），保留
- 有 2 个以上但**其实是同一串字** → 也提（同一串名字挂在多个标签下，本质是一个全局名）

要挑一个当全局名时（有多个不同语境名），判据是「**这东西脱离语境时认它是谁**」，**不看名字长短**：

```
♂   → 男性、雄性    （脱离语境就是男性；火星只在天文里成立）
→   → 右箭头       （脱离语境就是右箭头；函数映射只在函数里成立）
⎋   → 左上箭头破圆   （描述性名字当全局名，「退出键」退回语境名）
⇏   → 双杆带斜线右箭头（同上，「不能推出」退回语境名）
```

⚠️ 「票多的赢」「挑短的」两条都试过，**都是错的**——票数反映的是标签树怎么分，长短跟通用与否无关。

### 2. 主名跟直译名一字不差 = 白设，撤掉

直译本来就够好（`→` 的直译就是「右箭头」），不必特意设主名。

### 3. 一字符一名的原则

一个字符只有一个语境名时它实质就是全局名；「通用」这种机械轴下的语境名更是必然该提到全局。

### 4. 列工单不罗列肤色变体

`🏃🏻‍♂️` 那一串拿一个无肤色的当代表即可。

### 5. 拆「A、B」型直译名要看官方名

同样用「、」连接，语义两种，**不能按词形一刀切**：

```
右箭头、函数映射、趋近极限     ← 三个候选名，留跟官方名对应的那个
伸出舌头、紧闭眼睛的脸        ← FACE WITH X AND Y，是一个名字的两部分，不能拆
```

⚠️ **教训**：拆掉的成分**没有默认去处**。我当时的做法是按「这部分是否已在富化层」筛，以为都还在——
实际 17 个两边都不是，一拆就抹掉了。**遇到「丢东西」的场合，默认列出来给人审，不要自己补个默认去处。**

### 6. 找不到「读起来不像话」的通用判据

三条路都试过：

| 路 | 结果 |
|---|---|
| 「直译名里塞了两个互斥答案」 | 能自动筛，但**只有 3 条**，都是对的 |
| 「易错词表」（YEN/GOBLIN/FATHER…） | 能自动扫，抓出 4 条真错译（`MOTHER CHRISTMAS`→母亲圣诞 等） |
| 「不是个词」（查中文词典） | **失败**——jieba 词典（35 万词）也分不开：「母亲圣诞」和「圣诞婆婆」都合法切分 |

**唯一走得通的是按官方名的构造一族一族过**，每族量都不大：

| 族 | 条数 | 真错的 |
|---|---|---|
| `A OF B` | 245 | 12 |
| `A WITH B` | 249 | 2（嵌套 7 条，读得懂，不动） |
