日期：2026-08-27
状态：已实施

## 背景

todo 数据清理项 1：𝌀（U+1D300）在 Unicode 的官方英文名 `MONOGRAM FOR EARTH` 是**误命名**，实为「人」。背景见 v1.8.0（2026-08-25 文档）：太玄经符号三才 ⚊=天/阳、⚋=地/阴、𝌀=人/和；日本学者提案改名被拒。

## 方案权衡（用户裁定 A）

| | A：保持官方名 + 简介说明 | B：改英文名 + 简介说明 |
|---|---|---|
| 英文名显示 | MONOGRAM FOR EARTH（官方原貌） | 正确名或标注式（如"MONOGRAM FOR EARTH（误命名）"） |
| 数据纪律 | **名字.json 是官方数据层**（build_names.py 从 UnicodeData.txt 生成，重跑覆盖），保持官方名不污染、不反复维护 | 改它会被重跑覆盖，且英文名字段混中文标注变脏 |
| 项目先例 | 与 ☫ FARSI SYMBOL 一致（保持官方名，intro 说明真实含义） | 无先例 |

**结论：A**。英文名保持官方 `MONOGRAM FOR EARTH`，纠偏信息放 intro。

- **名字.json**：不改（方案 A 本就不动官方层）
- **todo.txt**：数据清理项 1 打勾（项 2"搜健康"早已在 v1.8.0 修正，本次从待办删除）
