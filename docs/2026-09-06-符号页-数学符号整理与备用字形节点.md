## 背景

用户整理语义轴「数学/数学符号」，逐层审计其直接持有成员。核心矛盾：该节点当初按 Unicode 官方分类（Sm=数学符号）批量扫入，但 **Sm 是"区块/编码层"分类，不等于"语义上有数学用途"**——大量字符是 STIX/Elsevier 出版社字形抢救品，只有字形价值。

## 一、℘ 命名与简介修正（符号数据.js）

- 主名：魏尔斯特拉斯 → **幂集**（℘(X) 集合论幂集用法更常见）
- 别名：幂集 → **魏尔斯特拉斯椭圆函数**（Unicode 官方名 SCRIPT CAPITAL P 的 formal alias 是 WEIERSTRASS ELLIPTIC FUNCTION）
- 新增 `intro`：写明 **SCRIPT CAPITAL P 是历史误名**（字形实为小写 p 手写体）、℘(z)=魏尔斯特拉斯椭圆函数（以德国数学家卡尔·魏尔斯特拉斯命名）、℘(X) 亦作幂集记号
- 教训：给"多义名"符号写简介能解决 Unicode 名"只描述字形不表达用途"的缺陷

用户要求"上面辨明的有用信息都写进简介"。简介载体 = SYMBOLS 条目 intro（符号数据.js），无条目的字符须**新建最小条目**（组键=字符首个所属标签，页面 saveSymbolMeta 协议）。

- **「备用字形」标签简介**（标签.json 节点级）：解释判定标准「Unicode 官方分类为数学符号（Symbol, math）但无活跃数学用途」
- **活符号补用途简介**（建条目+改可读名）：϶ 反向∈（皮亚诺引入反写月牙 ε，LaTeX `\backepsilon`）、⅀ 双线求和（∑ 双线变体）、؈ 阿拉伯射线、⅋ par（名留中文层）、𞻰𞻱（名难意译不改，只简介）

**坑（重要）**：手工拼 SYMBOLS 条目字符串有两个坑——① 条目间**缺逗号**（数组直接语法错）；② python 字符串里 `\backepsilon` 的 `\b` 被当转义成退格符 U+0008。**正确姿势：用 `json.dumps(entry, ensure_ascii=False, separators=(',',':'))` 逐条生成，再手动拼 tab 缩进与逗号**。写数据文件别手拼 JS 对象字面量。

## 九、数字直属分流 + 币/衡/度量/常数命名整理（2026-09-07/08，v1.20.0）

继 §六~八 之后的一整批收口：先打磨 34 个直属"数字"的松散成员，后外溢到货币/度量/常数整理。**命名规则中途多次被用户校正，最终以本节约定的为准（覆盖 §二 早期"移出""改名"的措辞）**。

### 9.1 命名主次规则（用户定稿，最重要）

- **主名要"一眼看懂"，宁通俗勿精确/权威**：能意译就意译（YEAR→年份）；不逐词塞原文（"希腊 YEAR符号"=坏）。**别为精确或"权威音译"牺牲易懂**。
- 精确值（≈39L、100肘见方）、原文词（Metretes…）、国别/多国列表、旧币说明 → 一律进 **简介(intro)**，不占主名。
- 被否过的两版：①自造凑音汉字（"墨特雷特/基阿托斯"——"几个汉字不表意不如不译"）；②主名留原文（"希腊 Metretes"）。
- 用户最终命名格式：**符号在前＋顿号＋中文义**（π="π、圆周率"），或 **中文词＋字母**（e="自然常数e"）；不用"圆周率 π"（带空格）拼法。
- **字母变体名用本源字形，不译成拉丁词**（数学字母区 354+337 处规整）：希腊字母写 α…π（非 ALPHA/PI/EPSILON）、小写拉丁标签用小写字形（数学斜体小写 a 而非 A）、数字写 0-9、∂/∇/ς/ı/ȷ 用符号、清 ITALIC 等英文残留。
- **别名**：术语变体可放（第N小单位↔第N次级单位、干量↔干货容积、重量↔衡、Aroura↔平方百肘）；**不放已在官方英文名里的外文词**（Metretes 作别名无意义）。单字符别名只存 符号数据.js SYMBOLS 条目；改名要 SYMBOLS 与 中文名.json 双层同步。
- 文明/时代词要明确：现代希腊≠古希腊；爱琴文明勿用地名式"爱琴"→"古爱琴文明"；货币用"古罗马货币单位·X"等。

## 决策依据（防回归）

- Unicode Sm = 编码层"数学排版字形池"，非"语义活跃证"。判断是否数学符号须查**有无公认数学含义/活跃用途**，不能只看官方分类
- 搬离数学符号前先确认归宿（几何/单位/方向/备用字形），避免孤儿
- 补充箭头/杂项数学符号的来源：ISO 9573 SGML 实体集 + STIX 项目 + Elsevier 私有字形，多有镜像成对/方向穷举特征
- 命名三优先：主名易懂 > 精确（精确进简介）> 权威音译；文明/时代词与"单位"维度要写明；术语变体走别名且别名前缀与主名一致
- "数学/数字"=数字系统+真数字记号（含常数）；度量衡→单位、度量；古代币/衡记号→货币标志；纪年→时间、日期
