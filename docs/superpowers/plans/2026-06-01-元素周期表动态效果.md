# 元素周期表动态效果 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现"动/静"开关下的7类元素动态动画效果

**Architecture:** 通过控制容器类名 `.animation` 切换动画状态，所有动画 CSS 规则嵌套在该类名下；铁磁/人造元素需要改 HTML 模板加行内 SVG

**Tech Stack:** Vue 3, CSS3 @keyframes, SVG SMIL animation

**Spec:** `docs/superpowers/specs/2026-06-01-元素周期表动态效果-design.md`

### Task 5: 验证与调优

- [ ] **Step 1: 全局检查效果叠加**

检查以下有多标签的元素是否有冲突：
- 铁磁性金属（Fe/Co/Ni）：同时有金属高光 + 磁感线 → 不冲突
- 人造放射性元素（Tc等）：同时有放射性粒子 + 人造闪电 → 放射性 ::after 与人造 SVG 独立
- 检查页面无 console error

- [ ] **Step 2: 可视化调优**

调整各效果的 animation-duration 和 timing-function 直到视觉满意：
- 磁感线流速 (`dur`)：2s 起步
- 液体张力 (`liquid-morph`)：2s
- 气体呼吸 (`gas-breathe`)：4s
- 金属高光 (`metal-shine`)：2.5s
- 贵金属/稀土呼吸灯：3s
- 放射性呼吸+粒子：3s
- 人造闪电：3s，glitch：5s

- [ ] **Step 3: 静态模式回归检查**

关掉"动"模式（`.animation` 移除），确认所有元素恢复静态样式，无异常。
