## 背景

用户整理语义轴「数学/数学符号」，逐层审计其直接持有成员。核心矛盾：该节点当初按 Unicode 官方分类（Sm=数学符号）批量扫入，但 **Sm 是"区块/编码层"分类，不等于"语义上有数学用途"**——大量字符是 STIX/Elsevier 出版社字形抢救品，只有字形价值。

## 一、℘ 命名与简介修正（符号数据.js）

- 主名：魏尔斯特拉斯 → **幂集**（℘(X) 集合论幂集用法更常见）
- 别名：幂集 → **魏尔斯特拉斯椭圆函数**（Unicode 官方名 SCRIPT CAPITAL P 的 formal alias 是 WEIERSTRASS ELLIPTIC FUNCTION）
- 新增 `intro`：写明 **SCRIPT CAPITAL P 是历史误名**（字形实为小写 p 手写体）、℘(z)=魏尔斯特拉斯椭圆函数（以德国数学家卡尔·魏尔斯特拉斯命名）、℘(X) 亦作幂集记号
- 教训：给"多义名"符号写简介能解决 Unicode 名"只描述字形不表达用途"的缺陷

## 二、移除无数学语义成员（标签.json）

按"是否有真实数学语义"逐簇盘点，移出 3 批（共 19 码位），全部**先补挂归宿再移除**防孤儿：

| 批次 | 移出 | 补挂去 |
|---|---|---|
| 确定性箭头 7 | ⟲⟳(27F2/3 回转刷新)、⍼(237C)、FFE9-FFEC 半角箭头 | 标志/箭头与方向（27F2/3 原本已双挂） |
| 几何形状 10 | ▷◁◸◹◺◻◼◽◾◿ | 数学/几何形状（三角在本级、方块在"方形"子节点，聚合已覆盖） |
| 度数 1 | °(0xB0，官方 gc=So 非数学) | 自然、科学/单位、度量（℃℉KÅ 同处） |

**1CEF0 勘误**：初判为"遗留计算符号"错误——查官方 Blocks.txt 它属 **Miscellaneous Symbols Supplement(1CEC0-1CEFF)**，非遗留计算补充(1CC00-1CEBF)。邻居是地占术符号但自身名字只是"带横杠空心圆"无占卜义。用户裁定归几何形状/圆形。

### 明确保留（避免误伤，留待数学符号细分）

- 基础箭头 ←↑→↓↔ 及 ↚↛↠↣↦⇒⇔ 等常用关系箭头
- 长箭头 ⟵⟶⟸⟹ 等（公式真用）
- 21F4-21FF 带竖线/偏函数箭头
- 全部积分变体（∫∬∭∮、2A00 区 ⨋-⨜）、圈运算 ⨁⨂、2A00 补充运算符多数、关系复合箭头 2970-297B
- 括号/界限拼装件 239B-23B3、23DC-23E1（LaTeX 拼高括号真用）
- 波浪箭头 ⤳、四重箭头 ⟰⟱（半活跃，保守保留）

### 有意留的"名字像字形、实为活符号"

϶(反向∈)、⅀(双线求和)、⅋(线性逻辑 par)——名字是"倒转"形态但数学有真身份，**不是**备用字形，属于"缺用途简介"类，留待后续补简介。

## 四、符号简介补全（2026-09-07 追加，随 v1.18.0）

用户要求"上面辨明的有用信息都写进简介"。简介载体 = SYMBOLS 条目 intro（符号数据.js），无条目的字符须**新建最小条目**（组键=字符首个所属标签，页面 saveSymbolMeta 协议）。

- **「备用字形」标签简介**（标签.json 节点级）：解释判定标准「Unicode 官方分类为数学符号（Symbol, math）但无活跃数学用途」
- **活符号补用途简介**（建条目+改可读名）：϶ 反向∈（皮亚诺引入反写月牙 ε，LaTeX `\backepsilon`）、⅀ 双线求和（∑ 双线变体）、؈ 阿拉伯射线、⅋ par（名留中文层）、𞻰𞻱（名难意译不改，只简介）
- **字形写来历**（建条目，名留中文层）：⅁⅂⅃⅄⍼⧂⧄⥼⥽⥾⥿ 共 11 个——⍼ 写 Angzarr 幽灵字形来历（Monotype→ISO9573/STIX）、⥼ 等注明 ElsevierGlyph E214、⅁ 注明 LaTeX `\Game`

**坑（重要）**：手工拼 SYMBOLS 条目字符串有两个坑——① 条目间**缺逗号**（数组直接语法错）；② python 字符串里 `\backepsilon` 的 `\b` 被当转义成退格符 U+0008。**正确姿势：用 `json.dumps(entry, ensure_ascii=False, separators=(',',':'))` 逐条生成，再手动拼 tab 缩进与逗号**。写数据文件别手拼 JS 对象字面量。

## 五、数学符号整体细分（2026-09-07，随 v1.18.0）

用户追问此前遗留的"数学符号下划分细类"，拍板**整体重建**。数学/数学符号 878 成员（原直持 835 + 旧"运算符、比较符、操作符"子节点 43）按语义角色重分为 9 子类：

```
数学/数学符号
├── 代数、算术运算符 174（四则、带圈/方运算、分数斜线…）
├── 比较、关系 224（=≠<≤≈≡、序关系、整除、平行…）
├── 微积分、分析 37（∫∬∮∂∇∑∏√∞ 及变体）
├── 逻辑 87（∧∨¬∀∃⊢⊨ 及 turnstile 族）
```

- **命名规则**（用户）：并列概念用**顿号**（代数、算术运算符），不用"与/和"，除非是连成词的固定语
- **省略号去留**（用户）：与"括号、定界符"语义不密切（成对定界 vs 省略占位），单列"省略号"子类

- **几何形状 → 几何**（用户）：改名收纳几何类符号；下加子节点 **角、线** 收 32 个（∠∟∡∢ 角度族、∥⊥ 几何关系、؈ 射线、三角形族）+ °(0xB0) 补挂（° 原已挂单位、度量，多挂合法）
- **∂∇ 粗斜体变体 10 个**（1D6xx/1D7xx）→ 移去"数学用的字母数字符号"（该树 ranges 已含 1D400-1D7FF，无需新增，实为取消数学符号侧重复挂载）
- **分类映射规则**：关键词+人工修正 43 项生成 `_map.tsv`，dry-run 核对后执行；执行前备份 标签.json.bak-rebuild，执行后删

## 六、代数、算术运算符 严谨审核（2026-09-07，随 v1.18.0）

用户通读「代数、算术运算符」后发现大量错位——**根因：该名是分类规则兜底**（规则未命中的符号全落这），成了垃圾桶。用户裁定边界 = **常义"代数"**（四则/幂根/带圈方框算符 + **关系代数**），并逐点归位：

| 用户疑问 | 裁决 | 去向 |
|---|---|---|
| ∄(THERE DOES NOT EXIST) | ∃ 的否定 = 逻辑量词 | → 逻辑 |
| ⊓⊔(square cap/cup) | 格论 meet/join，与∩∪同族 | → 集合 |
| ⋈⟕⟖⟗ | **关系代数**连接运算 → 属"代数" | 留 代数（用户裁定） |
| ⊢⊣⊤⊥ 各种 tack/turnstile | 逻辑证明符 | → 逻辑（24 个） |
| ⦝(MEASURED RIGHT ANGLE) | 测角符号 | → 几何/角、线 |
| ⧧(THERMODYNAMIC) | 热力学物理符号 | → 自然、科学/物理 |
| ♯(MUSIC SHARP) | 音乐升号为主，代数侧非真身份 | 移出代数，留 乐谱符号 |
| ℘ | 幂集记号 | → 集合（幂集义）|

**通读补充移出 70 个**：纯图形/沙漏/方块菱形/error-barred/开口方框（⦙⦶⧖⧗⧫⧮-⧳⧾⧿⟊2ACD…）→ 备用字形；序关系否定 ⊀⊁ → 比较、关系；∎(证毕) → 逻辑。

**审核后**：代数、算术运算符 174 → **104**（保留 +−×÷±、幂根、⊕⊗⊞⊠、⋅∗∘∙⋆、⋈⟕⟖⟗、关系代数、+变体等真代数算符）；逻辑→111、集合→118、备用→113、几何角线→40、物理→8。

**校验**：全语义树 17340=17340 零丢失；Playwright `tagsOf()` 实测 10 个代表符号归属全部正确。
