## 1. 直译名家族补齐

`MONOGRAM / DIGRAM / TRIGRAM / TETRAGRAM / HEXAGRAM` → **单爻 / 双爻 / 三爻 / 四爻 / 六爻**。
直译名是「对官方英文名的忠实直译」，所以这套是**爻系**词；富化层那套（三方/九州/八十一家）是
**方州部家**词。两层两套词，别混（·017 用户裁定）。

| 层 | 本轮改动 |
|---|---|
| 八卦 ☰–☷ | 剩下 4 条补上：`三爻·风` / `三爻·水` / `三爻·山` / `三爻·地`（前 4 条用户已改） |
| 六十四卦 ䷀–䷿ | 64 条裸卦名（乾/坤/屯…）→ `六爻·<官方英文名的逐词直译>`，如 `六爻·创造的天堂`、`六爻·初始的艰难` |
| 两仪 ⚊⚋ | 用户改为 `单爻·阳` / `单爻·阴`（与本套一致） |

八卦那 4 条的尾巴沿用已改 4 条的形制（`三爻·天堂`＝TRIGRAM FOR HEAVEN 的名词直译）。

## 2. 六十四卦的三种别名

| 别名 | 例 | 怎么来的 |
|---|---|---|
| 拼音 | `Zhun Hexagram` | 原有，本轮订正 5 处（见 §4） |
| **二进制** | `二进制100010（十进制34）` | **从卦象字形逐像素实测**：阳爻(实)=1、阴爻(断)=0、**自下而上**读 |
| **上下卦** | `坎上震下` | 同一次实测的 6 位里，低 3 位=下卦、高 3 位=上卦 |

**方向校验**（不靠记忆，两级）：

1. 拿用户已写好的八卦二进制别名反推方向 → **8/8 一致**（乾 111=7 … 坤 000=0）
2. 拿 9 个已知卦验六爻读数 → 乾 63、坤 0、屯 34、蒙 17、需 58、讼 23、师 16、比 2、未济 21 **全中**
3. 字形从自带 Noto 与 Segoe UI Symbol **两个字体分别量** → 64 个 **0 处不一致**

页面实测：`二进制`→73（64 卦 + 8 卦 + 1 条简介里提到「二进制」的 ㎅）、`六爻`→64、
`乾上乾下`→乾卦、`坎上震下`→屯卦、`离上坎下`→未济卦、`艮上坎下`→蒙卦。

## 3. 六十四卦简介：三段各自的出处

格式（用户裁定）：`上X（象）下Y（象），象征…。《象》曰：…。`

| 片段 | 出处 | 可核性 |
|---|---|---|
| `上坎（水）下震（雷）` | 卦象字形实测（同 §2），并用下面《大象》自述的构成反查 | ✓ 56 个非纯卦全对；8 个纯卦的象辞本身就写「洊雷/兼山/明两作/随风/丽泽」 |
| `《象》曰：云雷，屯；君子以经纶` | 維基文庫《周易/大象》**原文**，一字未动（只把简体转换误折的「干」改回「乾」） | ✓ |
| `象征万物初生之难` | **逐条对过《彖传》**（見下表） | ✓ 义合，非字同 |

⚠️ **教训**：这半句第一版是**我凭记忆写的、没有任何出处**，却和引文写在同一句里、只说明了
引文的来源，看起来像整句有据。用户追问「『标准卦义』又是从哪里来的」才暴露。**引文与概括
必须分开标明出处**。

四份材料各管什么（别再混）：

- **《彖传》**——给卦名下定义：「需，须也」「咸，感也」「坎，重险也」。**核「象征」用这份。**
- **《序卦传》**——训释卦名：「屯者物之始生也」「贲者饰也」「睽者乖也」。
- **《杂卦传》**——一对一的**情态对比**，不是定义：「比乐师忧」「乾刚坤柔」。
- **《大象》**——君子效法：「君子以…」。

## 4. 五处拼音订正

六十四卦的拼音别名（`Qian Hexagram` 一类）是 v1.35.0 数据文件改名时从旧数据带过来的，
**没有任何脚本会重新生成**。逐条过完，改 5 处：

| 卦 | 改前 | 改后 | 依据 |
|---|---|---|---|
| 屯 | `Chun` | `Zhun` | 屯卦读 **zhūn**（chún 只用于「屯留县」） |
| 小畜 | `Xiao Chu` | `Xiao Xu` | 卦名里的**畜读 xù**（畜养） |
| 大畜 | `Da Chu` | `Da Xu` | 同上 |
| 解 | `Jie` | `Xie` | 解卦读 **xiè**（节卦那条 `Jie` 是对的，按字符定位，没连坐） |
| 履 | `Lu` | `Lv` | lǚ；项目里「旅」已写 `Lv`，同音同形 |

其余容易读错的其实都对：否 `Pi`(pǐ)、贲 `Bi`(bì)、噬嗑 `Shi He`(shì hé)、夬 `Guai`、
姤 `Gou`、艮 `Gen`、兑 `Dui`。

## 5. `datatool` ④d 的人工豁免表

**起因**：☰ 的别名 `三` 被新的直译名 `三爻·天堂` 包含 → 体检红灯。用户裁定
「这是两种不同的含义，不是意思包含，这种包含不算」。

**为什么不能改成「单字别名一律不查」**：`①` 的别名 `1` ⊂「圆圈数字1」也是单字，
而那条是**真冗余**（同一个说法）。`datatool` 里本来就有一行注释挡着这个退法。

**做法**：加 `ALIAS_KEEP = {(字符, 别名)}` 登记表（目前 1 条），带注释说明判据。
它是**登记表不是逃生舱**——被包含**且**确实是长短式的照删。

## 6. 经验教训

1. **引文与概括必须分开标出处。** 我把「象辞（有出处）」和「象征（凭记忆）」写在同一句里、
   只交代了前者，看起来整句都有据。用户一句「标准卦义又是从哪来的」就戳破了。
   **写完先自问：这句里哪几个字是我自己下的判断？**
2. **去重复不能拿没依据的词去填。** 涣卦为了消除「涣散离散」的叠词，我造了「流通」，
   而它没有出处——**修一个问题引入了另一个**。正确做法是回源头找一个真说法的词。
3. **判据要按字符定位，别按字符串。** 「Jie Hexagram」在解卦与节卦上都有，
   按字符串改会连坐误伤；按 `char` 定位才对。
4. **机械推导要留校验点。** 二进制/上下卦都是从字形推的，但都配了独立的断言
   （八卦别名反推方向、9 个已知卦、两字体互验），推错立刻炸而不是静默写进数据。
5. **象辞可以当校验器用。** 大象辞本身就描述卦象构成（「云雷，屯」「山上有火，旅」），
   拿它反查我推的上下卦，56 个非纯卦全对——这是免费的独立验证。
