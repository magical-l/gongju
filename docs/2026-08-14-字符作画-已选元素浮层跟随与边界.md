# 字符作画页：已选元素浮层跟随与边界钳制

## 动机

用户反馈"已选元素"浮层（`#floatPanel`）两个问题：

1. **不跟随**：拖动/方向键移动选中元素时浮层不动，显得"有点傻"
2. **越界**：元素靠近画布底部时浮层下沿突破画布外框下沿

用户回忆此前设计：移动元素浮层跟随，除非手动移动过浮层（手动拖离后停留，换选其他元素重新贴住）。

## 变更

| 文件 | 变更 |
|------|------|
| `字符作画/字符作画.js` | 新增 `panelManuallyPositioned` 标志与 `followFloatPanel`；`positionFloatPanel` 加双向 clamp；`selectElement` 换选判断重贴；拖拽/缩放/方向键三条移动路径追加跟随；拖浮层标题栏置位拖离标志 |

### 关键逻辑

- **跟随**：`followFloatPanel()` 在拖拽（makeDraggable onMouseMove）、缩放（startResize onMouseMove）、方向键（moveSelectedBy）三处调用。手动拖离过（`panelManuallyPositioned`）或浮层隐藏/未选中时跳过。
- **边界钳制**：`positionFloatPanel` 对 left/top 双向 clamp（margin 8px），浮层整体进 `#canvasContainer` 外框；横向保留"右侧放不下翻到左侧"逻辑。
- **拖离语义**：拖浮层标题栏超过 3px 阈值置 `panelManuallyPositioned = true`；`selectElement` 里换选（锚点元素变化）时重置标志并重新贴住，点回同一元素保持停留。

## 踩坑记录

1. **原设计曾明确"不实时跟随"**。`docs/superpowers/specs/2026-08-12-字符作画-panel-restructure-design.md` L49 写"画布变换（拖动元素/平移/缩放）不实时跟随浮层——浮层仅在选中时定位一次"，但用户实际期望是跟随（除非手动拖离）。以用户当前意图为准：跟随成为默认，手动拖离是例外。
2. **根因是定位函数只在选中时被调用**。`positionFloatPanel` 之前只在 `selectElement` 里调用，移动路径从不更新 → 不跟随；纵向 clamp 缺失 → 越界。两个症状由同一函数补齐。
3. **换选判断不能破坏手动拖离**。若"每次 selectElement 都重贴"，用户手动停靠浮层后点回同一元素会又跳回去。用 `prevSelected` 捕获选中前的锚点元素，`anchor !== prevSelected` 才算换选，才重置拖离并重贴。
4. **拖非选中元素不跟随**。拖拽跟随用 `selectedSet.has(element)` 守卫——拖未选中的元素时浮层锚定的是另一个元素，不应跟着动。

## 验证

Playwright 实测（0 console error）：

- 选中元素 → 浮层贴元素右上出现（right+8 / top-12）
- 拖动元素 +60/+40 → 浮层精确跟随；方向键同步跟随
- 拖浮层标题栏移走 → 再拖元素浮层原地停留；换选其他元素重新贴住
- 元素拖到画布最底部（690,545）、素材库 drop 到底部 → 浮层底部距容器底 8px 不外溢；右侧放不下自动翻到左侧
- resize 手柄缩放 → 浮层跟随
- 回归：撤销/重做、缩放、图层拖拽排序、多选批量模式、滑块调参均正常
