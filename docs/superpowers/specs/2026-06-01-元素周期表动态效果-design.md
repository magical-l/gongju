# 元素周期表动态效果设计

## 概述

为元素周期表的"动/静"开关实现第二套动态效果。当用户打开工具栏上的"动"模式开关时，各分类元素的标记样式从静态变为动态动画，增强交互生动感。

## 架构

### 开关类名

- **现状**：`glow-animated`（不精确，仅暗示发光）
- **改为**：`.animation` 类名，在 `tableClasses` computed 中加入（替换 `glow-animated`）
- 切换开关绑定的 data 变量名从 `glowAnimated` 改为 `animationMode`
- 所有动态 CSS 规则嵌套在 `.animation` 父选择器下，与静态规则共存

### 变量名变更

| 旧名 | 新名 |
|------|------|
| `glowAnimated` (data) | `animationMode` |
| `glow-animated` (CSS class) | `animation` |

## 效果逐项说明

### 1. 铁磁元素 — 磁感线虚线流动

**现状**：`::before`/`::after` 用 `background-image: url("弧.svg")` 渲染虚线椭圆弧

**动态**：虚线沿椭圆路径滑动，产生磁感线从N极"出来"、进入S极的方向感

**实现**：
- 将 SVG 从 CSS background-image 改为行内 `<svg>`，用 `<animate>` 驱动 `stroke-dashoffset`
- `::before`（左侧弧）顺时针方向滑动（← N极出来）
- `::after`（右侧弧）逆时针方向滑动（S极进去 →）
- 保持现有三个大小层叠的椭圆
- 参数：`dur: 2s`，`from: 260` → `to: 0`，`repeatCount: indefinite`

**与静态关系**：替换 `background-image` 方案，HTML需为每个铁磁元素卡片加行内SVG

### 2. 液态元素 — 形态变化（表面张力）

**现状**：静态 `border-radius: 15%`

**动态**：border-radius 不规则变化 + 微缩放，模拟液滴表面张力变化

**实现**：
```css
@keyframes morphing {
  0%, 100% { border-radius: 15%; transform: scale(1); }
  50% { border-radius: 25% 15% 20% 15%; transform: scale(1.02); }
}
```
- 周期：2s ease-in-out infinite
- 仅影响 `.animation .液体` 类

**与静态关系**：CSS 叠加，不修改 HTML

### 3. 气体元素 — 呼吸脉动

**现状**：虚线边框 + 弱阴影

**动态**：卡片微缩放 + box-shadow 联动，模拟呼吸

**实现**：
```css
@keyframes breathe {
  0%, 100% { transform: scale(1); box-shadow: 0 0 6px rgba(0,0,0,0.08); }
  50% { transform: scale(1.04); box-shadow: 0 0 12px rgba(0,0,0,0.12); }
}
```
- 周期：4s ease-in-out infinite

**与静态关系**：CSS 叠加，与现有虚线边框不冲突

### 4. 贵金属 / 稀土元素 — box-shadow 呼吸灯

**现状**：贵金属有金色 box-shadow，稀土有绿色 box-shadow

**动态**：阴影透明度/大小缓慢变化，像呼吸灯

**实现**：
```css
.animation .贵金属 { animation: noble-shine 3s ease-in-out infinite; }
.animation .稀土元素 { animation: rare-shine 3s ease-in-out infinite; }

@keyframes noble-shine {
  0%, 100% { box-shadow: 0 0 var(--element-gap) var(--element-gap) rgba(255, 215, 0, 0.4); }
  50% { box-shadow: 0 0 var(--element-gap) var(--element-gap) rgba(255, 215, 0, 0.8); }
}
@keyframes rare-shine {
  0%, 100% { box-shadow: 0 0 var(--element-gap) var(--element-gap) rgba(180, 225, 70, 0.5); }
  50% { box-shadow: 0 0 var(--element-gap) var(--element-gap) rgba(180, 225, 70, 0.9); }
}
```
- 各用各的颜色通道，保持品牌色

**与静态关系**：CSS 叠加，仅覆盖 box-shadow 透明度

### 5. 金属元素 — 145°高光滑过

**现状**：静态 `linear-gradient(145deg, ...)` 高光带

**动态**：高光带从左上到右下滑过金属表面

**实现**：
- `background-size: 200% 200%`
- `background-position: 200% 200%` → `-100% -100%` 循环
- 所有金属卡片同步滑动（用户确认同步优于异步）
- 周期：2.5s ease-in-out infinite

**CSS 类别**：适用于所有 `.金属` 类别（碱金属、碱土金属、过渡金属、贫金属等）

**与静态关系**：修改 `.金属` 规则，加 `background-size` + 动画

### 6. 放射性元素 — ☢ 呼吸 + 粒子环辐射

**现状**：☢ emoji 居中叠加

**动态**：☢ 有节奏地呼吸（缩放+透明度），每轮向外辐射一圈点状虚线粒子环

**实现**：
```css
/* ::before: ☢ 呼吸 */
.animation .放射性元素::before {
  animation: rad-breathe 3s ease-in-out infinite;
}
@keyframes rad-breathe {
  0%, 100% { opacity: 0.5; scale: 0.9; }
  40% { opacity: 1; scale: 1.1; }
  50% { opacity: 0.9; scale: 1.05; }
}

/* ::after: 粒子环 */
.animation .放射性元素::after {
  content: '';
  position: absolute;
  border-radius: 50%;
  border: 2.5px dotted rgba(180, 90, 30, 0.6);
  pointer-events: none;
  animation: rad-emit 3s ease-out infinite;
}
@keyframes rad-emit {
  0% { width: 10px; height: 10px; opacity: 0.8; border-width: 3px; }
  40% { width: 10px; height: 10px; opacity: 0; }
  42% { width: 40px; height: 40px; opacity: 0.7; }
  100% { width: 150px; height: 150px; opacity: 0; border-width: 1px; }
}
```
- 注意：放射性元素的 `::before` 当前用于 ☢，`.animation` 下覆盖为动画版
- 注意：放射性元素的 `::after` 当前未用，可用于粒子环
- 粒子环用 `dotted` 边框而非实线

### 7. 人造元素 — 叉状闪电 + glitch

**现状**：🫴 emoji 左下角

**动态**：🫴 手不时射出一道叉状闪电击在卡片/文字上，配合文字 glitch 闪烁

**实现**：
- 在卡片内嵌 SVG 路径绘制叉状闪电
- `stroke-dashoffset` 动画绘制闪电
- 🫴 手在闪电发出时闪烁
- 文字定期 glitch（色偏 + 模糊 + 位移）
- 周期：3s（闪电）+ 5s（glitch）

**SVG闪电路径**：分叉枝形
```
主枝: 左下→右上
分枝: 从主枝中部向外分叉
```

**与静态关系**：需改 HTML，为人造元素卡片加 SVG 闪电 + glitch 容器

## 未包含的样式变更

- 各效果的 animation-duration 参数仅为起步值，实现中可微调
- 开关的过渡动画（静→动/动→静）不加淡入淡出，直接切换
- 所有动画仅在有 `.animation` 父类时生效，不影响静态模式

## 叠加规则

当元素同时属于多个分类时（如 "铁磁性金属"既是金属又是铁磁），各效果互不冲突，因它们作用在不同的 CSS 属性上：

| 效果 | CSS 属性 | 互斥风险 |
|------|----------|----------|
| 磁感线流动 | SVG stroke-dashoffset | 无（独立 SVG） |
| 液体形态 | border-radius, transform: scale | 无 |
| 气体呼吸 | transform: scale, box-shadow | 可能与贵金属 shadow 叠加 |
| 贵金属/稀土呼吸灯 | box-shadow | 注意：金属+贵金属元素 shadow 叠加 |
| 金属高光 | background-position | 无（gradient 背景） |
| 放射性粒子 | ::before/::after | 无（独立伪元素） |
| 人造闪电+glitch | SVG + filter | 无（独立 SVG） |
