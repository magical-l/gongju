# 多标签搜索 · 设计文档

**日期**：2026-08-26
**范围**：符号工具页（`符号/`）搜索功能的「多标签搜索」支持
**状态**：已定稿

## 背景

符号页搜索框目前把整个查询串当**单个关键词**做子串匹配（`符号.js` `matchedTags` / `matchedChars`），不支持多关键词。功能4「多标签搜索」要求：输入多个关键词时，能按标签组合定位字符。

## 目标

- 查询串按空白拆分为多个 token，每个 token 独立匹配
- 多 token 时计算**交集**，先展示交集结果，再逐 token 展示各自结果
- 单关键词行为与现状完全一致（回归兼容）

## 搜索语义

### 分词

查询串按空白（空格/制表符）拆分为多个 token。

### 每个 token 的字符集

1. **优先标签匹配**：token 匹配标签的 name / path / intro / alias。命中 ≥1 个标签 → 该 token 的字符集 = 所有命中标签成员（含子树）的**并集**。
2. **回退字符匹配**：标签无命中 → token 匹配字符（中文名 / 英文名 / 别名 / unicode 码点 / HTML 转义 / 旗序列名），字符集 = 命中的字符。

### 组合规则

- 单 token：行为与现状一致（标签匹配区 + 符号匹配区）。
- 多 token：**交集** = 所有正向 token 字符集的交集。
- 无排除（`-词`）语法——本期不做。

## 结果展示（搜索视图，从上到下）

1. **标签匹配区**：按 token 分组，每组显示该 token 命中的标签（名/路径/别名/简介）。点击任一标签 → 清空搜索并导航到该标签（沿用现有 `searchSelectTag` 行为）。
2. **字符结果区**：
   - **第一节「多标签交集」**：仅当 ≥2 个正向 token 时显示。空则显示提示「没有同时满足所有关键词的字符」，并指出哪个关键词无匹配。
   - **后续每节**：按输入顺序，每个 token 一节。节头显示该关键词，内容 = 该 token 自己的字符集，独立分页（沿用 500/页）。
   - 某 token 无任何匹配：对应节显示「无匹配」提示。

## 数据与性能

- 每个 token 的字符集物化为 `Set<cp>`；交集用集合运算（大标签如汉字几万码位可承受，O(n)）。
- 各节独立分页状态（每节一个 page 索引）。

## 兼容性约束

- 单关键词搜索完全不变。
- unicode / HTML 转义 / 单字符搜索照常工作。
- 点搜索结果标签 → 清空搜索并导航（不变）。

## 不做（YAGNI）

- `-词` 排除语法
- OR 并集语义
- 左树多选标签
- 各节字符集去重显示来源标签
