## 1. 领域自足（本任务的纲，2026-09-24 用户定）

> **一个标签要包含这个领域的全部相关字符，不用去好几个标签下到处找。**

这条比单条字符重要，已写进 `docs/设计/语义树结构.txt`。它解释了两件事：

- **为什么双挂是常态**：`球面度` 光学用得着 → 挂光学；电磁学用得着 → 也挂电磁学；
  宏观物理学用得着 → 再挂一份。不是二选一。
- **边界在哪**：**「收全」不是「沾边就收」**。判据仍是"这个字符**本身就是**这个领域的"，
  不是"跟这个领域沾过边"。反例：📸闪光灯（摄影）、🔅亮度符号（UI）、🌅日出（景观）、
  🪟窗（建筑）都不进光学。⚠️ 为填满节点做**外围搜刮**有前车之鉴（·019 把 📿🪷 从佛教捡去道教）。

## 3. 与「光学」相邻、但没并进来的

- **`㏛球面度`** 三挂：光学（坎德拉定义式 `cd = lm/sr`）、电磁学（天线增益）、
  宏观物理学（辐射传热的立体角）。它和 `㎭弧度`（平面角）是一对，但弧度现在挂
  `宏观物理学` + `数学/几何/角、线`，两者归类仍不一致 —— 留待后续。
