## 设计决策

- **页大小沿用原 CAP=500**（DOM 渲染预算不变，每页最多 500 个节点）
- **顺序语义不变**：单码位升序在前、旗序列 seqs 在后，翻页只切片不重排
- **按页窗口切片而非物化全量**：`enumerateWindow(ranges, start, count)` 用 skip/remaining 游标跨区间取第 `[start, start+count)` 个码位；单码位段取尽后从 `seqStart = max(0, start - singleTotal)` 衔接旗序列，直到每页 CAP 个或取尽
- **翻页自动选中**：切标签重置页 1；翻页后若当前选中项不在新页，自动选中新页第一个（`cellKey` 比较，保持预览与列表一致）

## 踩坑记录

- **大标签全量物化性能回归**：初版用 `gridAllItems`（`enumerate(ranges, Infinity)` + seqs）物化全列表再 slice。verify 实测根级聚合标签（文字系统/官方分类/区块各 1,114,112 码位）每次点选构建 111 万元素数组 ~20ms + 9MB 瞬时内存，低端设备会卡。改为按页窗口切片，翻页只遍历区间游标，不物化全量。交叉验证 5000 例与全量真值一致（无重无漏）

## 已知项

- 混合标签（单码位 + 旗序列，如语义"标志" 918+259=1177）分页时旗序列衔接在单码位段后：页1=500 码位、页2=418 码位+82 旗、页3=177 旗，末页可能不满一页
- 搜索选中字符后清空搜索框回到网格，若该字符不在当前页则无 sel 高亮（旧版超 500 截断时亦有同类情况，非本次引入）
