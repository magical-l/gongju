# 2026-07-15：text/emoji 双模变体支持

## 动机

部分 Unicode 字符同时有 text（黑白/线稿）和 emoji（彩色/填充）两种显示变体（如 ☀ 加 U+FE0F → ☀️）。原先只显示一种，用户无法知悉或选择另一种。

## 方案

- **数据驱动**：在 `符号数据.js` 中给有双变体的符号加 `"mode":"dual"` 字段（175 个符号，数据来源：Unicode 16.0 emoji-variation-sequences.txt + Emoji_Presentation）
- **CSS 展示**：双模符号在网格中并排显示两个字形——左侧 `.vs-text`（`font-variant-emoji: text`；文字风格），右侧 common.css 的 `.emoji` 类（`font-variant-emoji: emoji`；表情风格），中间无分隔符，gap 2px
- **复制行为**：点击文字侧 → 复制 原字符+U+FE0E（强制文字）；点击表情侧 → 复制 原字符+U+FE0F（强制表情）；点击名称区域 → 复制表情变体
- **页面背景**：`main { background: #eaeaea; }`，连续浅底使空心轮廓可见

## 文件变更

| 文件 | 变更 |
|------|------|
| `符号数据.js` | 175 个符号添加 `"mode":"dual"` 字段 |
| `符号.html` | CSS 工具类、模板渲染、复制逻辑、页面背景 |

# 2026-07-15：效果预览浮窗增加对齐参照

## 动机

符号字符的 glyph 对齐方式各异——有的居中，有的偏上/偏下/偏左/偏右。原先的预览只显示"文X字"，无法直观展示符号在文本中的实际对齐特性。

## 方案

- **同一字体 + 参考线**：参考字母（gxhAyO）和符号使用同一字体（sans-serif），消除不同字体度量差异导致的误导。每行显示 4 条统一灰线（顶/基线/中/底），基线通过 `flex align-items: baseline` + `::before/::after` 空元素精准定位。
- **替代旧预览**：直接替换原来的"文X字"预览区，不再保留独立的"对齐参照"面板。双模符号（text/emoji）保留两行分别展示。
- **动态字号**：Vue 驱动的自动缩放。测量 `.align-row` 的 `scrollWidth` vs `clientWidth`，溢出时按比例缩小（下限 0.9rem，上限 2rem）。窄符号保持 2rem，宽符号自动适配。

## 文件变更

| 文件 | 变更 |
|------|------|
| `符号.html` | 预览区重构：CSS 参考线体系、flex baseline 基线定位、Vue 动态字号逻辑；删除文X字预览和对齐参照面板 |

# 2026-07-16：字体切换下拉框 + 选项内字符预览

## 动机

Noto Sans Symbols 2 覆盖不全的符号（如部分 emoji、CJK 符号），用户无法切换本地字体查看效果。需要罗列本机字体让用户自由尝试，并直观看到每个字体是否包含该字形。

## 方案

- **字体枚举**：优先 `navigator.queryLocalFonts()` API（Chrome 103+，需用户手势触发权限弹窗），失败回退到预定义常用符号字体列表（Noto Sans Symbols 2、Segoe UI Symbol、Segoe UI Emoji 等 17 种）
- **选项内字符预览**：每项右侧用该字体渲染当前符号字符，用户肉眼判断是否支持（正常字形 vs tofu □），不再做算法检测
- **不设 CSS 后备**：选中的字体直接写入 `font-family`，不带 fallback，忠实反映该字体的实际覆盖率
- **"影响其他文本"开关**：关（默认）只替换符号字符的字体，开则整行（含参照文字 "gxhAyO"）替换
- **下拉定位**：`placement="bottom"` + fallback-placements 限定只往下方弹出，避免 sticky 容器导致 Popper.js 飘到左侧

## 一路踩的坑

1. **Canvas measureText 宽度对比法对 CJK/全宽字符无效**：tofu □ 和真实字形的 advance width 都是 1 em，无法区分。尝试了 serif+monospace 双重校验、动态阈值、`document.fonts.ready` 等待，均无效。最终放弃算法检测，改用视觉预览。
2. **`<el-option>` 内 Vue binding 引号嵌套**：`:style="{ fontFamily: \`"${font}"\` }"` 在 HTML 模板中需要正确处理模板字面量和双引号的嵌套。最终改用 `:style="fontStyle(font)"` 方法透传。

## 文件变更

| 文件 | 变更 |
|------|------|
| `符号.js` | 添加 `FALLBACK_SYMBOL_FONTS`、`enumerateFonts`、`fontStyle` 方法；`initFontList` + `onFontDropdownVisible` 懒加载字体列表；删除 `batchTestFonts`/`fontCanRender`/`fontRenderCache` 等检测代码 |
| `符号.html` | 预览面板新增字体切换区域（`el-select` + `el-checkbox`）；选项内字符预览；`:style="symbolStyle"` 绑定 |
| `符号.css` | 字体选择器样式（`.font-selector`、`.font-sample-char`、`.font-option-name`）；`.font-popper` 下拉框高度限制 |

# 2026-07-16：字号适配重构 + 字体切换改竖排单选 + pt 单位显示

## 改动

### 字号适配（`adjustFontSize`）
- **回退到原始溢出检测**：`row.scrollWidth > row.clientWidth` 在同一个 `.align-row` 上比较，避免了 `flex:1` 伪元素的干扰（之前错误地对比 `.align-row` 和 `.char-preview`，导致 flex 撑满后永远触发缩小）
- **取消"太小放大"**：窄符号天然窄，不强行放大，用户通过手动 +/- 自行调节
- **读 DOM 实际字号防级联收缩**：用 `getComputedStyle(row).fontSize` 取实际 px 值做计算，避免 mounted 期间多个 $nextTick 调用读到 stale 的 data 值反复缩小
- **字号范围**：`[0.3, 6]` rem
- **手动微调**：新增 `adjustFontSizeBy(delta)` 和 `resetFontSize()`，`fontSizeAutoFit` 开关控制
- **display 单位**：显示改为 `pt`（1rem = 12pt），CSS 渲染仍用 rem

### 字体切换 UI
- **下拉框 → 竖排单选按钮**：`<el-select>` 改为 `div.font-radio-list` + `label.font-radio-item`，选中项高亮
- **默认勾上"参考文本使用相同字体"**：`fontAffectsAll: true`
- **字体枚举提前**：`initFontList` 改为立即调用 `enumerateFonts`

## 踩坑记录

1. **`adjustFontSizeBy` 被误删**：Python 脚本替换 range 不够长 + 后续删残留代码时连带删除了 `adjustFontSizeBy` 方法体，导致 "not a function" 报错
2. **字体方法缩进偏移**：字体相关方法缩进多了一层（4 tab 而非 3 tab），Vue 未正确注册进 methods
3. **flex:1 伪元素干扰 scrollWidth 测量**：`::before`/`::after` 撑满容器使 `row.scrollWidth` 恒等于容器宽度，错误触发溢出缩小
4. **mounted 期间逐级收缩**：selectedCategory watcher + filteredSymbolGroups watcher + mounted 三个 $nextTick 链式调用 adjustFontSize，用 data 值计算而非 DOM 值，导致同一 DOM 被反复缩

## 文件变更

| 文件 | 变更 |
|------|------|
| `符号.js` | `adjustFontSize` 重写为读 DOM 实际 px；新增 `adjustFontSizeBy`/`resetFontSize`/`previewFontPt`；`fontAffectsAll` 默认 true；`initFontList` 改为直接枚举；删除 `onFontDropdownVisible`；修复字体方法缩进 |
| `符号.html` | 字号显示 `pt`；字体选择器改为竖排单选按钮；步进改为 ±2pt |
| `符号.css` | 新增 `.font-radio-list`/`.font-radio-item` 样式；删除 `.font-popper` |
