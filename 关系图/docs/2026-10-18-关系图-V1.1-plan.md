# 关系图 V1.1 Implementation Plan

> **实现完成（v1.72.0，2026-10-19）**：最终行为、缓存事故与决策见 `2026-10-18-关系图-V1.1-design.md` 的「实现记录与决策日志」；本计划保留为实施过程记录。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans.
> 按用户流程：验收通过前不 commit、不改版本号。

**Goal:** 实体缩放 + 实体多选/组拖/对齐分布/批量删除/方向键微调 + 左树搜索与多选高亮。

**Architecture:** 沿用 V1 分层。模型加 `minHeight` 与校验；几何加纯函数对齐/分布/框选相交；左树渲染支持 `selectedIds` 与 `query`；CanvasView 加缩放柄、多选样式、框选层；应用层把单选状态扩展为「实体集合 + 主对象」。

**Tech Stack:** 原生 JS / HTML / CSS；Node 自带断言。

## Global Constraints

- 不创建 package.json/node_modules；不引入 npm 包；不改 `lib/`。
- 只改 `关系图/` 内文件；不 commit、不改版本号，直到用户验收。
- HTML/CSS/JS 修改由 `html-editor` 子代理执行；改完跑 `node 关系图/test/run.js`、`node --check`，再 dispatch testing/verify。
- 所有新用户可见文案用中文。
- 现有 V1 行为（关系连线、自由线、样式继承、撤销、JSON/PNG、缩放平移）不能回归。

### Task 3: 应用层（选择集合、组拖、缩放、批量删除、微调、对齐分布、组面板、搜索）

**Files:**
- Modify: `关系图/关系图.js`

**Interfaces / 状态：**
- `app.selectedIds: Set<entityId>`；`app.selectedId` 主对象。
- 新增 helpers：`setSingleSelection(id)`、`toggleEntitySelection(id)`、`clearSelection()`、`selectAllPlaced()`、`pruneSelection()`。
- `renderTree` 传 `selectedIds`、`query`；`renderAll`/`renderSelection` 传 `selectedIds`。
- 新增 `app.treeQuery`、`app.nudgeTimer`。

- [ ] **Step 1: 选择状态改造**
  - 所有设置 `selectedId` 的入口统一走 helpers：
    - 选实体：`selectedIds={id}`，`selectedId=id`。
    - 选关系：`selectedIds.clear()`，`selectedId=rel.id`。
    - 新建/导入/撤销后：`pruneSelection()`。
  - `renderTree` 传 `selectedIds`/`query`；`renderAll`/`renderSelection` 传 `selectedIds`。
  - `select(id)` 按对象类别设置；居中逻辑保留。
- [ ] **Step 2: 左树点击**
  - 实体行：`Shift` → toggle；否则单选。
  - 关系行：保持单选 + 待用逻辑。
  - 搜索框：input 更新 `app.treeQuery`，只 `renderTree()`；Esc/清空恢复；不触发整体重绘。
- [ ] **Step 3: 卡片点选/组拖**
  - `onCardPointerDown` 判断 `e.shiftKey`：
    - Shift：toggle 实体选择，不启动拖动。
    - 普通且卡片已在多选集合：组拖（记录所有已选实体起始位置）。
    - 普通且未选中：单选后开始拖。
  - 组拖以整组外接框做 `G.snapGuides`；更新所有卡片和边；松手一次历史。
  - 无位移且多选：收拢为单点实体。
- [ ] **Step 4: 缩放交互**
  - `startResize(id, corner, e)`：记录起始 rect/position/width/minHeight；pointermove 计算新 rect（minWidth 80，minHeight 0）；
  - 西/北角同时改 position；调用 `view.resizeCardTo` + `view.updateEdges`；pointerup pushHistory + renderAll。
  - 与点击/拖拽阈值配合，避免空点。
- [ ] **Step 5: 选中清空/框选/全选**
  - 空白 pointerdown：Shift → 框选；否则清空 + 平移。
  - 框选：世界坐标 rect，选所有相交已放置实体；renderSelection。
  - `Ctrl+A`：全选已放置实体。
- [ ] **Step 6: 批量删除/方向键**
  - `deleteSelected`：有 selectedIds 时逐个删除，能删的删、被阻塞的汇总 toast，一次历史；无 selectedIds 时沿用单对象删除。
  - 方向键：移动所有已选实体 1px/10px；400ms 定时器合并一次历史；结束后 renderAll。
- [ ] **Step 7: 对齐/分布/组面板**
  - `alignSelected(mode)` / `distributeSelected(axis)` 调用 G 纯函数，写 position，pushHistory + renderAll。
  - `renderInspector`：`selectedIds.size > 1` → 组面板（N 个、六个对齐、两个分布、删除、取消选择）；否则现有对象面板。
  - 对齐按钮在 <2 时禁用；分布 <3 时禁用。
- [ ] **Step 8: 右栏宽/高**
  - 实体面板加「宽」「最小高度」数值行；来源/↺ 用现有 `styleRowHTML` 逻辑。
  - 宽空/0 → clear；高空/0 → clear（自动）；数值写 `style`；一次 change 一步历史。
  - 原型有子对象时提示尺寸会沿原型链继承。
- [ ] **Step 9: 回归**
  - 单选/关系/改名/连线/自由线/撤销/自动保存/JSON/PNG/缩放平移全部保持。
  - `node 关系图/test/run.js`、`node --check`。
