# 买房费用计算器：公积金贷款上限三档联动（套数×参贷人数×二孩）

## 动机

上海公积金贷款最高额度政策从固定值（首套240/二套160万）改为按三个维度联动：

| 套数 | 参贷人数 | 二孩以下 | 二孩或以上 |
|------|----------|---------|-----------|
| 首套 | 1人 | 100 | 120 |
| 首套 | 2人及以上 | 200 | 240 |
| 二套 | 1人 | 80 | 96 |
| 二套 | 2人及以上 | 160 | 192 |

三套及以上仍不可公积金贷款。需求由用户提供政策表截图驱动（`买房/贷款政策.jpg`）。

## 变更（`买房/买房费用.html`）

| 项 | 说明 |
|----|------|
| UI | 工具栏新增两个单选组「1人参贷 / 2人或以上参贷」（`loanParticipants`）、「二孩以下 / 二孩或以上」（`childrenCount`），与公积金/商贷同放工具栏；两个单选组包进 `<div class="flex monopoly-x">` 独占工具栏第二行 |
| 数据 | 新增 `loanParticipants: 'multi'`、`childrenCount: 'below2'`；`fundAmount` 默认 **240→200**（与默认档首套上限一致） |
| 计算属性 | `fundCap()` 从固定值改为三维查表：key 为 `` `${homeCount}-${loanParticipants}-${childrenCount}` ``，三套走 `\|\| 0` |
| 联动 | 新增 `loanParticipants` / `childrenCount` 两个 watcher，复用 homeCount 的模式：组合贷且未手动改过（`isCombined && !fundManual`）→ `fillFundAtCap()` |
| 帮助 | 「组合贷公积金锚定」bullet 的（首套240/二套160万）改为（按套数×参贷人数×二孩联动） |
| Tip | 公积金/商贷 tooltip 去掉「、贷款区可用性」，改为「影响首付比例」 |
| 缓存 | `STORAGE_KEY` 2026v4→**2026v5**：政策表变更，旧缓存 `fundAmount=240` 在新默认档（首套200）下语义失真（会显示红色超上限），递增使所有用户回到一致的默认态 |

## 设计决策

- **默认档 2人及以上参贷 + 二孩以下**（用户选定）：首套200/二套160。二套与旧默认一致，贴近多数家庭（夫妻参贷、≤1孩）的现实。
- **扁平 key 查表**：`${homeCount}-${loanParticipants}-${childrenCount}` 拼字符串查对象，三套无对应 key 走 `|| 0`。比嵌套对象更扁平、无遗漏键风险。
- **复用自动贷满模式**：新增 watcher 与 `homeCount` 完全同构（`isCombined && !fundManual → fillFundAtCap`），切参贷人数/二孩即自动贷满到新上限；手动改过额度则保留。
- **第二行用 `.monopoly-x`**：layout.css 现成惯用法（`flex-basis:100%` 强制换行），不引入新 CSS。
- **缓存版本递增**：与 2026v2（2026新政）、2026v4（忽略小金额）的递增先例一致——凡政策表/计算口径变化使旧缓存值语义失效即递增，不依赖"新字段向后兼容"的兜底。

## 踩坑记录

1. **冒烟测试首次加载被「页面说明」弹窗拦截**：`introVisible` 首访默认 true，el-dialog 遮罩拦截对工具栏单选组的点击。测试脚本需先关弹窗（点 `.el-dialog__headerbtn`）再交互。
2. **测试断言顺序与中间态**：从「1人参贷+二孩或以上」切回「2人或以上参贷」时二孩仍为「二孩或以上」，中间态上限是 240 而非 200——先断言中间态 240、再切二孩以下断言 200，才能覆盖完整路径。
3. **Vue 渲染后 DOM 无 `v-model` 属性**：测试脚本用 `[v-model=useFund]` 定位失败，改用渲染后的 `.el-checkbox-button` 文本定位；tooltip 的 `content` 不在 trigger 的 DOM 属性里，需 hover 触发后读 `.el-popper` 文本。

## 验证

- Playwright 冒烟测试 12 项断言全过（首测）：两组渲染、默认选中 2人+二孩以下、默认公积金200贷满绿、切换联动逐一验证 100/120/240/200/二套160、控制台无 error/pageerror。
- 工具栏重排后复测 8 项断言全过：`monopoly-x` 第二行存在且含两组、公积金/商贷在第二行之前、联动未破坏、tip 为「影响首付比例」、无 console 错误。
