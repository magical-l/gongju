# 字符作画 · 风格统一与功能增强 — 设计文档

日期：2026-08-11
状态：已确认，待实现

## 一、背景与目标

`字符作画/字符作画.html` 是一个 emoji/符号拖放画布编辑器，当前是**未接入任何共享资源的全屏 App 式页面**（奶油色系、胶囊圆角、悬浮工具栏、自绘弹窗、`alert/confirm` 反馈）。与项目其余页面（文档式布局 + 浅灰底蓝主调 + 共享 CSS 栈）风格完全脱节。

本次目标：
1. **统一风格**：完全对齐项目文档式页面（`body` 布局类 + header/footer 骨架 + 共享 CSS 变量 + 标准组件）。
2. **优化/增强功能**：补齐最基础的编辑能力（旋转、透明度、图层面板、方向键微调、多选、画布缩放）。

核心交互代码**保留原生 DOM 架构（vanilla JS）**，不引入 Fabric/Konva 等画布库——本页以 emoji 为核心，canvas 位图渲染有已知 emoji 测量/ZWJ 缺陷；且增强功能在原生架构中均为简单 CSS/JS，无需库。经用户确认。

## 二、范围

## 三、页面骨架与布局

```
<body class="目字形">
  <header>   站名"工具兽" + 两排站点导航（当前页高亮）
  <main>
    <header>   页面标题"字符作画" + 帮助按钮
    <div class="toolbar">   新建 保存 打开 │ 撤销 重做 │ 清空 │ 缩放控件(🔍− / 比例% / 🔍+ / 重置)   ← 缩放控件属阶段2
    <section class="editor">   ← 单列
      └── .canvas-card        画布（舞台居中，min-height 内容盒装下 600px 画布，默认无滚动条）
          ├── .scene-canvas
          └── .float-panel    悬浮面板（绝对定位；可拖/可折叠；属性选中时叠加在素材库上方，图层区叠在素材库下方可折叠）   ← 图层区属阶段2
  <footer>   二维码 + 版权 + 反馈
```

关键形态变化：
- 悬浮工具栏 → main 内标准 `.toolbar`（flex，按组 border-left 分隔）
- 素材/属性面板 → **画布内悬浮模块**（绝对定位 + 可拖拽 + 可折叠），不是固定右侧栏——用户验收反馈：素材库应是"悬浮在绘画区域里的模块"，给画布留出全宽
- 全屏 `100vh` → 文档流可滚动；画布卡片 `overflow:auto`（内容盒 ≥ 600px 画布 + 留白，默认无滚动条）
- 保留：空白画布拖拽平移（限卡片内）、撤销/重做/存读等核心交互

## 五、功能增强

### 5.1 画布缩放（视图缩放）
- Ctrl+滚轮 缩放 0.5~2.5，步进 0.1；工具栏 🔍−/比例/🔍+/重置 100%
- 实现：canvas 元素 `transform: translate(panX, panY) scale(z)`，transform-origin 0 0
- 只影响视图，不改元素坐标；平移 clamp 边界按缩放后尺寸计算

### 5.2 旋转
- 属性面板旋转滑块 -180~180 + 数字输入
- 元素 `transform: rotate(Xdeg)`
- 旋转后四角缩放手柄按 `getBoundingClientRect()` 贴旋转后包围盒（视觉正确）

### 5.3 透明度
- 属性面板滑块 0~100%，元素 `opacity: X`

### 5.4 图层面板（叠在素材库下方，可折叠）
- 悬浮面板最底部叠一个「图层」区（默认收起，展开看全层列表）
- 按 z-index 倒序列出全部元素（缩略字符 + 名称）
- 点击条目 ↔ 画布选中双向同步
- 每项 ↑↓ 按钮调层级 + 删除按钮（行间拖拽排序可选）
- 属性面板原"往前/退后"按钮移除，由图层面板接管

### 5.5 方向键微调
- 选中后方向键移 1px、Shift+方向键 10px（多选一起动）
- 选中时 `preventDefault`，防止滚动容器误滚

### 5.6 多选
- Ctrl+点击 增删选中
- 拖动任一选中元素 → 所有选中整体移动
- 批量删除；多选时属性面板显示"已选 N 个"
- 仅支持移动 + 删除（见范围）

## 六、数据模型与兼容

元素字段扩展：

| 字段 | 说明 |
|---|---|
| `type` | `"char"`（单字符/重复）——本次仍为唯一类型，字段为未来 `"text"` 预留 |
| `rotation` | 角度，默认 0 |
| `opacity` | 0~1，默认 1 |

- 快照格式在现有 `{ bg, elements[], transform, width, height }` 上扩展
- 旧数据兼容：读入时缺 `rotation/opacity` 自动补默认值
- localStorage 键不变：`char_scene_data`
- 批量操作（多选移动/删除、图层排序、缩放）并入一个 history 快照

## 七、交互细节与连锁修正（缩放引入）

- **drop/粘贴坐标换算**：`left/top = (client - rect.left) / scale`
- **平移 clamp**：按缩放后画布尺寸计算 min/max
- **缩放时 resize handle 定位**：现有 `getBoundingClientRect()` 已含 transform，无需改
