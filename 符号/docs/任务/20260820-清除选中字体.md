# 符号页：清除选中字体回归默认栈

## 动机

- 优化15：字体切换面板选了字体后无法取消，需加按钮清除，回归默认字体栈。

## 变更

| 文件 | 变更 |
|------|------|
| `符号/符号.html` | `.font-local-load` 内新增「恢复默认字体」按钮，`:disabled="!selectedPreviewFont"`，`@click="clearPreviewFont"`，title 说明用途 |
| `符号/符号.js` | 新增 `clearPreviewFont()`：置 `selectedPreviewFont = ''` |
| `符号/符号.css` | `.font-local-load` 加 `display: flex; gap: 8px`，两按钮并排 |

## 设计决策

- **清除只置 `selectedPreviewFont` 空**：`symbolStyle` 计算属性随之回 `{}` → 走 CSS 默认 `--sym-font-stack`（sans-serif 优先 + Noto 兜底），即"回归默认字体栈"。不动 `fontList`（切换列表保留，用户加载的本机字体选项仍在），也不动渲染栈。
- **禁用态表达**：`:disabled="!selectedPreviewFont"`——未选字体时按钮不可点，语义无歧义。

## 已知项

- 既存观察（非本次改动）：「参考文本使用相同字体」checkbox 无可见效果——`symbolStyle`（绑变体 glyph span）选中字体时无条件应用 `fontFamily`，覆盖行级 `previewStyle` 的 `fontAffectsAll` 分支。待后续处理。
