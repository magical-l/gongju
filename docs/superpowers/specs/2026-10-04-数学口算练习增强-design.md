# 数学口算练习增强 — 设计文档

## 概述

`数学/math-quiz.html` 是一个小学数学口算练习页（纯静态单文件，vanilla JS，无依赖）。现状只有「两位数加减法」一种题型、固定逻辑、无难度分级、无记录。

本次增强目标：**满足自家孩子按年级练习，同时结构上可扩展为工具站通用页面**。

第一轮范围 = **地基（难度分级 + 题型扩展）+ 学习闭环（错题本 + 历史记录）**。计时/连击/闯关玩法留第三层，本轮不做。

## 目标与范围

**本轮做：**
- 知识点注册表 + 难度档位（地基重构）
- 6 个年级难度档 + 自定义知识点勾选
- 「求结果」+「填空求未知数」两种题型
- 错题本（localStorage）：归集、按知识点分组、一键重做
- 历史成绩记录 + 正确率展示

**本轮不做（留接口）：**
- 比大小（答案非数值，输入模型不同）
- 限时挑战 / 连击 combo / 闯关星级
- 会做的题自动降频、错题自动加权（自适应难度）

## 数据模型（地基）

### 题目表示：token 流

所有题目统一表示为 token 流，**答案由程序计算，绝不硬编码**（答案错 = 整个工具废）：

```js
gen() -> {
  tokens:     ['36', '+', '47', '=', '83'],  // 完整表达式，含答案
  answerIndex: 4,                            // 答案在 tokens 中的下标
  blankable:  [0, 2],                        // 可被挖空的数值 token 下标（不含答案位）
}
```

渲染器把 `tokens[answerIndex]` 换成输入框，其余 token 顺序渲染为文本：

```
求结果:   36 + 47 = [__]
填空:     36 + [__] = 83      （answerIndex 被会话层改指到 token 2）
```

**这个模型的关键**：题目只描述完整表达式 + 答案位置，「填空」只是把 answerIndex 挪到别的可空位，是**通用变换**，不需要每个知识点各写一份填空生成器。多步运算（`)` `×` 等）同样适用。

### 知识点注册表

```js
TOPICS = {
  id: { name, grade, gen() -> {tokens, answerIndex, blankable} }
}
```

每题携带 `topic` id，供错题本按知识点归集。

### 难度档位

```js
LEVELS = { id: { name, topics: [知识点id] } }
custom = { name:'自定义', topics: 用户勾选 }
```

## 知识点清单（按人教版课标）

| 难度档 | 知识点 | 样例 |
|---|---|---|
| 一年级上 | 10以内加减、20以内进位加 | `8 + 5 = 13` |
| 一年级下 | 20以内退位减、100以内加减（口算） | `36 + 47 = 83`、`52 − 28 = 24` |
| 二年级上 | 表内乘法（2~9口诀）、乘加乘减、100以内加减混合 | `7 × 8 = 56`、`3 × 4 + 5 = 17` |
| 二年级下 | 表内除法、有余数除法、万以内加减 | `56 ÷ 8 = 7`、`17 ÷ 5 = 3 … 2` |
| 三年级上 | 多位数乘一位数、万以内加减 | `324 × 3 = 972` |
| 三年级下 | 两位数乘两位数、除数是一位数的除法 | `23 × 14 = 322`、`96 ÷ 4 = 24` |
| 自定义 | 任意勾选上述知识点 | — |

> 有余数除法 `17 ÷ 5 = 3 … 2`：token 流为 `['17','÷','5','=','3','…','2']`，答案位指向商 `3`；`blankable` 只含被除数、除数位，余数固定显示。

## 题型（呈现形式）

两种题型可独立开合，同时开启时每题随机选一种：

| 题型 | 规则 |
|---|---|
| 求结果 | answerIndex = 答案位（默认） |
| 填空求未知数 | 从 `blankable` 随机挖空一个数值位，answerIndex 指过去 |

## UI 结构

保持现有视觉风格（Comic Sans + 粉紫渐变 + 撒花），是给孩子用的，不改调性。

```
quiz-card
├── h1 + subtitle（显示当前难度档 + 题量）
├── settings-row
│   ├── 难度档 下拉（6 档 + 自定义）
│   ├── 知识点标签（联动展示当前档包含的知识点；选「自定义」时展开为复选框）
│   ├── 题型 复选框：☑ 求结果  ☑ 填空求未知数
│   └── 题量 input（5 ~ 30，不变）
├── 错题本按钮 → 面板
├── quiz-problems（token 流渲染：文本 token + 输入框）
├── score-bar
└── actions：批卷 / 重新出题
```

**错题本面板**：按知识点分组列出错题（表达式 + 正确答案 + 出错次数），底部「重做错题」按钮 → 生成一轮只含错题的练习。

**结果弹窗新增**：本轮用时、历史正确率、最易错知识点。

## 存储设计（localStorage）

```
mathquiz.v1.history   → [{ ts, level, count, correct, duration }]
mathquiz.v1.wrong     → { 知识点id: [{ expr, answer, count, ts }] }
mathquiz.v1.settings  → { level, topics, count, types }
```

- **批卷**：答错 → 写入错题本（同表达式累加 `count`）；重做答对 → `count` 减 1，归零则删除
- **重做错题**：用 `expr` 反查知识点重放，答对即销账
- 带 `v1` 版本号，格式变更时可迁移或丢弃

## 数据流

```
设置变更 → 按 LEVELS/topics 生成题目(token 流) → 按题型调整 answerIndex
        → 渲染 → 作答 → 批卷 → 更新 state + 写 localStorage → 渲染结果
```

## 边界处理

- **localStorage 全部 try/catch 包裹**：不可用或配额满或版本不符 → 降级为内存存储，静默不弹错
- 空知识点（自定义全不勾）→ 提示并回退到默认档
- 两个题型都不勾 → 回退到「求结果」
- 题量越界 → clamp 到 5~30（现有逻辑保留）
- 输入非数字 / 空白 → 判为错，错题本记「未填」

## 测试

- **生成器是纯函数**，抽成独立块，加 spec 验证：每个知识点生成的每道题，`Number(tokens[answerIndex])` 等于按运算规则手算的结果，且数值落在该知识点声明的范围内。这是唯一致命项。
- **功能测试**走 Playwright 真机：切难度档、勾/取消题型、批卷、错题本重做、刷新后历史与错题本仍在。

## 文件与实现约束

- 单文件：`数学/math-quiz.html`，纯 vanilla JS，无构建、无依赖
- 保持项目约定：无 package.json、不引 npm 包、不改 `lib/`
- 复用现有视觉 token（CSS 变量沿用），仅扩展设置区与新增面板的样式
