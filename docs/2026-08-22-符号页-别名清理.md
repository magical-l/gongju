# 符号页：别名清理 v1.2.2

## 动机

`符号数据.js` 每个符号的 `alias`（别名）数组被两类"标签式"词批量污染：

1. **旧分类组名** —— 打标时把整组名塞给每个成员：`脸`×103、`易经`/`道教`×79、`钱`/`货币`×28、`交通`×20…
2. **CLDR 关联词** —— emoji 注释关键词被当别名导入：👾 → `ufo`/`飞碟`/`太空`/`星际`（符号本身不是这些）

用户原话："很多'别名'被当成标签来用了……这个符号本身不是 ufo、飞碟之类。"

## 方案（两轮修正后定稿）

### 第一轮（踩坑）

派 12 个并行子代理逐符号审查，按"严格只留真别名"（别名=符号本身的名字，情绪词/类别词/关联词全删）。结果 3752→1174，**过度删除**——把表情词/意义词/俗称也删了（😂 的"笑哭了"、🍞 的"一条面包"、😍 的"花痴"、🔭 的"天文/观星"）。用户纠正"矫枉过正"。

**教训**：①"严格"规则的子代理天然偏向删除，拿不准时倾向删；②改数据前必须先看 git status/diff 里用户未提交的新增别名——第一轮把用户当天加的 😍"花痴" 删了，而它不在 HEAD 里，脚本无法靠 git 恢复，只能手工补回。

### 最终裁定（用户选"全恢复描述词"）

- **恢复**所有"描述符号本身"的词：表情词、意义词、俗称、同义词、关联词
- **只删**：
  - **纯类别词** —— 以 `标签.json` 标签名/别名为准（脸/动物/植物/昆虫/水果/蔬菜/星座/黄道十二宫/箭头/圆形/方形/扑克/麻将/骰子/记谱/设施/符号/标识/方向/旅行/运动/性别/太阳系/环保/塑料/工具/文具/交通/宗教/武器/军事/奖牌/马戏团/农业/武术/音乐/乐器/书法/医学/服装/服饰/鞋/袜/配饰/王冠/宝石/牌 等）
  - **明确错误对象** —— 👾👽 的 ufo/飞碟/太空/星际

结果：3752 → 3107。脸全清、易经/道教全清，但"猫脸/狗脸/火车/天文/高兴"等真描述词保留。
