# 星连星 地图生成整体算法

棋盘 M×N，颜色数 n，重试次数 T（如 5）。

---

## 整体选择

- **简单图**（n > min(M,N) 或 min(M,N) ≤ 6）→ 用 **1. 哈密顿分段**
- **生成方式 = 双向延伸** → 用 **2. 双向延伸**，失败重试 T 次，全失败则转 **3. 条纹+转移**
- 否则 → 用 **3. 条纹+转移**

---

## 1. 哈密顿分段

- **1.1 生成一条遍历所有格子的哈密顿路径**
    - 1.1.1 从若干固定形态（蛇形、螺旋等）中随机选一种生成整条路径；可选后续做「混合模式」或分治（当前未做分治）。
    - 1.1.2 对路径做多次随机「段反转」打乱形状。
- **1.2 随机分段**：将路径随机切成 n 段，每段长度至少为 2。
- **1.3 定星星与答案**：每段的首尾格定为该颜色的星星，该段即为该颜色的路径。

---

## 2. 双向延伸

- **2.1 逐颜色放置端点**
    - 2.1.1 对每种颜色 a：随机选一个空格作为端点 E1。
    - 2.1.2 在 E1 的相邻空格中随机选一个作为另一端点 E2。
    - 2.1.3 若 E1 无相邻空格，则重新选择 E1（可重试数次）；仍失败则本局失败，由外层重试 2.1（最多 T 次）。
- **2.2 预处理被包围格子**
    - 2.2.1 初始化端点候选集，包含所有 2n 个端点。
    - 2.2.2 循环直到没有新格子被处理：
        - 对候选集中每个端点 E，找 E 的相邻空格中「被包围」的（上下左右均为路径格子）。
        - 若某被包围格只与当前路径相邻：将其加入该路径的 E 端，从候选集移除 E。
        - 若与多个端点相邻：随机选一个端点，将该格加入该端点的路径，并从候选集移除该端点。
        - 被包围格不加入候选集。
- **2.3 延伸端点方法**（输入：端点 E）
    - 2.3.1 找 E 的四邻空格，分为「被包围空格」和「普通空格」。
    - 2.3.2 若存在被包围空格：随机选一个加入路径（E 变为内部点，新格为新端点），返回新端点，不加入候选集。
    - 2.3.3 否则若存在普通空格：随机选一个加入路径，返回新端点。
    - 2.3.4 若 E 无相邻空格，返回空。
- **2.4 随机延伸**
    - 当候选集非空：从候选集中随机选端点 E，调用延伸端点方法；若得到新端点 N，从候选集移除 E，若 N 非被包围则将 N 加入候选集；若
      E 无相邻空格则从候选集移除 E。
- **2.5 油泡合并**（若仍有空格）
    - 2.5.1 将剩余空格按四邻接成连通块。
    - 2.5.2 对每个块尝试构造一条简单路径（遍历块内所有格）；若某块无法构造则本局失败，重试 2.1。
    - 2.5.3 对每个块的路径调用「合并块到路径」；若失败则本局失败，重试 2.1。
- 重试 T 次均失败则转 **3. 条纹+转移**。

---

## 3. 条纹+转移

- **3.1 初始条纹**：将棋盘按行（或列）均分成 n 条平行路径，每条为连续的一行/列，按蛇形顺序连接。
- **3.2 端点转移**（多轮）
    - 3.2.1 每轮以一定概率选 k=2，否则 k=1（概率可配置，如 0.3）。
    - 3.2.2 随机选一条路径，从其某一端连续缩短 k 格，得到由 k 格组成的块（有序）。
    - 3.2.3 调用「合并块到路径」：若成功则更新相关路径；若失败则回退此步（将缩短的 k 格还原）。
- **3.3 扭线**：对每条路径内部做多次段反转（保持路径连续），增加穿插感。当前不做「随机交换相邻点」。
- **3.4 定星星与答案**：每条路径的首尾格定为星星，路径即为答案。

---

## 通用方法：合并块到路径

- **输入**：board、paths、由空格组成的块及其内已构造的一条简单路径（有序点列表，头尾 P、Q）。
- **输出**：是否成功；成功则更新 board 与 paths。

**步骤：**

1. 找出所有与 P 或 Q 相邻的已有路径格子，作为候选。
2. **若块大小 k = 1**：在候选中筛选出「路径端点」；若存在则随机选一端点 E，将块格接到 E（成为新端点），返回成功。
3. **若 k > 1**：在候选中寻找同一条已有路径上的**相邻两点** b、c，满足 (P 与 b 相邻且 Q 与 c 相邻) 或 (P 与 c 相邻且 Q 与 b
   相邻)；找到则将块路径插入 b、c 之间，返回成功。
4. 若未找到则返回失败。成功时更新相关路径的端点与连接关系。

---

## 当前实现说明

- **整体选择**：简单图（n > min(M,N) 或 min(M,N) ≤ 6）用哈密顿分段；生成方式=双向延伸时重试 T=5 次，全失败则转条纹+转移。
- **哈密顿**：1.1 从若干固定形态中随机选一种生成整条路径，再做段反转；暂不做分治与混合模式。
- **双向延伸**：2.1 逐颜色放端点，E1 无邻格则重选 E1（最多 10 次）；2.2 预处理被包围格；2.3/2.4 候选集随机延伸、优先被包围；2.5
  贪吃蛇+油泡合并；合并块到路径使用通用方法。
- **条纹+转移**：3.2 每轮 k=1 或 k=2（P(k=2)=0.3，可调），从同一端连续缩短 k 格后调用合并块到路径，失败则回退；3.3 扭线为段反转。
- **合并块到路径**：k=1 时只接到路径端点；k>1 时插入同一条路径上相邻两点 b、c 之间；油泡与条纹共用该方法。
