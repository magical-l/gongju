## 0. 一句话

用户给了两个样板（`𝌀` U+1D300 太玄经、`☽☾` U+263D/E 月相），据此把全库扫了一遍。
**判据**：官方名描述的**形状／朝向／构成**与官方码表画的**实际形状**矛盾。
不是「译名不好看」，是**源头就错**——所以只改**富化层**，**直译名照旧忠实照搬**。

反例（不算矛盾）：`U+2E3A/2E3B TWO/THREE-EM DASH` 官方码表画的是**虚线框＋"2M"/"3M"字样**——
那是「示意、没画代表字形」，不是名形矛盾。

## 1. 核字形：只能信官方码表

⚠️ **字体全不可信。** `Segoe UI Symbol` 给太玄经段画的是 Unicode 早期提案的错版
（`U+1D301/302/303` 三个互相错位）；`Noto Sans Symbols 2` 覆盖不全（`U+263D/E` 就没覆盖）。
唯一权威是官方码表：

```
https://www.unicode.org/charts/PDF/U<区块起点>.pdf
```

- `curl` 会 301 → 必须 `-L`；大区块 PDF 会超时 → 要重试 + 先写 `.part` 再改名。
- 区块区间表在 `符号/参考资料/Blocks.txt`。

**工具**（留在 `tmp/`，未入库）：

| 文件 | 干什么 |
|---|---|
| `chartlib.py` | 下载码表 PDF 到 `tmp/charts/` + 按标签搜格子 |
| `grid3.py` | **按码表页自身的格线**定位字形区、取位图（核心） |
| `sheet2.py` / `amap.py` | 家族拼图 / ASCII 逐格墨迹图 |

**两条定位教训**（都踩过）：

1. **格线要用「长线」判**：`page.get_drawings()` 里长度 > 90pt 的才是格线，短的是**字形笔画**。
   不筛长度会把笔画的 x 当成格子边界，裁出半个字形。
2. **页首那一行要跳过**：放的是区块起止码位（如 `1D300` `1D3FF`），不是格子。
   早期按「标签行 ≥4 个才算格子」筛，遇到只有 3 列的页会整页漏掉。

**判「名实不符」的几种程序化手段**（做过的）：

- 逐行/逐列**墨迹分布**判朝向（月牙的尖端在哪边、半黑图的墨在哪半边）
- **按名字声称的角度真转一遍**再比 IoU（旋转棋子 46/46 命中）
- **从字形解出爻序列**再跟卦名对（六十四卦 64/64 命中）
- 数**连通域**（多米诺点数）

## 2. 官方自己承认的「名字有问题」在哪找

| 来源 | 是什么 |
|---|---|
| **UTN #27** `unicode.org/notes/tn27/` | 《Known Anomalies in Unicode Character Names》——官方总清单，v8 (2024-08-13) |
| **NamesList.txt** | `*` 叙述性注解、`%` **正式更正别名**（规范性数据）、`=` informative alias |
| **Unicode errata** 各版本页 | 已勘误的字形错误（多数已修，别再当问题） |

本库规模：NamesList 里带「名字有问题」注解且**在库**的 **29 条**；带**正式更正别名**的 **40 条**。

## 3. 落盘清单

### 3.1 名与形直接矛盾（原批）

| 码位 | 官方名 | 码表实际画的是 |
|---|---|---|
| `U+263D ☽` | FIRST QUARTER MOON | 细月牙、弧面**向右**鼓（尖端在左上/左下） |
| `U+263E ☾` | LAST QUARTER MOON | 细月牙、弧面**向左**鼓 |
| `U+1F31B 🌛` | FIRST QUARTER MOON WITH FACE | 带脸细月牙 |
| `U+1F31C 🌜` | LAST QUARTER MOON WITH FACE | 带脸细月牙 |
| `U+2B7A` | …ARROW WITH DOUBLE **HORIZONTAL** STROKE | 两道**竖**杠（复制粘贴事故） |
| `U+2B7C` | …同上，向右 | 同上 |
| `U+0709 ܉` | SYRIAC SUBLINEAR COLON SKEWED **RIGHT** | 上点偏左、下点偏右 |

**最有力的证据是自相矛盾**：同一份码表里 `U+1F313 FIRST QUARTER MOON SYMBOL` 画半面（◐）、
`U+263D FIRST QUARTER MOON` 画月牙——四个「quarter」两种形。

### 3.2 甲档：名↔形（NamesList 注解类）

`U+019F`（名不描述字形）、`U+027F`／`U+0285`（名说"反形"实际不是）、`U+047C`（名说 omega+titlo
实际都不是）、`U+2E95`（实为「手」部）、`U+2E9C`（实为「帽/冃」部）、
`U+0137`/`013C`/`0146`/`0157`/`1E11`（名说 cedilla，字形是 comma below）——共 12 条。

### 3.3 乙档：名字认错了东西、形没错

`U+0292`、`U+05C6`、`U+0670`、`U+0CDE`、`U+0E9D`、`U+0E9F`、`U+0EA3`、`U+0EA5`、`U+0F0B`、
`U+0F0C`、`U+1BBD`、`U+301E`、`U+A015`、`U+12327`、`U+1E899`、`U+1FBC4`——共 16 条。**只加简介**。

### 3.4 正式更正别名

40 条里加进别名 **32 条**；**跳过 4 条**——更正名被官方英文名整段包含（`U+0EA5`/`16E56`/`16E76`/
`1E899`），官方英文名本身就是搜索通道，别名零贡献；另 4 条已有。

### 3.5 金银直译名

`U+1F71A` 金 → `黄金`、`U+1F71B` 银 → `白银`（两条只剩冗余别名的条目随之删掉）。
**不该改的有 4 条**：`U+2FA6` 是康熙部首「金部」（不是黄金）、`U+322E`/`U+328E`/`U+F90A` 是汉字「金」本身。

### 3.6 标签结构：基督教子树重组

```
信仰/基督教                       （原名「基督教、东正教、新教」——是并称，拆掉）
   ├ 十字架         37   ← 全部十字架类
   ├ 东正教        154   ← 153 个古教会斯拉夫字符 + ☦
   └ 叙利亚诸教会     2   ← ♰ ♱
   本级剩 5：℟ ℣ ⛪ 🛐 🪬
```

- **东正教的 153 个怎么筛的**：按 NamesList **自己的小节标题**判（含 `Historic` / `Old Cyrillic` /
  `Old Church Slavonic` 的进），**不按区段一刀切**——`U+A640–A69F` 里混着「古阿布哈兹语」24 个、
  `U+0500–052F` 混着科米/汉特/莫尔多瓦等现代少数民族语言，一律打「东正教」会打错。排除 76 个。
- **十字架与宗派节点是双挂不是独占**：`☦` 同时在 `十字架` 和 `东正教`；`♰♱` 同时在 `十字架` 和
  `叙利亚诸教会`。判据见 `设计/语义树结构.txt`「标签 = 关键词」。

## 4. 踩过的坑

1. **条目重写不能用 `clear()`**。批量 A 里我用 `o.clear()` 再 `update(新值)` 重写条目，
   **误删了 🌛🌜 原有的别名**（`微笑的上弦月/下弦月`），导致这两个搜索词返回 0 条。
   → 正确写法是**先 `old=dict(o)` 存底，再按字段顺序重建、逐字段判空回填**。

2. **删字段 ≠ 删条目**。`U+271F` 我只想去掉错误的 `name` 字段，却用了 `drop_symbols()`
   ——那是**删整行**，把 `intro`「拉丁十字的描边款。」一起删了。
   → 只改字段用 `update_symbols`，**删整个条目才用 `drop_symbols`**。

3. **range 不能按"含某码位"整段过滤**。把 `☦` 从 `基督教` 移出时，我写的
   `[r for r in ranges if not (lo <= cp <= hi)]` **把含它的整段 `[9766,9769]` 删掉了**，
   连带 `☧☨☩` 一起掉出基督教树、只剩通用根。→ 要**拆段**（左半 + 右半分别保留）。

4. **`**` 在简介里原样显示**。简介是纯文本输出，没有 markdown 渲染。我在 6 条简介里写了
   `**粗体**`，页面上直接显示星号。

5. **直译名会静默吞掉词表里没有的修饰词**。`OUTLINED` / `VOIDED` 不在 `译名词表.py` 里，
   于是 `OUTLINED GREEK CROSS` 直译成「希腊十字」、`VOIDED GREEK CROSS` 也成「希腊十字」
   ——两个不同字形**同名**，而且名不忠实。→ 已把 `'OUTLINED': '描边'`、`'VOIDED': '镂空'`
   补进词表；排查手法见 `设计/数据说明.md` §9。

6. **别把「自己提的方案」当成「要逐项确认」**。方案被批准后就一次走完，
   中途只在真正卡死时才停；而且想就既有数据提问前**先查一遍**——
   `🪬` 早就挂在四个标签下了，问「要不要挂」暴露的是没去读数据。
