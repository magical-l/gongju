# 符号页：人与身体根拆分设计

日期：2026-08-25
状态：设计定稿，待实施

## 背景

「人与身体」语义根有 13 个直接子节点，把**身体 / 人物 / 表情 / 生命**四个维度的内容平铺在一层，父类包容内容过杂（聚合 432 字符）。

## 语义定义（用户裁定，勿违背）

| 标签 | 定义 |
|------|------|
| **人** | 关于**单个"人"的整个个体**（含类人存在，如神仙妖怪/幽灵天使） |
| **身体部位** | **任意生物**的身体的部位（不限于人，可含动物脸） |
| **表情、表达** | **任意生物**的能表达某种意思的行为 |
| **死亡** | 归"人"（个体的生命事件） |
| **健康** | 与身体部位无关 → 并入「社会生活」 |
| **梳妆打扮** | 放回"人"（个体的装扮行为） |
| **仪容仪表** | 改回旧名「服饰」，只留穿戴物件 |

**标签=关键词哲学**：一个符号的含义可来自任何文化语境，可挂多个标签。例：扑克牌 🃢🃣 承载"未成年"牌义、🃥 承载"老年"牌义 → 挂"未成年/老人"是**正确**的（表达含义，不是被当成类别），**不得移除**。

## 根顺序

「人与身体」原为第 4 位（前 3 个是机械轴），是**第一个语义根、默认落点**。拆分后：

```
文字系统 → 官方分类 → 区块 → 人 → 身体部位 → 表情、表达 → 服饰 → 社会生活 → …（其余顺延）
```

默认落点 = 「人」。语义根数 28 → 31。

## 移动清单

| 操作 | 内容 |
|------|------|
| 新建根「人」 | 通用人(取消节点→本级) + 人物角色 + 人形图示 + 性别 + 未成年 + 老人 + 死亡、致命 + 梳妆打扮 |
| 新建根「身体部位」 | 原身体部位(本级6+6子) + 脸 + 发型、发色 |

## 不变项

- 全部字符归属零增删（只移动/改名/删除节点），扑克牌 🃢🃣🃥 保持不动
- 各节点 alias 保留（仅随节点移动）
- 机械轴（文字系统/官方分类/区块）不涉及
- 页面树数据驱动，除 符号.js 一处注释外无需改 JS 逻辑

## 数据格式注意

- 标签.json：`json.dump(indent=2, ensure_ascii=False)` 文本模式写回，保留 CRLF，git diff 干净
- 改名保序：原地重建 dict 保留键序（`rename_dict_key` 模式），新键不得排到末尾
- 验证：根数、子节点归属、聚合计数、无孤儿、搜索可达（别名未丢）

## 验证要点

## 同会话后续整理（v1.8.0 决策日志）

设计批准后本会话又追加了以下整理，全部随 v1.8.0 收尾：

### 家庭 / 职业
- **家庭 → 人**（6 字符，👪 从人本级移除避免同根父子双持有）
- **工作、职业 拆分**：**职业 → 人**（原 8 职业人 + 从人物角色拉入 💁💆💇🕴 共 12，保留人物角色标签双挂）；**工作、职业 → 工作、行业**（11 字符留社会生活，暂平铺）

### 遗留计算区块批量错分清理
- **根因**：Unicode 16/17 升级时，U+1FB00-1FBFF + U+1CC00-1CEFF（~950 字符）被整段区间粗暴打标
- 用户抓到 𜰂(LEFT-POINTING STICK FIGURE) 在游戏、博弈 → 全量审计
- **游戏、博弈 149 直接持有** → 57 精灵图留本级 + 29 象棋→棋类/国际象棋 + 63 迁出（武器→军事、蛇/鱼/蛙/鸟→自然动物、脸→身体部位/脸、电视/电脑→物品电子、婴儿床→生活用品、螺旋→装饰、树/苹果樱桃→植物饮食、办公楼→建筑、易碎品→标志）
- 技术符号/制表符 777、电气 19、天文 17、占卜 16 均确认**干净**（真块元素/电气件/小行星符号/地卜图）

### 易经 / 太玄经
- **易经拆分**：易经符号、八卦、六十四卦 79 → 易经（太极1/两仪2/四象4/八卦8/六十四卦64，平级直属子节点）
- **太玄经拆分**：太玄经符号、八十一首 87 → 太玄经（三方3/九州9/八十一家81）
  - **太玄经是三进制**（3^1=三方、3^2=九州、3^4=八十一家）；Unicode 区块只编 5 个两爻，缺 4 个=易经四象 ⚌⚍⚎⚏，双挂补齐=9
  - **术语**：爻系（一/两/三/四爻玄图）与 玄方州部家 两套并存，用户裁定用**玄方州部家**命名
  - **𝌀(U+1D300) 英文名 "MONOGRAM FOR EARTH" 是 Unicode 误命名**，实为「人」（⚊=天/阳、⚋=地/阴、𝌀=人/和）
- **符号命名统一**（符号数据.js）：⚊阳爻（易经）、天（太玄经）｜⚋阴爻（易经）、地（太玄经）｜𝌀人（太玄经）｜⚌⚍⚎⚏四象·太阳/少阴/少阳/太阴（易经）+天天/天地/地天/地地（太玄经）
- **八十一首坐标前缀**：每个首加「a方b州c部d家」坐标（家→部→州→方 3 进制），如 一方一州一部一家·中、三方三州三部三家·养

### 占星术 / 炼金术
- 炼金术 129 全真炼金符号（干净）
- 占星术（原占卜改名）：移出 20 个与炼金术重复的炼金符号；16 个地卜图新建「地卜图」子节点；本级留 8 月相+🔮

### 踩坑记录
- **pop 后循环插值 bug**：先 pop 旧节点再循环遍历 children 时，旧键已不在迭代对象里，插入条件永远不触发 → 节点内容丢失。修法：先记录位置再 pop，或原地重建时在旧键处插新键
- **同会话用户并行编辑**：改名（性别→性别、婚姻、军事→军事、武器、战争、占卜→占星术、emoji→emoji（绘文字）等）、根重排、符号数据.js 别名。迁移脚本用「原地替换」避免依赖完整子节点清单
- **canvas 字形对比**：判断两批字符是否重复，用 canvas 渲染后逐像素比对（30×30 黑白签名）
