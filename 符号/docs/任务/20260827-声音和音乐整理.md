# 符号页：声音和音乐整理 + 乐谱符号两层拆分（v1.11.0）

日期：2026-08-27
状态：已实施

## 背景

延续「宗教符号整理」模式，用户要求整理「声音和音乐」。全量核对 703 字符，发现两批问题：~130 个记谱符号遗漏未归入、~210 个名字中英混杂（质量差）。随后按用户要求把「乐谱符号」拆成两层。

## 一、遗漏补入（130 个 → 乐谱符号 645→775）

扫描全部记谱 Unicode 区块，补入 5 个遗漏系统：
- **巴厘岛甘美兰记谱** 29（U+1B60-1B7C，此前全未归入）
- **纽姆谱组合标记** 69（U+1CF00-1CF46，主符号 1CF50+ 早已归入）
- **西方音乐组合标记** 29（U+1D16D-1D18B，附点/符尾/连音线/吐音）
- **古希腊音乐组合时值** 3（U+1D242-1D244）

补入按已分配过滤（1CF2E/2F 未分配自动跳过）。

## 二、命名 / 重命名（~210 个，中文名.json 基底层）

发现「声音和音乐」内字符**并非真无名**——中文名.json 基底层已有名，但大量**中英混杂**（build_zhnames 直译残留）。统一清理：

- **希腊声乐记谱** 70 → 希腊声乐记谱符号-N（原"希腊 VOCAL NOTATION SYMBOL-N"）
- **希腊器乐记谱** 37 → 希腊器乐记谱符号-N（VOCAL 之外的第二套）
- **巴厘岛** 29 → 巴厘岛音乐符号·咚/登/当…（甘美兰锣声音译）
- **纽姆谱组合** 69 → 纽姆谱组合·低/高/带十字在左…（俄文术语意译）
- **西方音乐组合** 29 → 附点/符尾/连音线/重音/断奏/双吐…（标准乐理术语）
- **零散** 16 → 拜占庭 GG二连符/OU双元音、4/4拍号、加号形符头等

**保留 13 个中英混合**（合理乐理惯例）：C谱号、X形符头、弱（p）、格列高利C谱号、基辅C谱号等——强行全中文反不专业。

## 三、乐谱符号两层拆分

### 第一层：按记谱系统（6 系统）

```
乐谱符号
├── 通用音乐记号 12（♩♪♫♬♭♮♯ + 🎵🎶🎼 emoji）
├── 巴厘岛甘美兰记谱 29
├── 纽姆谱（俄式圣歌）185
├── 拜占庭圣歌记谱 246
├── 西方五线谱 233
└── 古希腊音乐记谱 70
```

按 Unicode 区块天然划分（各记谱系统独占区块）。

### 第二层：西方五线谱按用途（10 类，无杂项）

```
西方五线谱 233
├── 小节线、反复、停顿 20
├── 谱号、谱表 19（含 BRACE/BRACKET 花括号方括号——连接谱表用）
├── 音符、时值 9
├── 休止符 10
├── 符头 25
├── 调号、拍号、变音 16
├── 力度、声部 10
├── 装饰音、演奏法 41（含踏板 PEDAL/DAMP、Z、度数斜线）
├── 组合记号 31（含指颤音、SORI 韩国演唱记号）
└── 中世纪、格列高利记谱 52（纽姆符 VIRGA/PODATUS、基辅 KIEVAN、格列高利谱号、古代时值 LONGA/BREVIS/FUSA/MAXIMA/TEMPUS、SQUARE B）
```

分类关键：中世纪先于通用（KIEVAN EIGHTH NOTE 属基辅圣歌非普通音符）；古代休止符（LONGA REST/SEMIBREVIS REST）归中世纪；Z/TR 用词边界避免误匹配 PIZZICATO/TREMOLO。

## 五、踩坑记录

- **audit 脚本误报"无名"**：判断字符有无名字要看两层（SYMBOLS + 中文名.json），只看 SYMBOLS 会把"中文名.json 已有名"的误判为无名
- **中文名.json 的 names 是数组**（[[码位,名],...] 升序），修改 = 找到码位项改 name，新增需 push 并保持升序
- **分类正则 Z/TR 词边界**：`Z` 裸写会匹配 PIZZICATO（含 Z）、`TR` 会匹配 TREMOLO，须用 `\bZ\b`/`\bTR\b`
- **记谱系统按区块分天然干净**：纽姆谱/拜占庭/西方/古希腊/巴厘岛各占独立 Unicode 区块，一层拆分即按区块切分；只有通用音乐记号需额外收 emoji 音符（U+1F39C/1F3B5 等不在记谱区块）
- **第二个"古希腊音乐记谱80"是区块轴**（机械轴 Unicode 官方区块），与语义轴 70 同名正常，非重复
