# 关系图 V1.2：内置模板

日期：2026-10-20
状态：已实现（v1.74.0，2026-10-20）

## 目标

让第一次打开工具的人不必面对空白画布：内置五套具体示例模板，选中即可得到一张可编辑的图，同时顺带展示「未放置定义 + 已放置实例」的原型继承模型。

## 边界

**做：**

- `✨ 新建` 改为「新建关系图」弹窗：空白图 + 五套模板。
- 五套模板：分类树、科技树、食物链、时间线、人类迁徙。
- 每套：1 个未放置根定义（设置填充/边框色）、约 6 个已放置实例（继承样式）、1 个未放置关系定义、若干已放置关系实例。
- 选中模板后替换当前图，沿用现有确认与撤销；加载后自动适应内容。
- 模板数据独立成 `templates.js`，Node 测试覆盖。

**不做：**

- 模板缩略图/预览图、用户自定义模板、模板插入当前图（只替换）、把模板作为站点首页入口。
- 图库/多文档、自动布局、分组容器。

## 一、入口与流程

```
✨ 新建
  → 打开 <dialog>「新建关系图」
      [空白图] [分类树] [科技树] [食物链] [时间线] [人类迁徙]
  → 选中空白：沿用现有 newDocument()
  → 选中模板：
      confirmReplace('使用模板「X」')（当前图有内容时）
      app.doc = tpl.build()
      清空选择、armedId
      setViewport → pushHistory → renderAll → fitContent
      toast「已加载模板「X」，可直接改名字使用」
```

- 弹窗卡片为按钮，键盘可聚焦；`Esc` / 「关闭」按原生 `<dialog>` 行为关闭。
- 模板加载后仍是普通文档：可改名、增删、连线、导出、撤销。
- `templates.js` 未加载时，弹窗只显示「空白图」，新建仍可用（降级不报错）。

## 二、模板数据

### 文件与接口

`关系图/templates.js`（UMD，Node 下 `require('./model.js')`，浏览器读 `window.RGModel`）：

```js
window.RGTemplates = {
  list: [
    { id: 'taxonomy', name: '分类树', desc: '…', build: function () { /* 返回新文档 */ } },
    …
  ]
};
```

- 每套模板用 `M.createEntity` / `M.createRelation` 构建，ID 显式且合法，避免手写 JSON 的引用错误。
- `build()` 每次返回全新文档；页面应用时直接替换 `app.doc`。
- 关系实例 `name: ''`，继承关系定义标签；实体实例不覆盖样式，继承根定义颜色。

### 五套内容

| 模板 | 文档名 | 未放置根定义 | 已放置实体（均引用根定义或上级） | 关系定义 | 关系实例 |
|---|---|---|---|---|---|
| 分类树 | 分类树示例 | 生物 | 哺乳纲、犬科、猫科、狼、狐、虎 | 包含 | 哺乳纲→犬科、哺乳纲→猫科、犬科→狼、犬科→狐、猫科→虎 |
| 科技树 | 科技树示例 | 科技 | 基础工具、用火、农业、陶器、冶金、畜牧、文字、轮子 | 解锁 | 基础工具→用火、基础工具→农业、用火→陶器、用火→冶金、农业→畜牧、畜牧→轮子、陶器→文字 |
| 食物链 | 食物链示例 | 物种 | 草、兔、鼠、狐、鹰、虎 | 捕食 | 虎→狐、虎→鹰、狐→兔、狐→鼠、鹰→鼠、兔→草、鼠→草（箭头指向猎物，直线） |
| 时间线 | 时间线示例 | 阶段 | 立项、需求、开发、测试、上线 | 下一步 | 立项→需求、需求→开发、开发→测试、测试→上线（竖排） |
| 人类迁徙 | 人类迁徙示例 | 人群 | 非洲起源、西亚、欧洲、南亚、东亚、北亚、美洲 | 迁徙 | 非洲起源→西亚、西亚→欧洲、西亚→南亚、南亚→东亚、东亚→北亚、北亚→美洲 |

- 根定义颜色：分类树蓝、科技树绿、食物链橙、时间线紫、人类迁徙青；关系定义同色系。
- 手工坐标：
  - 分类树：上下树形；
  - 科技树：从左到右的分支 + 交叉解锁，不做对称括号式；
  - 食物链：金字塔，猎物在下、顶级掠食者在顶，直线连接，箭头由掠食者指向猎物；
  - 时间线：自上而下；
  - 人类迁徙：节点位置近似世界地图（非洲左下、欧洲左上、西亚居中、南亚/东亚向右、北亚右上、美洲最右）。

## 三、界面

- 弹窗：标题左对齐，右上角圆形 × 关闭；说明文字用次级色。
- 卡片：网格两列（`auto-fit minmax(300px, 1fr)`），每张为「图标 + 名称/说明 + 箭头」，左侧 3px 模板色强调条；hover 上移并改用模板色边框，`:focus-visible` 显示轮廓。
- 空白图排在最后，虚线边框、整行占满，与模板区分。
- 卡片必须显式 `height: auto` / `min-height: 76px`，抵消全局 `button` 的固定高度（32px），否则内容会重叠。
- 样式只新增 `.rg-template-*` 与 `.rg-dialog-close` / `.rg-dialog-lead`，复用现有颜色变量。

## 四、版本与缓存

- 不改模型接口，`MODEL_VERSION` 保持 4。
- 新增 `templates.js`；`关系图.html` 全部本页脚本与 CSS 的 `?v=` 递增为 `261025`（模板内容与弹窗样式迭代期间已分别用过 261022–261024，必须让用户浏览器全部失效）。
- 站点版本验收后升 v1.74.0。

## 实现记录与决策日志（v1.74.0，2026-10-20）

### 交付

- `关系图/templates.js`：五套模板（分类树/科技树/食物链/时间线/人类迁徙），每套含未放置根定义、已放置实例、关系定义与实例，并带图标/色调元数据。
- `关系图/关系图.js`：新建按钮打开模板弹窗；加载模板走替换确认 → 构建文档 → 清选择 → 设置视口 → 历史 → 渲染 → 适应内容 → toast；空白图沿用原 `newDocument`。
- `关系图/关系图.html` / `.css`：模板弹窗、图标卡片、模板色强调条、空白项置后、右上圆形关闭。
- `关系图/test/templates.spec.js`：五套模板合法性、继承演示、构建独立性。

### 用户反馈后的内容重写

1. 进化树语义错误：关系写成「演化」，实际是分类层级 → 改名「分类树」，关系「包含」，节点改为「生物 → 哺乳纲 → 犬科/猫科 → 狼/狐/虎」。
2. 科技树过于对称、农业解锁轮子不合理 → 改为游戏式分支 + 交叉解锁，「火」改「用火」，轮子由畜牧解锁，文字由陶器解锁。
3. 食物链箭头方向会读成「草捕食兔」→ 方向改为掠食者→猎物，直线，金字塔排布（猎物在下、顶级掠食者在上）。
4. 时间线横放 → 竖排。
5. 迁移没有体现人类、布局不像地图 → 改名「人类迁徙」，简介写明人类，节点按世界地图大致位置排布。

### 踩过的坑

1. **全局按钮高度压扁模板卡**：`css/common.css` 的 `button { height: var(--btn-h) }` 让 `.rg-template-card` 固定 32px，说明文字与下一行重叠。修复：卡片显式 `height: auto; min-height: 76px`。
2. **hover 边框被全局规则覆盖**：`button:not(:disabled):hover { border-color: currentColor }` 特异性高于 `.rg-template-card:hover`。修复：把选择器提升为 `.rg-template-dialog .rg-template-card:hover`。
3. **缓存版本必须随内容递增**：模板内容与弹窗样式迭代期间依次使用 261022 → 261023 → 261024 → 261025；只要模板/样式变了，就要让用户浏览器失效旧 `templates.js`。
4. **窄屏画布 2px**：既有三栏布局（280 + 自适应 + 300）在 600px 宽时把画布挤到 2px，模板加载后看不见。属既有布局限制，本版不处理；桌面宽度正常。

### 验证

- Node：64/64。
- Playwright：五套模板数量/方向/排布/无越界；弹窗顺序、图标、tone、空白项、hover/focus、宽窄屏；模板编辑/撤销/刷新；替换确认/取消；复制粘贴、删除提升、JSON/PNG、缩放、多选、搜索回归；console/pageerror/404 干净。

### 明确延后

- 图库（多文档）：评估后降级——单图 + JSON 导入导出足以覆盖低频切换，不为假想的多图需求建索引/迁移体系。
- 模板缩略图、用户自定义模板、模板插入当前图。
- 自动布局、分组容器、触屏、颜色预设。
