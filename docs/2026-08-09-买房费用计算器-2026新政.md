# 买房费用计算器：2026 新政适配

## 动机

用户提供宝山区人民政府 2026-04-22 政策梳理《上海个人居住用房买卖税费全梳理！2026最新政策一文读懂》，原页面契税/增值税/个税逻辑已过时。**注意：宝山区只是发布方，政策本身是全国性规定**（财政部/税务总局公告），页面计算不受区域影响。

## 政策依据

- 财政部 税务总局公告 2025 年第 17 号（个人销售住房增值税）
- 财政部 税务总局 住房城乡建设部公告 2024 年第 16 号（契税分档）
- 财政部 税务总局 住房城乡建设部公告 2026 年第 3 号（换购住房个税退税）
- 国税发〔2006〕108 号（个税核定征收）

## 变更（`买房/买房费用.html`）

| 项目 | 旧 | 新 |
|------|----|----|
| 契税档位 | 首套≤90㎡1%/>90㎡1.5%；二套普通2%/非普3% | 唯一≤140㎡1%/>140㎡1.5%；二套≤140㎡1%/>140㎡2%；三套及以上3% |
| 契税计税基数 | 成交总价 | 不含增值税成交价（二手房缴增值税时 = 总价−增值税额） |
| 增值税 | 不满2年 5.3% | 满2年免征；不满2年 3% 价税分离（含税÷1.03×3%） |
| 个税 | 普通1%/非普2% | 统一核定1%（据实征收按差额20%在说明注明） |
| 印花税 | 总价×0.05% | 个人住房全额免征（默认免付） |
| 套数 | 首套/二套 | 新增「三套及以上」（契税3%，首付参考默认100%） |
| 普通/非普通控件 | 存在（影响契税/个税） | 移除（新政下对交易税费无影响） |

## 踩坑记录

1. **面积跨 140㎡ 契税不联动**：`deedTaxRate` 用手动值 `deedTaxPct`，但 watch 只有 `homeCount`/`deedTaxMode` 会重置它，无 `area` watch。面积改 150㎡ 时契税仍按 1% 算而说明高亮已切 1.5%。**补 `area()` watch** 重置契税为政策档位。
2. **localStorage 旧缓存覆盖新政默认**：老用户缓存 `stampMode:'percent'`、`vatRate:5.3` 等旧值，`created()` 恢复后新政默认不生效。`STORAGE_KEY` 加 `2026v2` 版本后缀使旧 key 失效，属政策大版本下的合理迁移。
3. **印花税遗漏**：政策正文只写增值税/个税/契税/房产税，印花税"全额免征"在正文的税费表格图里，需看全图文才不漏。个人住房合同印花税暂免征收是既有政策。

# 同日补充：公积金 / 商贷 贷款方式开关

## 动机

首付比例取决于贷款方式（首套公积金 20% / 纯商贷 15%）。原页面固定组合贷（公积金+商贷都参与），无法表达纯商贷/纯公积金场景。用户要求加两个开关联动首付与贷款区。

## 设计

- homeCount 组后新增两个 `el-switch`：`useFund`（公积金贷款）、`useCommercial`（商贷），默认都开 = 组合贷
- **首付联动**（`policyDownPaymentRate`/`resetDownPaymentRate`）：首套 `useFund ? 20 : 15`；二套与贷款方式无关（差异化 20%/其他 25%）；三套 100%；双关 = 100%（无贷款全款）
- **贷款区 disabled**：关公积金 → fundAmount/fundRate 禁用；关商贷 → commercialAmount/commercialRate 禁用；关闭时对应额度归 0（watch 处理）
- **计算守卫**：`fundLoanAmount`/`commercialLoanAmount` 按 `useFund`/`useCommercial` 短路，贷款合计只算启用的贷款

## 踩坑（重要）

- **in-DOM 模板下 `<el-switch ... />` 自闭合不渲染**：该页面 `mount('main > article')` 是 in-DOM 模板，浏览器 HTML 解析器不认组件标签的 `/>` 自闭合，会把第一个 el-switch 当作未闭合元素、**吞掉后续兄弟节点**（第二个 switch 和 el-tooltip 全部消失）。字符串模板（`template:` 选项）则正常。修复：el-switch 必须用显式 `</el-switch>` 闭合。全文件扫描确认仅此两处组件自闭合隐患。
