# 符号页 变体折叠卡片（design）

日期：2026-08-27
状态：已批准（用户确认：只叠肤色、性别不叠、搜索也折叠）

## 背景

v1.12.0 全量注入 ZWJ 序列后，笛卡尔积变体平铺导致网格冗余严重：同一个符号按肤色 5 套、有时按性别再 2 套，一眼看过去非常雷同。

| 节点 | 当前条目 | 去肤色后（不同符号） |
|------|---------|---------------------|
| 人/职业 | 348 | 60 |
| 人/肤色/浅肤色 | 349 | 209 |
| 人/家庭 | 47 | 32 |
| emoji（绘文字）根 | 1614 | 269 |

目标：**展示层折叠**——同款不同肤色的变体缩成一张卡，卡内用"肤色点行"切换。数据一条不动（`标签.json` 完整保留，1614 全量仍是权威）。

## 核心抽象

**肤色码位集**：`SKIN_CPS = {0x1F3FB..0x1F3FF}`（5 个）。

**分组键**：`variantGroupKey(cps) = cps 去掉 SKIN_CPS 成员后 join('-')`。
- `浅肤色厨师` 与 `中浅肤色厨师` → 键都是 `1F468-200D-1F373`（男厨师）→ 同组折叠。
- `男厨师` vs `女厨师`（首位人码位不同 1F468/1F469）→ 键不同 → **各自成卡**（性别不叠，用户裁定）。

**卡片结构**：
```js
{ main: <成员>, dots: [<成员>...], overflow: N }
```
- `main`：组内**无肤色成员优先**（职业节点里即中性版厨师）；无中性版则取组内第一个（侦探 🕵️♂️ 等 2 组）。
- `dots`：组内其余成员（肤色点行），忠实渲染真实字符（豆腐/不连字照实）。最多 8 个。
- `overflow`：`dots.length > 8` 时的溢出数（如牵手组 26 成员 → dots 8 + overflow 17）。
- 组内只有 1 个成员 → `dots` 空，卡片退化为普通平铺卡，视觉与现在无差别。

**范围**：折叠只作用于展示层 computed（`gridCards`），`gridItems`/`selectedMembers` 保持成员语义不变，详情区/编辑逻辑不受影响。

## 展示改动

三处列表统一折叠：

1. **标签网格**（`人/职业` 348→60 卡）：
   - ranges 单码位逐码位成卡（单码位无肤色变体，天然不折叠）。
   - seqs 按 `variantGroupKey` 分组，每组一卡。
   - 分页/计数按**卡**计（每页 100 卡，职业一页装下）。

2. **概览分段**（非叶子节点各段）：每段 preview 折叠，段 count 按卡数。

3. **搜索结果**：折叠，但 `main` **优先取搜索命中的那个变体**（搜"浅肤色厨师"卡片直接显示浅肤色厨师，而非中性版）。

## 交互

- 点卡片主符号 → `selectItem(main)` 进右侧详情。
- 点肤色点 → `selectItem(该变体)` 进详情（详情区显示该变体的完整序列/标签/预览）。
- 点 `+N` → 弹小面板列出全部变体（带中文名），点选。
- 拖拽卡 = 拖 `main` 成员（肤色点不可拖）。
- ✎ 编辑按钮作用于 `main`。

## 边界

1. **单成员组**（浅肤色节点 209 组中 150 组单成员）→ 无点行，视觉与现在一致。
2. **无中性版组**（侦探等）→ main = 第一个成员，点行照常。
3. **溢出 >8** → 前 8 点 + `+N` 按钮 + 弹面板。
4. **渲染状态**：点行每个点走 `renderState` + `checkSeqRenderable` 检测（已有 SEQ_RENDER_CACHE），不连字/豆腐的照实显示。
5. **详情区**：选中变体后照常显示，不做折叠。

## 前端改动（符号.js / 符号.html / 符号.css）

**符号.js**：
- 新增 `SKIN_CPS` 常量 + `variantGroupKey(cps)` 函数。
- 新增 `gridCards()` computed：聚合 `selectedMembers` → ranges 逐码位成卡 + seqs 分组 → 按页切片 → 卡片数组。
- `gridPageCount` 改为基于卡片总数；`selectedCount` 展示值改为卡片总数（网格头"共 X 个"）。
- `overviewSegments`：各段 preview 改为卡片数组，count 按卡。
- `searchSections`：items 折叠成卡，main 优先命中变体。
- `selectItem` 保持成员语义，不变（卡片 click/dot click 都传成员进去）。
- 新增 `variantPanel` 状态（溢出面板的卡片 + 打开态）。

**符号.html**：三处网格 `v-for` 改为 `card in gridCards`/`seg.preview`/`sec.items`，渲染主符号 + 点行（点行每点一个小 `.char-dot`，忠实渲染）+ `+N` 按钮；加溢出面板弹层。

**符号.css**：`.char-dot` 小圆点样式（缩小版符号）、点行容器、`+N` 按钮、溢出面板。
