## 设计决策

- **名字数据源**：标签网格 `gridItemName(item)` 实时算（`zhNameOf || nameOf`，旗走 `SEQ_INDEX`）；搜索卡片用预计算 `mc.zhName || mc.officialName`，数据同源
- **卡片布局**：column flex = 符号区（固定 36px）+ 名字区（多行自适应）。符号区固定高度 + `justify-content: flex-start`（顶部对齐）保证同一行内不同名字行数卡片符号不错位
- **网格占满**：10 列 `minmax(44px, 1fr)`，去掉 `justify-content: center`，列宽随中间区域自适应（宽视口 ~129px/列，窄视口 ~57px）
- **名字换行**：`white-space: normal` + `overflow-wrap: anywhere`，长名多行居中完整显示
- **分页文案**：vendored EP 的 `#total` 插槽无效（见踩坑），改手写 span

## 踩坑记录

- **EP Pagination #total 插槽无效**：vendored `element-plus/2.10.7` 的 `ElPaginationTotal` 编译产物不引用 slots（`t("el.pagination.total",{total})`），且 bundle 无 zh-cn locale → `#total` 插槽不生效，显示英文 "Total 1177"。改法：layout 去掉 total，分页器旁手写"共 N 个"span（外层 `div.grid-pager` flex + gap）
- **flex 抑制原生 marker（上一轮遗留关联）**：`summary { display: flex }` 会隐藏原生 disclosure marker，同类型问题
- **`.char-symbol` 内联换行**：改动把双模 variant 从 `.char`（行向 flex nowrap）包进 `.char-symbol` 后，窄视口下内联 span 换行竖排堆叠——`.char-symbol` 需 `display: flex` 行向 + `.variant { flex: 0 0 auto }` 强制横排
- **卡片符号错位**：`.char` 曾用 `justify-content: center`，grid 行高由多行名字卡片撑起时其余卡片整体居中，符号区上下浮动 7-14px——改 `flex-start` + 符号区固定 36px 解决

## 已知项

- 无名字卡片：符号区固定 36px 占位，与有名字卡片对齐；名字区空
- 名字多行后卡片变高（3 行名 ~91px），grid 行高自适应
- 宽视口下卡片较大（~129px/列）；若需限制可考虑加列数或 max-width，当前按"占满中间区域"需求实现
