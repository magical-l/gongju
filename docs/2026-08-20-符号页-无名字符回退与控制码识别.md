# 符号页：无名字符回退与控制码识别

## 动机

- bug2：按码点搜出的字符没有名字/名字不对，如 U+84 详情区名字一片空白（`zhName || officialName || char` 兜底到不可见的控制字符本身）。

## 变更

| 文件 | 变更 |
|------|------|
| `符号/符号.js` | `isControlCode(cp)` 顶层函数（C0/C1 控制码识别，与 官方分类/控制字符 标签 ranges 同源）；`nameOf`/`zhNameOf` 无名字码点分类回退名（控制/私用区/未分配）；组件方法 `isControlCode`（模板调用委托顶层）；`titleOf`/`searchTitle` 控制码前缀「控制码」 |
| `符号/符号.html` | 搜索卡片 / 标签网格卡片 `is-ctrl` 类 + 「控制码」徽标；详情区「不可见控制码」提示 |
| `符号/符号.css` | `.char-grid .char.is-ctrl` 虚线边框；`.ctrl-badge` 徽标；`.ctrl-tip` 详情提示 |
| `符号/zh-other.json` | +4 条：U+0080/81/99「（预留控制协议码）」、U+0084「电传打字机换行动作码」 |
| `符号/build_names.py` | `CONTROL_ALIAS = {0x84: 'IND'}`——field-10（Unicode 1.0 名）缺失的控制字符补 ISO 6429 缩写 |
| `符号/名字.json`、`符号/中文名.json` | 管线重生成（+1 显式英名、+4 显式中名） |

## 根因

C1 控制区（0x80-0x9F）32 个字符中 28 个有 UnicodeData field-10 名，**4 个无**：U+0080/81/99（C1 预留位，从未分配名字）、U+0084（ISO 6429 叫 IND/Index，但本项目 UnicodeData 副本 field-10 为空，词表也没覆盖）。按码点搜索（U+84、0x84、裸 hex）能命中任意码点，无名字符显示时 `zhName || officialName || char` 兜底到不可见字符本身 → 名字空白。

全量扫描：可搜索码点 0x0~0x10FFFF 中无名字 = 4 个 C1 控制字符 + 私用区（Co）13.7 万 + 未分配（Cn）81.5 万。后两类天生无名，靠页面回退标签。

## 设计决策

### 无名字码点回退名（页面层，兜底全部）

`nameOf`/`zhNameOf` 数据层未命中后按分类回退：

| 分类 | 中文 | 英文 |
|------|------|------|
| C0/C1 控制码 | 控制字符 | `<control-XXXX>` |
| 私用区（E000-F8FF + 两个补充平面） | 私用区码点 | `<private-use-XXXX>` |
| 其余（未分配/非字符） | 未分配码点 | `<unassigned-XXXX>` |

### 4 个 C1 控制码走数据管线（可被搜索）

名字若只写在页面回退里，搜索「电传打字机」找不到 U+84（搜索只匹配 中文名.json）。因此走数据管线：zh-other.json 补中名 + build_names.py `CONTROL_ALIAS` 补英名，重跑生成两个 json。已验证管线**无损重建**（改动前跑一次 git diff 为空）。

### 控制码两条路（用户选定：混排 + 徽标）

控制码与可见字符是两条路，不能混同。用户明确选择**混排+徽标**：控制码卡片不单独分栏，但加「控制码」徽标 + 虚线边框 + 悬浮标题前缀，详情区加「不可见控制码」提示。

- 识别 `isControlCode(cp)` = `cp < 0x20 || (0x7F <= cp <= 0x9F)`，与 官方分类/控制字符 标签 ranges `[0,31]+[127,159]` 同源
- 「找出所有控制码」不需要新做：左侧树 官方分类 → 控制字符 标签（65 个成员）已可浏览全部
- 搜索命中、标签网格共用同一徽标逻辑；正常符号无徽标、不受影响

## 踩坑记录

- **Vue 模板调不到顶层函数**：`isControlCode(mc.cp)` 直接在模板里用报 `isControlCode is not a function`——模块顶层函数不在组件作用域，需在组件 methods 里加委托方法
- **浏览器缓存旧 中文名.json**：改了数据文件后页面仍显示旧名字，需新开浏览器实例（无缓存）验证
- **CSS 文件编辑被工具限制**：Edit 对多行 CSS 替换报错，改用 python 脚本插入
- **zh-other.json children 结构**：标签.json 的 `children` 是 dict（按名索引）不是 list，遍历要 `.values()`

## 已知项

- 私用区/未分配的英文回退名 `<private-use-XXXX>`/`<unassigned-XXXX>` 是页面标签非官方名，搜索匹配不含
- 非字符（如 U+FFFF）归到「未分配码点」，与 UCD 的 noncharacter 概念略有出入，可接受
- `CONTROL_ALIAS` 目前只补 U+0084；未来若 UnicodeData 升级引入新无名控制码，需同步扩充
