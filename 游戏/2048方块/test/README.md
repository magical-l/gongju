# 2048方块 · 自动化测试说明

## 运行

在项目根目录 `游戏/2048方块` 执行：

```bash
npm test
```

等价于 `node test/run.js`，加载 `test/all.spec.js` 中的全部用例。

---

## 《玩法》规则与用例对照

下列按《玩法.txt》章节归纳：**当前已覆盖**、**建议后续补充**（实现与测试可分期做）。

| 玩法章节 | 内容摘要 | 当前覆盖（`all.spec.js`） | 缺口 / 后续用例建议 |
|---------|---------|-------------------------|---------------------|
| §2 场地与坐标 | 行、列、左下为原点（实现为 `board[0]` 顶行） | 各用例棋盘尺寸不一，隐含坐标一致 | 单独断言「矩阵 `(i,j)` → 场地 `(col,row)`」与 §2 公式一致（若 logic 暴露可测函数） |
| §4.1 移动与合并 | 前线格、整块同进同退、同数合并 / 异数阻挡 | **§4.1 合并**：七形状各「下落一格合并」「异数硬降锁定」「两 tick 链式」 | 左/右移合并、下移以外方向的前线格；多前线格组合边界 |
| §4.2 硬降/软降 | 硬降逐步判定至锁定 | 硬降在「异数」用例中 | 软降间隔、松手恢复周期（需 mock 时间或暴露步进 API） |
| §4.3 旋转 | SRS、旋转不合并 | **无** | 各形状 0/1/2/3、踢墙成功/失败、旋转后合并仅在之后 tick |
| §5 锁定延迟 | 接触后可操作直至超时 | **无**（需多 tick + 锁计数） | 锁定期内左右移、旋转、再落地 |
| §6 固化 | 合并后进固定堆 | 合并与消行用例间接覆盖 | 显式「仅固化、无合并」终盘格子数 |
| §7.1 消行 | 满行、`min` 除法、商 1 消 / 商>1 剩、剩格与上方块生成 | **§7.1 消行（除法与重力）**：1.x～4.x 编号场景 | 非相邻多消行组、商>1 多格不同商 |
| §7.2 多活动块 | 排序、同 tick 下落、争格优先、锁独立、递归消行 | **§7.2～7.3 整理链**（`advancePostLockLineClearNoSpawn`） | 两枚剩格争一格、顺序与 `lineClearPolicy` 全组合 |
| §7 + 策略 | 整块上方行、竖并条件、保形 | **§7 整块上方行与 lineClearPolicy**（U 形、异数禁竖并等） | 与默认 policy 矩阵对照表 |
| §8 生成与登顶 | 生成重叠则游戏结束 | **无** | 构造顶行满 + 生成点被占 → `gameOver` |
| §9 SRS | 与经典一致 | **无** | 与 §4.3 合并为 SRS 专项 |
| §10 碰撞 | 越界、顶行暂出、仅判占用 | 间接 | `row < 0`、仅越顶不撞 |
| §11 计分 | 行基础分、数字奖励、升级 | **§11 计分**：全 2 一行、2/4 混合一行、`getLineClearBaseScore`；`logic` 内累计 `linesClearedTotal` 并更新 `level`（每 10 行一级，上限 20） | 多轮链式消行后的累计分与等级；与 UI 展示的等级/下落周期联动测试 |

**结论**：现有用例覆盖 **§4.1 合并**、**§7.1 消行**、**§7 整理链与整块策略**、**§11 计分**；**旋转/SRS、锁定延迟、登顶** 等可继续按上表补 **it**。

## 目录结构（精简说明）

| 路径 | 作用 |
|------|------|
| `run.js` | Node 下 `describe`/`it` 迷你运行器，**唯一 CI 入口** |
| `all.spec.js` | 全部自动化断言（与上表对应） |
| `scenarios/scenario-0x.js` | 供 `run-all-scenarios.js` 与 `scenario-0x.html` 复用的数据 |
| `run-all-scenarios.js` | 在 Node 中跑与浏览器场景相同的数据（可选回归） |
| `scenario-0x.html`、`测试可视化*.html` | 本地 HTTP 下人工 / 可视化对照 |
| `line-clear-policy-demo.html` | 消行策略组合演示 |
| `gen-scenario*.js`、`compute-before.js` | 生成或推算场景初始面的**辅助脚本**，不纳入 `npm test` |
| `悬空合并与重力-探讨.md` | 设计讨论备忘，非测试断言 |
