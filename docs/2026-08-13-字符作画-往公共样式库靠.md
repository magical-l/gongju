## 实现说明

- **弹窗**：原生 `<dialog>` 走 top-layer，居中由 UA 承担，遮罩用 `::backdrop`。`dialog.close()` 只关闭不销毁元素，必须与 `remove()` 成对，否则重复开关累积隐藏 `<dialog>`。ESC 触发 `cancel` 事件关闭（旧 div.modal 无此行为），需 `cancel` 监听同步 remove。
- **问号图标**：common.css 的 `.help` 设 `--icon-char: var(--char-question)`，`.icon.char-style:empty::before` 渲染 `?`，只需收紧尺寸变量到 18px（icon 默认 36px 太大）。
- **滑块行**：layout.css 的 `flex items-x-space-between items-y-near-center` 提供对齐，`items-single-line` 防换行。

## 踩坑记录

1. **原生 `<dialog>` UA 默认 3px 边框**——切到 dialog 后若只删旧的 `1px solid` 而不显式 `border: none`，弹窗会显示粗边框（verify 抓出）。
2. **`dialog.close()` 不销毁元素**——旧 div.modal 用 `remove()` 直接移除；切到 `close()` 后 DOM 残留，需 `close(); remove();` 成对（verify 抓出）。
3. **ESC 是原生 dialog 新增行为**——旧 div.modal 无 ESC 处理；需监听 `cancel` 事件同步 remove，否则 ESC 关闭残留隐藏 dialog（testing 抓出）。
4. **layout.css `.flex` 的隐式副作用**——common.css 的 `.flex > input { width:0; flex:1 }` 会把 range 滑块拉伸，layout.css 的 `.flex { flex-wrap: wrap }` 会换行。复用工具类必须显式补 `input[type="range"]{flex:none}` + `items-single-line`。
5. **tooltip 被 icon 覆盖层顶掉**——common.css `.icon.char-style:empty::after` 是 `inset:0` 的覆盖层（特异性 0,3,1），会覆盖页面 `[data-tooltip]:hover::after`（0,2,1），tooltip 永不显示。需更高特异性 `i.icon[data-tooltip]:hover::after` + `top/right:auto; line-height:normal` 抵消。
6. **弹窗卡片视觉来源**——biz.css `.modal > .body` 的 `box-shadow 0 10px 25px`、`border-radius: 15px`、`background: white`、`zoomIn 动画` 是原卡片视觉；切 dialog 后要原样迁移到 `dialog` 卡片，别用 `var(--radius-lg)`(8px) 替代 15px，否则圆角可见偏差。
7. **CSS 改动用 css-ast 事务**——本环境对直接写 CSS 有守卫 hook，css-ast 的 `set-value` 用 includes 匹配选择器，曾把 `dialog > .body input` 的 radius 连带改坏，需精确回退。
