# 符号页：别名清理遗漏 v1.3.1（饮食组 CLDR 关联词）

## 动机

用户发现 🍌 别名里有个"钾"——"钾是香蕉的别名？真是莫名其妙！"。

## 根因

`参考资料/annotations-zh.json`（CLDR 中文注释）把关联词当关键词标：🍌 的 `default` 关键词是 `["水果","钾","香蕉"]`（香蕉富含钾）。构建时 CLDR 关键词被拷进 `符号数据.js` 的 alias 数组。v1.3.0 全量清理删了"水果"，但"钾"漏网。

**教训**：CLDR 注释关键词是**关联物/营养/场所/品牌**（钾、维他命C、星巴克、酒吧、早晨），不是别名。v1.3.0 按词表删了一批，但遗漏在同一类里反复出现（🌭香肠、⛾杯子/饮料、🍌钾）——说明这类清理不能靠单次词表，要按"关联物/类别词/属性词"的**类**去扫。

## 方案（用户裁定"全清同类残留"）

按 v1.3.0 定稿标准（别名=能确定性指代该字符的称呼，非关联物/类别词/品牌/场所/属性词/含义词/时间词），一次性清完饮食组全部同类残留，含边缘词（煎/蛋/全麦面包/烤面包/水果蛋糕/酒）。

### 保留原则

- **同义词**：柑桔/比萨/烟肉/芝士/咖啡/茶
- **意义词**：干杯（v1.2.1 明确保留）
- **描述符号本身的词**：一条面包/一片披萨/一面老一面嫩的煎蛋
- **表情 emoji 的情绪词不动**（v1.2.1 "全恢复描述词"裁定）
- **符文本义**：ᛞ Dagaz 的 白天/黎明 是符文本义直译，非 CLDR 关联词，保留
- **误名配套**：⭘ 的"睡眠/sleep"是"电源待机"（误名，官方 HEAVY CIRCLE）的配套，非 CLDR 污染
