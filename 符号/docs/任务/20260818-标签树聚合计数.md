# 符号页：标签树节点显示聚合字符数

## 动机

2026-08-18 todo 功能2：左侧标签树每个节点都显示字符数量（没有就显示 0），非叶子节点的字符数包含下属所有叶子节点的字符数，数字不要用逗号分隔。随后用户补充：全页数字统一不带千分位逗号。

## 变更

| 文件 | 变更 |
|------|------|
| `符号/符号.js` | `treeVisible` computed 的 count 由"只算节点自身 ranges/seqs，无则 `|| null` 隐藏"改为 `this.collectNode(node)` 聚合自身+全部子孙，`count = rangeCount(merged.ranges) + seqs.length`，恒为数字（无成员 = 0） |
| `符号/符号.html` | tcount 去掉 `v-if="t.count !== null"` 与 `toLocaleString()`（树节点恒显数字、无逗号）；gridhead"共 N 个"去掉 `toLocaleString()`（全页数字统一） |

## 设计决策

- **聚合复用 `collectNode`**：与选中标签的 `selectedCount`/`selectedMembers` 同一函数、同一公式（`rangeCount(merged.ranges) + seqs.length`），点树节点时 `selectedTag.node === t.node`（同一引用），树数字与 gridhead"共 N 个"必然一致
- **并集去重语义**：父节点 count = mergeRanges 合并后的并集码位数 + seqs 数，非"子节点简单求和"。实测 30 个父节点中 1 个下存在 26 对兄弟叶子 range 重叠，并集去重避免重复计入；与分页/selectedCount 语义完全一致
- **性能**：树 716 节点（686 叶、最深 4 层），全展开最坏重算 7.65ms；`expanded` 是唯一响应式依赖，每次 toggleExpand 只重算一次
- **保留 gridhead 千分位**：功能2 只要求树节点，gridhead 单独处理（用户确认全页统一后也去除）

## 踩坑记录

- **无成员节点误隐藏**：旧代码 `(...) || null` 让非叶子（自身无 ranges）count 变 null → 模板 `v-if="t.count !== null"` 隐藏数字。改为恒为数字（0）
- **demo 原型残留**：`demo/原型.html`（历史原型存档，git 已移入 demo/）仍有 3 处 `toLocaleString`，属存档不在"符号页全页数字"范围内，未动

## 已知项

- gridhead"共 N 个"与树 tcount 均为无逗号整数；el-pagination 组件内 total 显示（`Total 7659` 形式）为组件自带格式，非项目数字，未改
- 若未来标签树规模膨胀 10 倍以上，可考虑按 path 缓存各节点聚合 count（当前 716 节点无必要）
